Frigidaire Microwave Error Codes

Complete Troubleshooting & Repair Guide

Control Panel Errors
F1
Touch Pad Error
  • Disconnect power for 5 minutes.
  • Clean control panel from moisture or grease.
  • Check ribbon cable connection.
  • Replace touch pad if faulty.
Temperature & Sensor Errors
F2
Overheat Condition
  • Allow microwave to cool completely.
  • Check ventilation openings for blockage.
  • Inspect thermal sensor or thermostat.
  • Replace thermal cutoff if needed.
F3
Sensor Failure
  • Inspect sensor wiring connections.
  • Test sensor resistance.
  • Check for moisture damage.
  • Replace sensor if defective.
Door & Safety System Errors
F4
Door Switch Issue
  • Check door alignment and latch.
  • Inspect door switches for damage.
  • Test continuity of door interlock system.
  • Replace door switch assembly if needed.
Power & Cooking System Errors
F5
Relay Failure
  • Reset microwave power supply.
  • Inspect control board relay circuit.
  • Check wiring to high-voltage components.
  • Replace control board if relay is faulty.
F6
Magnetron Fault
  • Do not operate unit if fault persists.
  • Check high-voltage diode and capacitor.
  • Inspect magnetron connections.
  • Replace magnetron if confirmed faulty.
Important: Microwave repairs involve high voltage components. If the issue persists, contact a certified Frigidaire technician.
