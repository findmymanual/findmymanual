Canon Printer Error Codes

Complete Canon Printer Guide

This guide explains all Canon Printer error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

READY
Canon Printer Ready Status
  • Printer is powered on and ready for use.
  • No action required.
  • Start printing jobs normally.
  • Ensure device is selected as default printer.
ERR 01
Print Head Communication Failure
  • Remove and reinstall ink cartridges.
  • Clean cartridge contacts gently.
  • Check compatibility of ink cartridges.
  • Restart printer to reset system.
ERR 02
Paper Feed / Tray Issue
  • Reload paper correctly into tray.
  • Adjust paper guides properly.
  • Remove any jammed paper.
  • Clean feed rollers if needed.
ERR 05
Ink System Error
  • Check ink levels and replace if low.
  • Reinstall ink cartridges properly.
  • Run ink system reset or cleaning.
  • Restart printer.
ERR 06
Scanner Unit Malfunction
  • Restart printer/scanner device.
  • Clean scanner glass surface.
  • Ensure lid is fully closed.
  • Update printer firmware.
ERR 10
Print Job / File System Error
  • Clear print queue.
  • Restart printer and computer.
  • Resend document to print.
  • Check file format compatibility.
ERR 20
Mechanical Feed Failure
  • Check paper path for obstructions.
  • Remove jammed paper carefully.
  • Inspect rollers for wear or dust.
  • Service feed mechanism if needed.
ERR 30
Internal System Fault
  • Restart printer.
  • Unplug power for 1 minute.
  • Update firmware if available.
  • Contact service center if unresolved.
ERR 40
Power Supply Error
  • Check power cable and outlet.
  • Try a different power source.
  • Inspect adapter for damage.
  • Replace power unit if needed.
ERR 50
Main Board Communication Failure
  • Restart printer system.
  • Check internal ribbon cables.
  • Update firmware.
  • Replace main board if required.
ERR 60
Print Head Alignment Failure
  • Run print head alignment tool.
  • Clean print head nozzles.
  • Use recommended paper type.
  • Replace print head if needed.
ERR 70
Print Processing Error
  • Restart printer and computer.
  • Clear print queue.
  • Update printer driver.
  • Reduce print job size.
ERR 80
Electrical System Fault
  • Turn off and unplug printer.
  • Check for moisture or dust inside.
  • Inspect wiring connections.
  • Service internal board.
ERR 90
Paper Jam System Error
  • Remove jammed paper carefully.
  • Check rollers and feed path.
  • Reload paper correctly.
  • Clean paper sensors.
ERR 100
Memory Write Failure
  • Clear print queue.
  • Restart printer.
  • Reduce large print jobs.
  • Update firmware.
ERR 110
Ink Cartridge Recognition Issue
  • Reinsert ink cartridges properly.
  • Clean cartridge contacts.
  • Use compatible cartridges only.
  • Replace faulty cartridge.
ERR 120
Overheating Warning
  • Turn off printer and allow cooling.
  • Improve ventilation around device.
  • Avoid continuous heavy printing.
  • Remove dust buildup.
ERR 130
USB / Network Connection Failure
  • Check USB or LAN cable connection.
  • Restart router and printer.
  • Reinstall printer drivers.
  • Try different cable or port.
ERR 140
Firmware Conflict
  • Reset printer settings.
  • Update to latest firmware.
  • Remove external accessories.
  • Perform factory reset if needed.
ERR 999
Unknown System Error
  • Restart printer.
  • Unplug power cable and reconnect.
  • Check all connections.
  • Contact Canon support.
FAQ
Canon Printer Common Issues
  • Check power and connection if printer is not printing.
  • Ensure Wi-Fi or USB connection is stable.
  • Replace ink cartridges if print quality is poor.
  • Restart device to fix temporary errors.
FAQ
Canon Printer Connectivity Issues
  • Verify Wi-Fi password and network settings.
  • Move printer closer to router if signal is weak.
  • Restart router and printer.
  • Reinstall printer driver if needed.
FAQ
Canon Printer Maintenance
  • Clean print heads regularly.
  • Use proper paper type and size.
  • Keep firmware updated.
  • Avoid long continuous printing sessions.

Frequently Asked Questions


What does PRN01 Canon Printer Not Ready mean?
Check power connection, ensure printer is turned on, verify USB or Wi-Fi connection, and restart printer and computer.
What does PRN02 Blank Print Output Detected mean?
Check ink cartridges, run print head cleaning, ensure correct print settings, and replace empty or clogged cartridges.
What does PRN03 Printer Offline / Not Responding mean?
Check USB or Wi-Fi connection, restart printer and computer, set printer as default, and clear print queue.
What does PRN04 Wi-Fi Connection Failure mean?
Verify Wi-Fi password, restart router and printer, move closer to router, and reconfigure wireless settings.
What does PRN05 Poor Print Quality Detected mean?
Check ink levels, clean print head, use correct paper settings, and align print head if needed.
What does PRN06 Streaks or Lines on Print mean?
Clean print head and nozzles, remove dust inside printer, check ink cartridges, and run deep cleaning cycle.
What does PRN07 Paper Jam Detected mean?
Remove jammed paper carefully, check rollers for debris, reload paper properly, and ensure correct paper size.
What does PRN08 Multi-Feed Paper Error mean?
Fan paper before loading, avoid overloading tray, clean rollers, and use dry flat paper.
What does PRN09 Unusual Noise Detected mean?
Check for foreign objects, inspect rollers, clean internal parts, and stop use if noise continues.
What does PRN10 Printer Not Detected mean?
Check USB or network connection, reinstall drivers, try different port, and restart devices.
What does PRN11 Slow Printing Performance mean?
Lower print quality, close background apps, check network stability, and restart printer.
What does PRN12 Print Job Not Saving or Stuck mean?
Clear print queue, check storage space, restart print spooler, and reinstall printer driver.
What does PRN13 Connection Instability mean?
Replace USB cable, check Wi-Fi signal, update firmware, and restart router and printer.
What does PRN14 Print Interrupted Error mean?
Check paper feed, remove jams, restart print job, and update drivers.
What does PRN15 General System Failure mean?
Restart printer, reset settings, check power connection, and contact support if issue persists.
What does PRN16 Overheating Warning mean?
Turn off printer, allow cooling, ensure ventilation, and avoid continuous heavy printing.
What does PRN17 Restart Loop Detected mean?
Check power supply, update firmware, reset settings, and inspect internal hardware.
What does PRN18 Power Failure mean?
Check power cable, test outlet, inspect adapter, and replace faulty power supply if needed.
What does PRN19 Network Connection Lost mean?
Restart router, reconnect Wi-Fi, check network stability, and update network settings.
What does PRN20 System Reset Required mean?
Power off printer, wait 30–60 seconds, restart system, and test printer operation.
What does PRN21 Memory Overflow Error mean?
Reduce print size, clear queue, restart printer, and update firmware if needed.
What does PRN22 Maintenance Required mean?
Clean print head, check rollers, run calibration, and replace worn parts if needed.
Important: Always disconnect power before performing repairs. Contact a qualified technician if the issue persists.
