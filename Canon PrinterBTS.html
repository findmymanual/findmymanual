Canon Printer Error Codes

Complete Troubleshooting & Maintenance Guide

Paper System Errors
E02
Paper Not Loaded
  • Load paper correctly into tray.
  • Align paper guides properly.
  • Check for sensor obstruction.
  • Restart printer after loading.
E03
Paper Jam Detected
  • Turn off printer and remove jammed paper.
  • Check rear and front paper paths.
  • Ensure no torn paper remains inside.
  • Restart printer after clearing jam.
Ink System Errors
E04
Ink Cartridge Not Detected
  • Reinstall ink cartridge properly.
  • Clean cartridge contacts gently.
  • Ensure compatible cartridge is used.
  • Replace cartridge if faulty.
E05
Ink Cartridge Error
  • Remove and reinstall cartridge.
  • Check for protective tape removal.
  • Clean chip contacts carefully.
  • Replace cartridge if needed.
Maintenance & Waste Ink Errors
E07
Waste Ink Absorber Full
  • Service waste ink pad or absorber.
  • Reset printer counter (service mode).
  • Avoid continued printing without maintenance.
  • Contact technician if unsure.
E08
Ink System Error
  • Restart printer system.
  • Check ink delivery system for blockage.
  • Inspect cartridge installation.
  • Service internal ink system if required.
Cartridge Communication Errors
E13
Ink Level Unknown
  • Remove and reinstall cartridge.
  • Clean chip contacts.
  • Use genuine or compatible cartridge.
  • Replace cartridge if issue persists.
E14
Cartridge Communication Failure
  • Check cartridge chip alignment.
  • Clean contact points carefully.
  • Restart printer.
  • Replace cartridge if faulty.
E15
Cartridge Not Recognized
  • Reinstall cartridge properly.
  • Ensure correct model compatibility.
  • Clean cartridge contacts.
  • Replace cartridge if necessary.
E16
Ink Low Warning
  • Prepare replacement ink cartridge.
  • Continue printing if allowed.
  • Monitor print quality closely.
  • Replace cartridge soon.
Note: Some ink system errors may require reset or service mode access depending on printer model.
