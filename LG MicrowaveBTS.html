LG Microwave Error Codes & Troubleshooting

Complete LG Microwave Oven Repair Guide

F1
Keypad Error
  • Check control panel for stuck buttons.
  • Clean keypad surface.
  • Reset power supply.
  • Replace control panel if needed.
F3
Temperature Sensor Fault
  • Inspect thermistor wiring.
  • Check sensor connection.
  • Allow unit to cool down.
  • Replace sensor if faulty.
F4
Door Switch Error
  • Ensure door is fully closed.
  • Check door latch alignment.
  • Inspect door switch mechanism.
  • Replace door switch if defective.
F5
Magnetron Failure
  • Unplug microwave immediately.
  • Check high-voltage components.
  • Inspect magnetron condition.
  • Professional repair required.
F6
Inverter Error
  • Check inverter board connections.
  • Inspect power supply stability.
  • Reset unit.
  • Replace inverter if needed.
SE
Sensor Error
  • Check internal sensor wiring.
  • Clean control board area.
  • Restart microwave.
  • Replace sensor if necessary.
E11
Main PCB Failure
  • Disconnect power for 10 minutes.
  • Inspect PCB for damage.
  • Check wiring harness.
  • Replace control board if needed.
E13
Touch Panel Communication Error
  • Clean control panel surface.
  • Check ribbon cable connection.
  • Restart unit.
  • Replace touch panel if faulty.
E14
Overheating Detected
  • Allow microwave to cool down.
  • Check ventilation openings.
  • Avoid overuse.
  • Inspect cooling fan.
E15
Cooling Fan Malfunction
  • Check fan for obstruction.
  • Inspect fan motor wiring.
  • Clean internal dust buildup.
  • Replace fan if not working.
F0
Control Board Communication Error
  • Turn off and unplug the microwave for 10 minutes.
  • Inspect wiring between control board and display panel.
  • Check for moisture or dust on connectors.
  • Replace main PCB if the error persists.
F2
Humidity Sensor Error
  • Clean the interior sensor area.
  • Check sensor wiring connections.
  • Restart the microwave.
  • Replace humidity sensor if faulty.
F7
Inverter Overcurrent Error
  • Unplug microwave immediately.
  • Check inverter board and wiring.
  • Inspect magnetron for damage.
  • Seek professional repair service.
F8
Low Voltage Error
  • Check household power supply stability.
  • Avoid using extension cords.
  • Reset circuit breaker.
  • Test microwave on a different outlet.
F9
High Voltage Transformer Fault
  • Disconnect power immediately.
  • Inspect high-voltage transformer (technician only).
  • Check capacitor and diode condition.
  • Professional repair required.
E10
Exhaust Fan Error
  • Check ventilation fan for obstruction.
  • Clean grease buildup inside unit.
  • Inspect fan motor wiring.
  • Replace fan if not functioning.
E12
Thermal Cutoff Activated
  • Allow microwave to cool completely.
  • Check ventilation and airflow.
  • Clean internal dust and grease.
  • If repeated, inspect thermal fuse.
E16
Relay Control Failure
  • Unplug microwave and reset power.
  • Inspect relay board connections.
  • Check control PCB for damage.
  • Replace relay board if necessary.
E17
Door Open Detection Fault
  • Ensure door is fully closed.
  • Inspect door latch and hooks.
  • Check door switch alignment.
  • Replace switch if defective.
E18
Sensor Calibration Error
  • Reset microwave power.
  • Clean sensor area inside cavity.
  • Check sensor wiring connections.
  • Replace sensor if calibration fails.

Frequently Asked Questions


Why is my LG microwave not heating?

This is usually caused by a faulty magnetron, inverter, or door switch. Professional repair may be required.

What does “SE” error mean on LG microwave?

SE indicates a sensor error. Try resetting the unit and checking sensor connections.

Why does my LG microwave show F3 error?

F3 means a temperature sensor fault. The thermistor may be damaged or disconnected.

Can I reset my LG microwave?

Yes. Unplug the microwave for 5–10 minutes, then plug it back in to reset the system.

Why does my LG microwave keep shutting off?

This may be due to overheating, a faulty door switch, or unstable power supply.

Is it safe to use a microwave with an error code?

No. Stop using the unit if an error appears, especially if it involves heating or high-voltage components.

What causes sparking inside the microwave?

Sparking can be caused by metal objects, damaged waveguide cover, or internal component failure.

Why is my LG microwave keypad not responding?

This may be due to a stuck button, moisture damage, or control board failure.

When should I call a technician for LG microwave issues?

You should contact a technician for magnetron failure, inverter errors, burning smell, or repeated error codes.

Important: Always unplug the microwave before inspection or troubleshooting.
