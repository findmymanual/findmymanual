GE Washer Error Codes

Complete GE Washer Guide

This guide explains all GE Washer error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

E22
Door Lock Failure
  • Check door latch alignment.
  • Inspect door lock wiring.
  • Ensure door closes completely.
  • Replace door lock assembly if faulty.
E47
Door Lock Circuit Issue
  • Inspect wiring harness to door lock.
  • Test continuity of lock circuit.
  • Check control board output signal.
  • Replace lock or PCB if needed.
E39
Lid Switch Failure
  • Check lid switch alignment.
  • Inspect switch wiring for damage.
  • Test switch continuity.
  • Replace lid switch if faulty.
E23
Drain Pump Issue
  • Clean drain pump filter.
  • Check for hose blockage.
  • Inspect pump motor wiring.
  • Replace pump if not running.
E24
Drain Problem Detected
  • Inspect drain hose for kinks.
  • Check pump impeller for debris.
  • Ensure proper drainage path.
  • Reset machine after cleaning.
E25
Drain Blockage Detected
  • Remove lint and debris from drain system.
  • Check hose for internal clogging.
  • Inspect pump for obstruction.
  • Restart cycle after cleaning.
E30
Motor Control Error
  • Check motor wiring connections.
  • Inspect control board output.
  • Test motor resistance.
  • Replace motor or PCB if needed.
E54
Motor Overload
  • Reduce heavy laundry load.
  • Check drum for blockage.
  • Inspect motor for overheating.
  • Allow cooling before restart.
E57
High Motor Current Detected
  • Inspect drum bearings.
  • Check motor shaft movement.
  • Look for jammed load.
  • Replace motor if current remains high.
E58
Motor Overheating
  • Allow machine to cool down.
  • Check ventilation around motor.
  • Inspect motor components.
  • Replace motor if overheating persists.
E59
Motor Tachometer Failure
  • Inspect tachometer sensor wiring.
  • Test signal output.
  • Check rotor movement.
  • Replace sensor if faulty.
E31
Pressure Sensor Fault
  • Inspect water level sensor tube.
  • Check pressure switch wiring.
  • Clean air trap hose.
  • Replace sensor if needed.
E38
Water Level Issue
  • Check inlet valve operation.
  • Inspect water pressure.
  • Clean inlet filter screen.
  • Verify sensor accuracy.
E40
Temperature Sensor Error
  • Inspect thermistor wiring.
  • Test sensor resistance.
  • Check connector pins.
  • Replace sensor if faulty.
E43
Control Board Communication Fault
  • Restart machine power cycle.
  • Inspect wiring between modules.
  • Check for moisture damage.
  • Replace PCB if fault persists.
E44
UI Communication Failure
  • Check ribbon cable connection.
  • Inspect display board wiring.
  • Reset power supply.
  • Replace UI board if unresponsive.
E60
Voltage Supply Error
  • Check household power stability.
  • Inspect outlet and breaker.
  • Avoid extension cords.
  • Use voltage regulator if needed.
E61
Overheating Protection Activated
  • Allow washer to cool down.
  • Check motor ventilation.
  • Inspect load size.
  • Restart after cooling.
E62
Internal Memory Error
  • Power cycle the machine.
  • Check control board firmware.
  • Inspect for moisture damage.
  • Replace PCB if needed.
E63
Cycle Calibration Error
  • Reset washer settings.
  • Run calibration cycle.
  • Check sensor alignment.
  • Update firmware if available.
E64
Motor Start Failure
  • Check motor wiring connections.
  • Inspect start capacitor (if applicable).
  • Ensure drum is not jammed.
  • Replace motor if no response.
E65
Motor Position Sensor Error
  • Inspect rotor position sensor wiring.
  • Test sensor signal output.
  • Check for loose connectors.
  • Replace sensor if faulty.
E66
Motor Drive Circuit Failure
  • Inspect inverter/control board.
  • Check for burnt components.
  • Test motor drive output voltage.
  • Replace PCB if necessary.
E67
Overcurrent Protection Triggered
  • Reduce load in drum.
  • Check motor for mechanical resistance.
  • Inspect wiring for short circuits.
  • Replace motor or PCB if issue persists.
E68
Undervoltage Error
  • Check household voltage supply.
  • Avoid extension cords.
  • Inspect outlet stability.
  • Use voltage stabilizer if needed.
E69
Communication Timeout
  • Restart machine power cycle.
  • Inspect wiring harness connections.
  • Check control board signal lines.
  • Replace PCB if communication fails.
E70
Water Inlet Timing Error
  • Check water supply valve.
  • Inspect inlet hose for blockage.
  • Clean inlet filter screen.
  • Replace inlet valve if needed.
E71
Water Pressure Too Low
  • Check household water pressure.
  • Inspect inlet hose for kinks.
  • Clean filter screen.
  • Install pressure booster if needed.
E72
Drain Timeout Error
  • Check drain hose for clogging.
  • Inspect drain pump operation.
  • Clean pump filter.
  • Replace pump if not draining.
E73
Excessive Foam Detected
  • Reduce detergent usage.
  • Use HE-approved detergent only.
  • Run rinse cycle.
  • Clean detergent dispenser.
E74
Water Temperature Sensor Drift
  • Inspect thermistor wiring.
  • Test sensor resistance.
  • Check water heating system.
  • Replace sensor if unstable readings.
E75
Load Imbalance Detected
  • Redistribute clothes evenly.
  • Avoid washing single heavy items.
  • Reduce load size.
  • Restart spin cycle.
E76
Door Sensor Intermittent Fault
  • Inspect door switch wiring.
  • Check latch alignment.
  • Clean door lock area.
  • Replace switch if unstable.
E77
Pump Cavitation Detected
  • Check for air in drain system.
  • Inspect pump impeller.
  • Clean drain hose.
  • Replace pump if noise continues.
E78
Firmware Calibration Error
  • Power cycle washer.
  • Run calibration mode.
  • Check control board firmware.
  • Update or replace PCB if needed.

Frequently Asked Questions


Why is my GE washing machine not starting?
Check that the washer is properly plugged in and the circuit breaker is on. Make sure the door is fully closed and locked, select a wash cycle, and ensure control lock is not enabled.
Why is my GE washing machine not filling with water?
Ensure the water supply valves are fully open. Check inlet hoses for kinks or blockages, clean the inlet filter screens, and verify household water pressure is adequate.
Why is my GE washing machine not spinning?
Redistribute clothes evenly in the drum. Avoid overloading, check for drainage issues, and inspect the drive belt or motor if the problem continues.
Why is my GE washing machine not draining?
Clean the drain pump filter and check the drain hose for clogs or bends. Ensure the pump is working properly and restart the cycle after clearing blockages.
Why is my GE washing machine leaking water?
Inspect inlet and drain hoses for leaks. Check the door seal for damage or dirt buildup. Avoid overloading and ensure the washer is level on the floor.
Why is my GE washing machine making loud noise?
Check for loose items inside the drum. Ensure the washer is level and not vibrating excessively. Inspect suspension system, bearings, or motor if noise continues.
Why does my GE washing machine stop mid-cycle?
Check for power interruptions, water supply issues, or drainage problems. Ensure the load is balanced and restart the cycle after resetting the machine.
Why is my GE washing machine not unlocking?
Wait for the cycle to complete fully. Check if water is still inside the drum. Try unplugging the washer for a few minutes and inspect the door lock mechanism.
Why does my GE washing machine smell bad?
Clean the drum, detergent drawer, and door seal regularly. Run a tub clean cycle and leave the door open after use to prevent mold and odor buildup.
How do I reset my GE washing machine?
Turn off the washer and unplug it for 5–10 minutes. Restore power, then select a new cycle and start the machine again.
Why is my GE washing machine not completing the cycle?
Check water supply and drainage issues. Ensure the load is balanced and not overloaded. Inspect the control panel for interruptions or faults.
Why is my GE washing machine vibrating excessively?
Make sure the washer is level on the floor. Redistribute clothes evenly and avoid overloading. Check shock absorbers or suspension springs if vibration continues.
Why is my GE washing machine not turning on?
Check the power outlet and breaker. Ensure the washer is plugged in properly. Inspect the door lock and control panel for any faults.
Why is my GE washing machine leaving clothes wet?
Check if the spin cycle is working properly. Avoid overloading and ensure proper drainage. Inspect the motor or belt if spin performance is weak.
Why is my GE washing machine displaying unusual behavior?
Reset the machine by unplugging it for a few minutes. Check for water, power, or load issues. If the problem continues, inspect the control board.
Important: If the error code continues after troubleshooting, disconnect power immediately and contact a certified GE technician.
