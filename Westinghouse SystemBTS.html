Westinghouse System Messages

Meaning & Troubleshooting Guide

Control Lock & Safety
LOC
Control Lock Active
  • Press and hold the lock button for 3–5 seconds.
  • Check if control panel is responding.
  • Clean keypad surface for moisture or dirt.
  • Reset power if lock does not clear.
Temperature & Safety Warnings
HOT
Overheat Warning
  • Allow appliance to cool completely before use.
  • Check ventilation and airflow paths.
  • Clean filters or cooling components.
  • Avoid continuous high-load operation.
Power Messages
PF
Power Failure Detected
  • Check household power supply and breaker.
  • Reset appliance by unplugging for 5–10 minutes.
  • Reconfigure settings after restart.
  • Use voltage stabilizer if fluctuations occur.
System Errors
ERR
General System Error
  • Perform a full power reset.
  • Check wiring and internal connections.
  • Look for additional fault codes.
  • Replace control board if error persists.
System Reset
RESET
System Restart Required
  • Turn off appliance and unplug for several minutes.
  • Restart system after reset cycle.
  • Check if message reappears.
  • Inspect control board if repeated resets occur.
Cooling Cycle
COOL
Cooling Cycle Active
  • Allow cycle to complete normally.
  • Do not interrupt operation.
  • Ensure proper ventilation around unit.
  • System will return to normal automatically.
Important: If system messages persist frequently, disconnect power and contact a certified Westinghouse technician.
