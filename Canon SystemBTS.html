Canon System Messages

Status Indicators & Basic Troubleshooting Guide

System Status Messages
BUSY
Device Processing Task
  • Wait for current task to complete.
  • Do not power off device.
  • Check for queued print/scan jobs.
  • Restart only if frozen for long time.
READY
Device Ready for Use
  • No action required.
  • Ensure paper and ink are loaded.
  • Verify connection to computer or network.
  • Begin printing or scanning normally.
Error & Warning Messages
ERROR
General System Error
  • Restart device.
  • Check for paper or ink issues.
  • Inspect display for specific error code.
  • Reset system if necessary.
RESET
Restart Required
  • Power cycle the device.
  • Unplug for 1–2 minutes.
  • Reconnect and restart.
  • Check if issue persists.
Supply Status Messages
NO INK
Ink Cartridge Empty
  • Replace empty ink cartridge.
  • Check cartridge installation.
  • Ensure correct model compatibility.
  • Run print test after replacement.
NO PAPER
Paper Tray Empty
  • Load paper into tray.
  • Adjust paper guides properly.
  • Check for paper feed obstruction.
  • Restart print job.
Note: System messages are often status indicators and not hardware faults unless persistent.
