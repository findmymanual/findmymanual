Canon System Messages Error Codes

Complete Canon System Messages Guide

This guide explains all Canon System Messages error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

PRN-BUSY
Device Processing Task
  • Wait for the current operation to finish.
  • Do not power off the device during processing.
  • Check for pending print, scan, or copy jobs.
  • Restart only if the device becomes unresponsive.
PRN-READY
Device Ready for Use
  • No action required.
  • Ensure paper is loaded correctly.
  • Check ink or toner levels.
  • Confirm device connection to PC or network.
PRN-GEN
General System Error
  • Turn device off and on again.
  • Check for paper jams or cartridge issues.
  • Review display for error details.
  • Perform system reset if needed.
PRN-RST
Restart Required
  • Power off device completely.
  • Unplug power cable for 1–2 minutes.
  • Reconnect and restart device.
  • Verify issue is resolved.
PRN-INK-EMPTY
Ink Cartridge Empty
  • Replace empty ink cartridge.
  • Ensure correct installation.
  • Use compatible Canon ink.
  • Run nozzle check after replacement.
PRN-NO-PAPER
Paper Tray Empty
  • Load paper into input tray.
  • Adjust paper guides properly.
  • Remove any paper obstructions.
  • Restart print job.
PRN-JAM
Paper Jam / Feed Obstruction
  • Open all printer covers carefully.
  • Remove jammed paper slowly.
  • Check rollers for debris.
  • Reload paper and retry printing.
PRN-LOW-INK
Ink Level Warning
  • Prepare replacement cartridge.
  • Monitor print quality closely.
  • Continue printing if acceptable.
  • Replace when output fades.
PRN-COVER
Cover Open Error
  • Close all printer covers firmly.
  • Check cartridge access door.
  • Ensure no objects block closure.
  • Restart device if needed.
PRN-OFFLINE
Communication Lost
  • Check USB or Wi-Fi connection.
  • Restart printer and computer.
  • Set printer as default device.
  • Reconnect network if required.
PRN-MEM
Memory Full
  • Cancel unnecessary jobs.
  • Reduce scan or print size.
  • Print in smaller batches.
  • Restart device to clear memory.
PRN-SCAN
Scan Operation Failure
  • Restart scanner or printer.
  • Check scanner lock switch.
  • Verify cable connection.
  • Update drivers and software.
PRN-PHEAD
Print Head Error
  • Reseat print head carefully.
  • Clean contacts gently.
  • Run cleaning cycle.
  • Replace print head if needed.
PRN-WIFI
Wireless Connection Issue
  • Restart router and printer.
  • Reconnect to Wi-Fi network.
  • Check password accuracy.
  • Move closer to router.
PRN-MAINT
Maintenance Required
  • Run maintenance cleaning cycle.
  • Check rollers and sensors.
  • Inspect waste ink absorber.
  • Contact service if persistent.
PRN-CARTRIDGE
Cartridge Error
  • Reinstall ink cartridge.
  • Clean electrical contacts.
  • Check compatibility.
  • Replace if defective.
PRN-NET
Network Busy / Delay
  • Wait for current tasks to finish.
  • Reduce simultaneous jobs.
  • Check network stability.
  • Restart router if needed.
PRN-FWUP
Firmware Update in Progress
  • Do not turn off device.
  • Maintain stable power supply.
  • Follow on-screen instructions.
  • Restart after update completes.
PRN-USB
USB Communication Error
  • Reconnect USB cable.
  • Try another port.
  • Replace damaged cable.
  • Reinstall drivers.

Frequently Asked Questions


What does CAN-SCN02 Device Not Detected mean?
Check USB cable connection, try another USB port, reinstall Canon scanner drivers, and restart both scanner and computer.
What does CAN-SCN03 Blank Scan Output mean?
Ensure document is placed correctly, close scanner lid fully, clean scanner glass, and verify scan settings.
What does CAN-SCN04 Blurry Scan Output mean?
Clean scanner glass, increase scan resolution, ensure document is flat, and remove dust or smudges.
What does CAN-SCN05 Slow Scanning mean?
Reduce scan resolution, close background applications, use direct USB connection, and restart scanner.
What does CAN-SCN06 Wi-Fi Connection Failure mean?
Verify Wi-Fi password, restart router and scanner, move closer to router, and redo wireless setup.
What does CAN-SCN07 Scanner Keeps Disconnecting mean?
Check signal stability, update drivers and firmware, inspect USB cable, and use wired connection if possible.
What does CAN-SCN08 Files Not Saving mean?
Check save location settings, ensure enough storage space, verify file permissions, and restart scanning software.
What does CAN-SCN09 Scanner Error Message mean?
Restart scanner and computer, check connections, update drivers, and refer to specific Canon error code guide.
What does CAN-SCN10 Scanner Not Responding mean?
Check all cables, restart devices, reopen scanning software, and reinstall Canon drivers if needed.
What does CAN-SCN11 ADF Not Working mean?
Remove jammed documents, clean ADF rollers, load documents correctly, and inspect roller wear or damage.
What does CAN-SCN12 System Reset Required mean?
Power off scanner, wait 30–60 seconds, restart system, and test scanner functionality.
What does CAN-SCN13 Communication Failure mean?
Check USB or network cable, restart scanner and computer, try another port, and update firmware if needed.
What does CAN-SCN14 Overheating Warning mean?
Turn off scanner, allow cooling, clean vents, and ensure proper ventilation around device.
What does CAN-SCN15 Power Failure mean?
Check power cable, test outlet, inspect adapter, and replace power supply if needed.
What does CAN-SCN16 Firmware Error mean?
Update firmware, reset scanner settings, reinstall firmware, and restart device.
What does CAN-SCN17 Image Quality Issue mean?
Clean scanner glass, adjust scan resolution, improve lighting, and ensure proper document alignment.
What does CAN-SCN18 Network Connection Lost mean?
Restart router, reconnect Wi-Fi, check network stability, and update network settings.
What does CAN-SCN19 General System Failure mean?
Restart scanner, unplug power for 30–60 seconds, check internal cables, and contact Canon support if issue persists.
What does CAN-SCN20 Maintenance Required mean?
Clean scanner glass, inspect rollers, run calibration, and perform maintenance service if needed.
Important: Always disconnect power before performing repairs. Contact a qualified technician if the issue persists.
