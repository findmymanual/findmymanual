Haier Washing Machine Error Codes

Complete Troubleshooting & Repair Guide

Door System Errors
ERR1
Door Lock Error
  • Check door latch alignment.
  • Inspect door lock wiring connection.
  • Ensure door is fully closed.
  • Replace door lock assembly if faulty.
Drainage Errors
ERR2
Drainage Problem
  • Clean drain pump filter.
  • Check drain hose for blockage or kinks.
  • Inspect pump motor operation.
  • Replace pump if not working.
Sensor & Water Level Errors
ERR3
Temperature Sensor Fault
  • Inspect thermistor wiring connection.
  • Test sensor resistance.
  • Check control board input.
  • Replace sensor if faulty.
ERR8
Water Level Protection Activated
  • Check inlet valve for blockage.
  • Inspect pressure sensor tube.
  • Ensure proper drainage system.
  • Reset machine after inspection.
EUAR
Water Level Sensor Error
  • Inspect pressure switch wiring.
  • Clean air trap hose.
  • Test sensor continuity.
  • Replace sensor if needed.
Heating System Errors
ERR4
Heating Error
  • Check heating element continuity.
  • Inspect wiring harness.
  • Verify control board output.
  • Replace heater if faulty.
Water Supply & Overflow Errors
ERR5
Water Overflow Detected
  • Check inlet valve for stuck open condition.
  • Inspect water pressure level.
  • Ensure pressure sensor is working.
  • Replace valve if necessary.
NO WATER
No Water Supply Detected
  • Check water tap is open.
  • Inspect inlet hose for blockage.
  • Clean inlet filter screen.
  • Verify household water pressure.
Motor System Errors
ERR6
Motor Malfunction
  • Inspect motor wiring connections.
  • Check drum for blockage.
  • Test motor resistance.
  • Replace motor if faulty.
ERR7
Motor Drive Communication Failure
  • Inspect inverter board wiring.
  • Check control board communication line.
  • Restart system after power reset.
  • Replace PCB if needed.
System Errors
ERR9
EEPROM Communication Error
  • Reset machine power for 10 minutes.
  • Inspect main control board.
  • Check for firmware corruption.
  • Replace PCB if error persists.
UNB
Unbalanced Laundry Load
  • Redistribute clothes evenly.
  • Reduce heavy load size.
  • Check drum suspension system.
  • Restart spin cycle.
Important: If the error continues after troubleshooting, disconnect power immediately and contact a qualified technician.
