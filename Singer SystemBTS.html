Singer System Messages

Meaning & Quick Troubleshooting Guide

Status Messages
READY
Ready for Sewing
  • Machine is ready for operation.
  • No action required.
  • Start sewing normally.
STOP
Machine Stopped
  • Check if machine was paused manually.
  • Inspect fabric and needle area.
  • Resume operation when safe.
System Control Messages
RESET
Restart Required
  • Turn machine off completely.
  • Wait a few seconds before restarting.
  • Check if message clears after reboot.
LOCK
Safety Lock Active
  • Disable safety lock via control panel.
  • Ensure covers and panels are closed.
  • Confirm machine is properly secured.
Thread & Bobbin Messages
THREAD
Threading Required
  • Re-thread upper thread correctly.
  • Follow threading guide on machine.
  • Ensure proper tension path is used.
NO BOBBIN
Bobbin Not Installed
  • Insert bobbin properly into case.
  • Check correct bobbin orientation.
  • Clean bobbin sensor area if needed.
Important: Regular maintenance helps prevent most sewing interruptions and system alerts.
