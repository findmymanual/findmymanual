Janome System Messages

Meaning & Quick Troubleshooting Guide

Status Messages
READY
Machine Ready for Sewing
  • Machine is ready for normal operation.
  • No action required.
  • Begin sewing as needed.
STOP
Operation Halted
  • Check if machine was paused manually.
  • Inspect fabric or needle for obstruction.
  • Restart operation when ready.
System Control Messages
RESET
System Restart Required
  • Turn machine off completely.
  • Wait a few seconds before restarting.
  • Check if error clears after reboot.
LOCK
Safety Lock Active
  • Deactivate safety lock via control panel.
  • Check machine cover and safety switches.
  • Ensure all parts are properly closed.
Thread & Bobbin Messages
THREAD
Threading Required
  • Re-thread upper thread correctly.
  • Follow threading guide on machine.
  • Ensure thread passes through all tension points.
NO BOBBIN
Bobbin Not Detected
  • Insert bobbin properly into case.
  • Check bobbin orientation.
  • Clean bobbin sensor area.
Important: Regular maintenance of thread path and bobbin area helps prevent most operational interruptions.
