Sub-Zero Refrigerator / Freezer Error Codes

Complete Troubleshooting & Diagnostic Guide

Compressor System Errors
EC40
Compressor Not Running
  • Check power supply and breaker.
  • Inspect compressor relay and start capacitor.
  • Verify control board output signal.
  • Replace compressor components if needed.
Fan System Errors
EC50
Condenser Fan Failure
  • Clean condenser coil and fan blades.
  • Check fan motor wiring connections.
  • Test fan motor operation.
  • Replace fan motor if defective.
EC51
Evaporator Fan Error
  • Inspect fan for ice buildup or blockage.
  • Check wiring harness connections.
  • Test fan motor resistance and operation.
  • Replace evaporator fan motor if faulty.
Defrost System Errors
EC52
Defrost System Failure
  • Check defrost heater continuity.
  • Inspect defrost timer or control board.
  • Verify sensor operation.
  • Replace defective defrost components.
Sensor & Temperature Errors
EC53
Temperature Sensor Fault
  • Inspect thermistor wiring and connectors.
  • Test resistance at room temperature.
  • Check for moisture or corrosion damage.
  • Replace sensor if readings are incorrect.
Door System Errors
EC54
Door Switch Error
  • Ensure door closes and seals properly.
  • Inspect door switch alignment.
  • Test switch continuity.
  • Replace switch if faulty.
Communication Errors
EC55
Main Board Communication Failure
  • Inspect wiring between control boards.
  • Check connectors for corrosion or looseness.
  • Perform full power reset.
  • Replace main PCB if issue persists.
Temperature & Alarm Errors
EC56
High Temperature Alarm
  • Check door seal for leaks.
  • Verify condenser airflow is not blocked.
  • Ensure compressor is operating correctly.
  • Allow unit to stabilize after reset.
Power System Errors
EC57
Low Voltage Detected
  • Check household voltage supply stability.
  • Inspect power cord and outlet condition.
  • Use voltage stabilizer if needed.
  • Reset appliance after correction.
Ice Maker System Errors
EC58
Ice Maker System Fault
  • Check water supply line and valve.
  • Inspect ice maker module for blockage.
  • Verify wiring connections.
  • Replace ice maker assembly if needed.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified Sub-Zero technician.
