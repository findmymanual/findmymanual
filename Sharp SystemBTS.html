Sharp System Messages

Status Indicators & Meaning Guide

Control & Safety Messages
LOC
Child Lock Active
  • Press and hold lock/unlock button for a few seconds.
  • Refer to model-specific control panel instructions.
  • Perform a power reset if lock does not clear.
  • Ensure no buttons are stuck.
PF
Power Failure Detected
  • Check household power supply.
  • Inspect circuit breaker or fuse box.
  • Reset appliance after power stabilizes.
  • Ensure stable voltage supply.
Warning Messages
HOT
Overheat Warning
  • Turn off appliance and allow cooling.
  • Check ventilation openings for blockage.
  • Ensure fan system is working properly.
  • Restart after temperature normalizes.
ERR
General System Error
  • Power cycle the appliance.
  • Check for visible wiring or control issues.
  • Reset system using restart option.
  • Call technician if error persists.
System Status Messages
RESET
System Restart Required
  • Disconnect power for a few minutes.
  • Reconnect and restart appliance.
  • Check if message returns.
  • Inspect control board if persistent.
COOL
Cooling Cycle Active
  • Allow appliance to complete cooling cycle.
  • Do not open doors unnecessarily.
  • Ensure airflow is not blocked.
  • Monitor temperature stabilization.
Note: These messages are status indicators and not always faults. Persistent errors may require technician inspection.
