Midea Air Conditioner Error Codes

Complete Troubleshooting & Diagnostic Guide

Communication Errors
E1
Indoor/Outdoor Communication Error
  • Turn off power and restart the system.
  • Inspect communication wiring between units.
  • Check connectors for corrosion or looseness.
  • Replace control board if communication fails.
E9
PCB Communication Error
  • Inspect main PCB wiring connections.
  • Power cycle the air conditioner.
  • Check for damaged communication cables.
  • Replace faulty PCB if needed.
Sensor Errors
E2
Indoor Coil Sensor Fault
  • Inspect indoor coil sensor wiring.
  • Test thermistor resistance values.
  • Check for loose connectors.
  • Replace sensor if readings are incorrect.
E3
Outdoor Coil Sensor Fault
  • Inspect outdoor sensor wiring.
  • Check sensor placement on coil.
  • Test resistance with multimeter.
  • Replace faulty outdoor sensor.
Compressor Protection Errors
E4
Compressor Overload Protection
  • Allow compressor to cool before restart.
  • Clean condenser coil for proper airflow.
  • Check refrigerant pressure levels.
  • Inspect compressor capacitor and relay.
E5
Overcurrent Protection Triggered
  • Check power supply voltage stability.
  • Inspect compressor current draw.
  • Verify electrical wiring condition.
  • Replace damaged electrical components.
Refrigerant System Errors
E6
Refrigerant Leakage Detected
  • Inspect refrigerant lines for leaks.
  • Check flare connections and valves.
  • Contact certified HVAC technician.
  • Recharge refrigerant after repair.
Fan System Errors
E7
Fan Motor Error
  • Inspect fan blades for obstruction.
  • Check motor wiring connections.
  • Test fan motor operation.
  • Replace fan motor if defective.
Memory & Control Errors
E8
EEPROM Failure
  • Power cycle the unit.
  • Inspect PCB for moisture or damage.
  • Check EEPROM communication lines.
  • Replace control board if fault persists.
System Protection Messages
EC
System Protection Mode Active
  • Allow unit to stabilize and cool down.
  • Check for airflow restrictions.
  • Inspect sensors and refrigerant levels.
  • Reset system after correcting issue.
Important: Refrigerant and compressor-related repairs should only be performed by a certified HVAC technician.
