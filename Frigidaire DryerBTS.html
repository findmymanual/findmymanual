Frigidaire Dryer Error Codes

Complete Troubleshooting & Repair Guide

Heating System Errors
E64
Heating Element Failure
  • Check heating element continuity.
  • Inspect wiring connections for burns or damage.
  • Test thermal fuse and high-limit thermostat.
  • Replace heating element if defective.
E66
Overheating Detected
  • Clean lint filter and exhaust vent.
  • Check airflow restriction in ducting.
  • Inspect thermal cutoff switch.
  • Allow unit to cool and reset system.
Sensor Errors
E65
Thermistor Fault
  • Check thermistor resistance with multimeter.
  • Inspect wiring harness for damage.
  • Ensure proper connection to control board.
  • Replace thermistor if readings are abnormal.
Control System Errors
E68
Control Board Failure
  • Reset power by unplugging for 5–10 minutes.
  • Inspect control board for burn marks.
  • Check wiring harness connections.
  • Replace main control board if needed.
Motor & Door System Errors
E71
Motor Relay Fault
  • Check motor relay on control board.
  • Inspect wiring to motor assembly.
  • Test relay switching function.
  • Replace control board if relay is faulty.
E72
Door Switch Error
  • Check door latch alignment.
  • Inspect door switch for damage or wear.
  • Test continuity of door switch.
  • Replace switch if defective.
Important: If the dryer continues showing errors after troubleshooting, disconnect power and contact a certified Frigidaire technician.
