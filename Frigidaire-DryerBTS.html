Frigidaire Dryer Error Codes

Complete Frigidaire Dryer Guide

This guide explains all Frigidaire Dryer error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

E64
Heating Element Failure
  • Check heating element continuity using a multimeter.
  • Inspect wiring connections for burns or damage.
  • Test thermal fuse and high-limit thermostat.
  • Replace heating element if defective.
E65
Thermistor Fault
  • Check thermistor resistance with a multimeter.
  • Inspect wiring harness for damage or looseness.
  • Ensure secure connection to control board.
  • Replace thermistor if readings are outside specification.
E66
Overheating Detected
  • Clean lint filter and exhaust vent system thoroughly.
  • Check airflow restrictions in ducting or vent hose.
  • Inspect thermal cutoff switch and safety thermostat.
  • Allow unit to cool before restarting.
E68
Control Board Failure
  • Unplug dryer for 5–10 minutes to reset system.
  • Inspect control board for burn marks or damage.
  • Check wiring harness connections.
  • Replace main control board if fault persists.
E71
Motor Relay Fault
  • Inspect motor relay on control board.
  • Check wiring connections to motor assembly.
  • Test relay switching operation.
  • Replace control board if relay is defective.
E72
Door Switch Error
  • Check door latch alignment and condition.
  • Inspect door switch for wear or damage.
  • Test switch continuity using a multimeter.
  • Replace door switch if faulty.
E73
Temperature Sensor Error
  • Check temperature sensor resistance values.
  • Inspect wiring harness for damage or corrosion.
  • Verify secure connection to control board.
  • Replace sensor if readings are incorrect.
E74
Temperature Mismatch Error
  • Verify correct sensor type is installed.
  • Inspect wiring connections for faults.
  • Test all temperature sensors for consistency.
  • Replace sensor or control board if mismatch persists.
E82
User Interface Communication Error
  • Reset dryer power supply.
  • Inspect display panel wiring connections.
  • Check ribbon cable between UI and control board.
  • Replace interface board if communication fails.
E91
Main Board Communication Failure
  • Inspect communication wiring harness.
  • Check connectors for corrosion or looseness.
  • Restart appliance and retest system.
  • Replace control board if failure continues.
E92
Configuration Error
  • Verify appliance configuration settings.
  • Reset control system if available.
  • Check software/programming data.
  • Reprogram or replace control board if needed.
E93
EEPROM Memory Error
  • Disconnect power and restart dryer.
  • Inspect control board connections.
  • Check PCB for damage or corrosion.
  • Replace control board if memory error persists.
E5A
Motor Overheat Protection
  • Allow dryer to cool completely.
  • Check ventilation and airflow system.
  • Inspect motor and control board condition.
  • Replace motor control module if needed.
E5B
Low Voltage Supply
  • Check household voltage supply stability.
  • Inspect power cord and outlet connection.
  • Avoid using extension cords.
  • Contact electrician if voltage remains low.
E5C
High Voltage Supply
  • Measure outlet voltage with a tester.
  • Inspect electrical installation for faults.
  • Disconnect appliance until voltage stabilizes.
  • Call a qualified electrician if needed.
E41
Door Not Closed
  • Ensure dryer door is fully closed and latched.
  • Inspect door seal and latch mechanism.
  • Check for clothing blocking closure.
  • Replace door latch if damaged.
E51
Motor Triac Fault
  • Inspect control board triac components.
  • Check motor wiring connections.
  • Test motor resistance and operation.
  • Replace control board if triac is faulty.
E52
No Motor Signal Detected
  • Check motor tachometer wiring.
  • Inspect drive motor connections.
  • Test motor operation manually.
  • Replace motor if signal is not detected.
F21 / E21
Motor Failure / Drum Jam
  • Check drum for blockage.
  • Inspect motor and belt system.
  • Remove load imbalance.
  • Replace motor if needed.

Frequently Asked Questions


What does E10 Airflow Restriction / Lint Blockage mean?
Clean lint filter thoroughly, check exhaust vent for blockage or kinks, inspect internal ducting for lint buildup, and ensure proper airflow before restarting the dryer.
What does E11 Reduced Airflow Detection mean?
Check vent hose for obstruction or collapse, clean lint trap and housing area, ensure exhaust outlet is not blocked, and run the dryer again after airflow is restored.
What does E12 Overheating / Thermal Protection Triggered mean?
Clean lint filter and vent system, allow dryer to cool completely, check thermostat and thermal fuse, and inspect airflow for restrictions.
What does E20 Condensation Drain Blockage mean?
Check condensate drain hose for clogs, inspect water container (if applicable), clean pump filter and drain path, and ensure proper water flow system operation.
What does E21 Condensate Pump Timeout mean?
Inspect drain pump for blockage, check pump wiring connections, clean internal water reservoir, and replace pump if drainage is slow or failed.
What does E22 Drain Pump Failure mean?
Test drain pump motor operation, check wiring and connectors, remove debris from pump housing, and replace pump if it does not run.
What does E30 Door Lock Error mean?
Ensure dryer door is fully closed, inspect door latch mechanism, check door switch wiring, and replace door lock assembly if faulty.
What does E31 Door Open During Cycle mean?
Close door properly and restart cycle, check door switch sensor function, inspect latch alignment, and replace switch if defective.
What does E40 Door Lock Failure mean?
Inspect door lock assembly for damage, check wiring connections, test lock engagement mechanism, and replace lock if it fails to engage.
What does E41 Door Switch Fault mean?
Test door switch continuity, inspect latch alignment, check wiring harness, and replace door switch if faulty.
What does E50 Motor Control Error mean?
Reset dryer power supply, inspect motor wiring connections, check control board output signals, and replace motor control board if needed.
What does E51 Motor Triac Fault mean?
Inspect control board for burnt components, test motor resistance and operation, check wiring harness condition, and replace control board if triac is faulty.
What does E60 Heating System Error mean?
Check heating element continuity, inspect thermostat and thermal fuse, test wiring connections, and replace heater assembly if faulty.
What does E61 Temperature Sensor Fault mean?
Test thermistor resistance, inspect wiring for damage or corrosion, check connection to control board, and replace sensor if readings are incorrect.
What does E62 Overheating Protection Triggered mean?
Clean lint filter and vent system, allow dryer to cool before restart, check airflow restrictions, and inspect thermal cutoff switch.
What does E90 Electronic Control Fault mean?
Reset power supply for 5–10 minutes, inspect control board connections, check for moisture or corrosion on the PCB, and replace the main control board if the error continues.
Important: Always disconnect power before attempting repairs. If the issue continues, contact a qualified Electrolux service technician.
