Canon Camera Error Codes

Complete Canon Camera Guide

This guide explains all Canon Camera error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

READY
Canon Camera Ready Status
  • Camera is powered on and ready for use.
  • No error detected in system.
  • You can start shooting normally.
  • Ensure lens and battery are properly installed.
ERR 01
Lens Communication Failure
  • Remove and reattach the lens securely.
  • Clean lens and body contacts gently.
  • Test with another compatible lens.
  • Inspect lens mount for damage or misalignment.
ERR 02
Memory Card Issue
  • Reinsert the memory card properly.
  • Format the SD card in camera settings.
  • Try a different compatible memory card.
  • Check if card is locked or corrupted.
ERR 05
Flash System Error
  • Turn camera off and restart.
  • Ensure flash is not overheated.
  • Check if flash is obstructed or stuck.
  • Update firmware if issue persists.
ERR 06
Sensor Malfunction
  • Power cycle the camera.
  • Clean sensor area carefully.
  • Check for dust or debris inside body.
  • Seek service if issue continues.
ERR 10
File System Error
  • Format memory card in camera.
  • Backup and remove corrupted files.
  • Try another SD card.
  • Reset camera settings if needed.
ERR 20
Mechanical Shutter Failure
  • Restart the camera.
  • Check for physical shutter obstruction.
  • Test shutter in different modes.
  • Service shutter mechanism if needed.
ERR 30
Internal System Fault
  • Restart camera completely.
  • Remove battery and memory card.
  • Update firmware to latest version.
  • Send for professional repair if unresolved.
ERR 40
Power System Error
  • Check battery charge level.
  • Clean battery contacts.
  • Try a different battery.
  • Inspect power circuit for faults.
ERR 50
Communication Fault (Main Board)
  • Restart the camera.
  • Check internal flex cables.
  • Update firmware if available.
  • Service main board if needed.
ERR 60
Autofocus Failure
  • Clean lens contacts.
  • Test with another lens.
  • Check autofocus motor operation.
  • Service lens if autofocus is stuck.
ERR 70
Image Processing Error
  • Restart the camera.
  • Reset camera settings.
  • Update firmware.
  • Service image processor if needed.
ERR 80
Electrical System Fault
  • Remove battery and restart.
  • Inspect internal wiring.
  • Check for moisture damage.
  • Service main board.
ERR 90
Shutter Curtain Jam
  • Power cycle the camera.
  • Check shutter movement for obstruction.
  • Remove lens and inspect mirror box.
  • Service shutter assembly if needed.
ERR 99
Unknown System Error
  • Restart camera.
  • Remove battery and memory card.
  • Clean all contacts.
  • Seek professional service.
ERR 100
Memory Card Write Failure
  • Reformat or replace SD card.
  • Check write protection switch.
  • Test another memory card.
  • Update camera firmware.
ERR 101
Lens Aperture Control Fault
  • Reattach lens securely.
  • Clean lens contacts.
  • Test aperture movement.
  • Service lens if aperture is stuck.
ERR 102
Image Buffer Overflow
  • Use faster SD card (UHS-I/UHS-II).
  • Reduce burst shooting mode.
  • Clear storage space.
  • Reset camera settings.
ERR 103
Autofocus Sensor Misalignment
  • Clean AF sensor area.
  • Test with different lens.
  • Reset autofocus settings.
  • Calibrate or service AF module.
ERR 104
Firmware Corruption
  • Reinstall firmware update.
  • Use official Canon firmware tool.
  • Remove battery during reset process.
  • Send for service if unresolved.
ERR 120
Internal Temperature Overload
  • Turn off camera and let it cool.
  • Avoid long video recording sessions.
  • Remove battery temporarily.
  • Ensure proper ventilation.
ERR 130
HDMI Output Failure
  • Disconnect HDMI cable.
  • Restart camera.
  • Try another HDMI cable.
  • Inspect HDMI port for damage.
ERR 140
Firmware Conflict
  • Reset camera settings.
  • Update to latest firmware version.
  • Remove external accessories.
  • Perform factory reset if needed.
FAQ
Canon Camera System Questions
  • Check battery if camera does not turn on.
  • Format SD card if errors occur.
  • Clean lens for blurry photos.
  • Update firmware for performance issues.

Frequently Asked Questions


What does SCN01 Canon Camera Not Ready mean?
Check battery installation, ensure lens is properly attached, restart the camera, and verify no system errors are active.
What does SCN02 Blank Image Capture Detected mean?
Ensure lens cap is removed, check exposure settings, clean lens, and verify correct shooting mode is selected.
What does SCN03 Device Offline / Not Responding mean?
Check USB or Wi-Fi connection, restart camera and device, and ensure proper connection to PC or app.
What does SCN04 Wi-Fi Connection Failure mean?
Verify network credentials, restart camera and router, move closer to Wi-Fi source, and update firmware if needed.
What does SCN05 Poor Image Quality Detected mean?
Clean lens, adjust ISO and exposure settings, stabilize camera, and check focus mode.
What does SCN06 Image Noise / Streak Error mean?
Clean lens and sensor area, reduce ISO, check lighting conditions, and ensure sensor is not dusty.
What does SCN07 Memory Card Error Detected mean?
Reinsert memory card, format card in camera, try another SD card, and check compatibility.
What does SCN08 Multi-Shot Buffer Full mean?
Wait for buffer to clear, use faster SD card, reduce burst shooting, and free up storage space.
What does SCN09 Mechanical Noise Warning mean?
Remove lens, check for debris, inspect shutter mechanism, and avoid forcing moving parts.
What does SCN10 Camera Not Detected mean?
Check USB cable, reinstall drivers, try different port, and restart computer and camera.
What does SCN11 Blurry Image Output mean?
Clean lens, adjust focus settings, stabilize camera, and increase shutter speed.
What does SCN12 System Error mean?
Restart camera, remove battery, reinstall firmware, and check for hardware issues.
What does SCN13 PC Connection Failure mean?
Check USB cable, reinstall drivers, disable firewall blocking, and restart computer.
What does SCN14 Slow Performance mean?
Use faster SD card, reduce resolution settings, close background apps, and restart camera.
What does SCN15 File Save Error mean?
Check storage space, format memory card, verify save settings, and try another card.
What does SCN16 Connection Instability mean?
Replace USB cable, check Wi-Fi stability, update firmware, and reset network settings.
What does SCN17 Capture Interrupted mean?
Check battery level, ensure no overheating, restart camera, and avoid interrupting shooting process.
What does SCN18 General System Failure mean?
Restart camera, remove battery and memory card, update firmware, and seek service if needed.
What does SCN19 Overheating Alert mean?
Turn off camera, allow cooling, avoid long video recording, and ensure proper ventilation.
What does SCN20 Restart Loop Detected mean?
Check battery, update firmware, reset camera settings, and inspect internal components.
What does SCN21 Power Failure mean?
Check battery charge, clean contacts, try another battery, and inspect power circuit.
What does SCN22 Network Connection Lost mean?
Restart camera, reconnect Wi-Fi, check router, and update network settings.
What does SCN23 System Reset Required mean?
Power off camera, wait 30–60 seconds, restart system, and test functionality.
What does SCN24 Memory Overflow Error mean?
Clear memory card, reduce image size, restart camera, and free storage space.
What does SCN25 Maintenance Required mean?
Clean lens and sensor, check for dust buildup, run calibration, and service camera if needed.
Important: Always disconnect power before performing repairs. Contact a qualified technician if the issue persists.
