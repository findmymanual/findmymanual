Canon Camera Error Codes

Diagnostic & Troubleshooting Guide

Lens & Communication Errors
Err 01
Lens Communication Failure
  • Remove and reattach lens securely.
  • Clean lens contacts gently.
  • Test with another compatible lens.
  • Inspect lens mount for damage.
Memory System Errors
Err 02
Memory Card Issue
  • Reinsert memory card properly.
  • Format card in camera menu.
  • Try a different SD card.
  • Check card compatibility and speed.
Flash System Errors
Err 05
Flash System Error
  • Turn off camera and restart.
  • Check built-in or external flash unit.
  • Ensure flash is not overheated.
  • Service flash circuit if needed.
Sensor Errors
Err 06
Sensor Malfunction
  • Power cycle camera.
  • Remove lens and inspect sensor area.
  • Update firmware if available.
  • Service sensor module if issue persists.
File System Errors
Err 10
File System Error
  • Format memory card in camera.
  • Backup and replace corrupted files.
  • Try another SD card.
  • Reset camera settings if needed.
Mechanical System Errors
Err 20
Mechanical Shutter Failure
  • Power cycle the camera.
  • Check for physical obstruction.
  • Test shutter in different modes.
  • Service shutter mechanism if faulty.
Internal System Errors
Err 30
Internal Camera Fault
  • Restart camera.
  • Remove battery and memory card.
  • Update firmware.
  • Send for professional repair if persistent.
Power System Errors
Err 40
Power System Error
  • Check battery condition and charge.
  • Clean battery contacts.
  • Try a different battery.
  • Inspect power circuit if issue continues.
Important: Internal sensor, shutter, and power faults may require professional Canon service.
