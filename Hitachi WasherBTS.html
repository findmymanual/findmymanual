Hitachi Washer Error Codes

Complete Troubleshooting & Diagnostic Guide

Water Supply Errors
C01
Water Supply Issue
  • Ensure water faucet is fully open.
  • Inspect inlet hose for kinks or blockage.
  • Clean inlet filter screen.
  • Test water inlet valve operation.
Drain System Errors
C02
Drain Error
  • Check drain hose for blockage or bending.
  • Clean pump filter and drain trap.
  • Inspect drain pump operation.
  • Replace pump if defective.
Door System Errors
C03
Door Lock Failure
  • Ensure door is fully closed.
  • Inspect door latch and strike mechanism.
  • Check wiring to door lock assembly.
  • Replace door lock if faulty.
Motor System Errors
C04
Motor Error
  • Check motor wiring connections.
  • Inspect drum for free movement.
  • Test motor resistance and operation.
  • Replace motor or control board if needed.
Water Level Errors
C05
Water Overflow Detected
  • Turn off water supply immediately.
  • Inspect pressure sensor and hose.
  • Check inlet valve for stuck open condition.
  • Replace faulty water level components.
Sensor Errors
C06
Temperature Sensor Fault
  • Inspect thermistor wiring connections.
  • Test sensor resistance values.
  • Check for moisture or corrosion.
  • Replace sensor if readings are incorrect.
Heating System Errors
C07
Heater Error
  • Test heating element continuity.
  • Inspect heater wiring and connectors.
  • Check thermal fuse condition.
  • Replace heating element if faulty.
Important: If the error persists after troubleshooting, disconnect power and contact a qualified technician.
