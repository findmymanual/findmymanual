Whirlpool Dryer Error Codes

Complete Troubleshooting & Repair Guide

Airflow & Ventilation Errors
AF
Airflow Restriction Detected
  • Check lint filter and clean it.
  • Inspect exhaust vent for blockage.
  • Ensure hose is not kinked or crushed.
  • Clean internal airflow passages.
F30
Restricted Airflow
  • Remove lint buildup from filter.
  • Check external vent cap for blockage.
  • Inspect blower wheel condition.
  • Ensure proper ventilation path.
Power System Errors
PF
Power Failure During Cycle
  • Check power outlet stability.
  • Inspect plug and cord connection.
  • Reset breaker if tripped.
  • Restart dryer cycle.
F31
Low Voltage Detected
  • Verify household voltage supply.
  • Avoid using extension cords.
  • Check wiring connections.
  • Contact electrician if issue persists.
Control Board & Communication Errors
F01
Main Electronic Control Fault
  • Reset dryer power for 10 minutes.
  • Inspect control board for damage.
  • Check wiring harness connections.
  • Replace control board if necessary.
F70
Communication Failure Between Boards
  • Check wiring between UI and main board.
  • Inspect connectors for corrosion.
  • Restart system power.
  • Replace PCB if fault continues.
F71
User Interface Communication Error
  • Inspect keypad ribbon cable.
  • Check UI board connections.
  • Reset dryer system.
  • Replace UI panel if needed.
F02
User Interface Keypad Issue
  • Clean control panel surface.
  • Check for stuck buttons.
  • Inspect ribbon cable connection.
  • Replace keypad assembly if needed.
Heating System Errors
F20
Heater Relay Problem
  • Inspect heating relay on control board.
  • Check wiring to heating element.
  • Test heater continuity.
  • Replace relay if faulty.
Temperature & Moisture Sensor Errors
F22
Outlet Thermistor Open
  • Check outlet thermistor wiring.
  • Test sensor resistance.
  • Inspect connector pins.
  • Replace thermistor if needed.
F23
Outlet Thermistor Shorted
  • Inspect thermistor wiring for short circuit.
  • Replace damaged sensor.
  • Check moisture damage near sensor.
F24
Inlet Thermistor Fault
  • Inspect inlet temperature sensor.
  • Check wiring harness.
  • Test resistance values.
  • Replace sensor if faulty.
F25
Inlet Thermistor Shorted
  • Check wiring for short circuit.
  • Inspect connector damage.
  • Replace thermistor if needed.
F28
Moisture Sensor Failure
  • Clean moisture sensor bars.
  • Check wiring connections.
  • Test sensor response.
  • Replace sensor if required.
F29
Moisture Sensor Shorted
  • Inspect sensor wiring.
  • Check for moisture damage.
  • Replace sensor assembly.
System & Lock Errors
LOC
Control Lock Enabled
  • Press and hold control lock button for 3–5 seconds.
  • Check user manual for unlock sequence.
  • Reset power if panel is frozen.
Important: If the dryer continues to show errors after troubleshooting, disconnect power and contact a qualified technician.
