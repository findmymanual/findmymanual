Sharp Air Conditioner Error Codes

Complete Diagnostic & Troubleshooting Guide

Communication Errors
E0
Indoor/Outdoor Communication Error
  • Turn off power and restart system.
  • Inspect indoor-to-outdoor wiring connections.
  • Check communication cable for damage.
  • Replace PCB if communication fails.
E8
Communication Fault (PCB)
  • Power cycle the air conditioner.
  • Inspect PCB connectors and wiring harness.
  • Check for loose or corroded terminals.
  • Replace faulty control board if needed.
Sensor Errors
E1
Indoor Sensor Fault
  • Inspect room temperature sensor wiring.
  • Test thermistor resistance values.
  • Check for moisture or corrosion.
  • Replace indoor sensor if defective.
E2
Outdoor Sensor Fault
  • Inspect outdoor sensor connections.
  • Check sensor placement and wiring.
  • Measure resistance with multimeter.
  • Replace faulty outdoor sensor.
Compressor Protection Errors
E3
Compressor Overload
  • Allow compressor to cool down.
  • Check refrigerant pressure levels.
  • Clean condenser coils for proper airflow.
  • Inspect compressor relay and capacitor.
Fan System Errors
E4
Fan Motor Error
  • Inspect fan blades for obstruction.
  • Check fan motor wiring connections.
  • Test fan motor operation.
  • Replace motor if malfunctioning.
Memory & Control Errors
E5
EEPROM Failure
  • Disconnect power and restart unit.
  • Inspect PCB for visible damage.
  • Check memory IC connections.
  • Replace main control board if needed.
Refrigerant System Errors
E6
Refrigerant Issue
  • Inspect for refrigerant leaks.
  • Check system pressure levels.
  • Ensure proper cooling performance.
  • Recharge refrigerant if necessary.
Electrical Protection Errors
E7
Overcurrent Protection
  • Check voltage stability.
  • Inspect compressor current draw.
  • Examine wiring for shorts or damage.
  • Reset system after correcting issue.
Important: Electrical and refrigerant repairs should only be performed by a certified HVAC technician.
