Maytag Microwave Error Codes

Complete Troubleshooting & Repair Guide

Control Panel Errors
F1
Touch Pad Shorted
  • Disconnect power for 5 minutes.
  • Clean control panel surface from moisture or grease.
  • Inspect ribbon cable connection to control board.
  • Replace touch pad or keypad assembly if faulty.
SE
Keypad Communication Error
  • Check keypad ribbon cable connection.
  • Inspect for stuck or damaged buttons.
  • Reset microwave power supply.
  • Replace control panel if communication fails.
Temperature & Sensor Errors
F2
Oven Cavity Overheating
  • Allow microwave to cool completely.
  • Check ventilation openings for blockage.
  • Inspect thermal sensor and thermostat.
  • Replace thermal cutoff or sensor if needed.
F3
Humidity Sensor Failure
  • Inspect humidity sensor wiring.
  • Clean interior cavity of moisture buildup.
  • Check sensor connector pins.
  • Replace humidity sensor if faulty.
Power & Cooking System Errors
F6
Microwave Relay Issue
  • Reset microwave by unplugging for 5 minutes.
  • Inspect relay on control board for damage.
  • Check wiring connections to magnetron circuit.
  • Replace control board or relay if necessary.
Important: If the error persists after troubleshooting, disconnect power immediately and contact a certified Maytag technician.
