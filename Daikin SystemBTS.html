Daikin System Messages

Status & Operation Indicators Guide

Operation Cycle Messages
DEFROST
Defrost Cycle Active
  • Unit is automatically removing ice buildup.
  • No action required during cycle.
  • Normal operation will resume shortly.
Control System Messages
LOCK
Control Lock Enabled
  • Child lock or safety lock is active.
  • Disable lock via remote or control panel.
  • Ensure correct settings before operation.
RESET
System Restart Required
  • Turn unit off completely.
  • Wait 1–2 minutes before restarting.
  • Check if message clears after reboot.
Protection Messages
OVERHEAT
Overheat Protection Triggered
  • Turn off unit immediately if needed.
  • Check airflow and filter condition.
  • Allow system to cool down.
  • Restart after temperature stabilizes.
Maintenance Messages
FILTER
Air Filter Needs Cleaning
  • Remove air filter carefully.
  • Clean dust and debris thoroughly.
  • Allow filter to dry before reinstalling.
  • Reset filter indicator after cleaning.
Power State Messages
STANDBY
Unit in Standby Mode
  • System is powered but not actively running.
  • Activate via remote or control panel.
  • Check timer or scheduling settings.
Important: These messages indicate normal operation states and maintenance alerts rather than critical faults.
