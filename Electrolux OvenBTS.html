Electrolux Oven Error Codes

Complete Electrolux Oven Guide

This guide explains all Electrolux Oven error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

F1
Electronic Control Board Failure
  • Disconnect power for 5–10 minutes.
  • Inspect control board for visible damage.
  • Check wiring harness connections.
  • Replace main control board if fault returns.
F2
Over-Temperature Condition
  • Turn off oven and allow it to cool completely.
  • Check temperature sensor operation.
  • Inspect heating relays for sticking.
  • Replace faulty components if overheating continues.
F3
Temperature Sensor Open Circuit
  • Inspect sensor wiring for disconnection.
  • Test sensor resistance with multimeter.
  • Check connector terminals for corrosion.
  • Replace temperature sensor if defective.
F4
Temperature Sensor Shorted
  • Inspect sensor wiring for damage.
  • Test resistance for short circuit.
  • Check wiring harness condition.
  • Replace sensor if shorted.
F5
Door Lock Failure
  • Inspect door latch alignment.
  • Check lock motor operation.
  • Ensure door closes properly.
  • Replace door lock assembly if faulty.
F6
Communication Fault
  • Reset appliance power.
  • Inspect wiring between modules.
  • Check connectors for looseness.
  • Replace control board if communication fails.
F7
Keypad Failure
  • Inspect keypad for stuck buttons.
  • Restart appliance after power reset.
  • Check ribbon cable connections.
  • Replace keypad assembly if needed.
F8
Cooling Fan Failure
  • Inspect cooling fan for obstruction.
  • Check fan motor wiring.
  • Test fan operation.
  • Replace fan if defective.
F9
Latch Motor Issue
  • Inspect latch mechanism for blockage.
  • Check motor wiring connections.
  • Test latch operation.
  • Replace motor if faulty.
F10
Runaway Temperature Detected
  • Turn off appliance immediately.
  • Check temperature sensor accuracy.
  • Inspect relay contacts.
  • Replace control board if overheating persists.
F11
Touch Panel Communication Error
  • Inspect touch panel wiring.
  • Check for moisture behind display.
  • Restart appliance.
  • Replace interface board if needed.
F13
EEPROM Memory Error
  • Disconnect power and restart oven.
  • Check control board connections.
  • Inspect PCB for damage.
  • Replace control board if memory fails.
F14
Configuration Error
  • Verify appliance settings.
  • Check software configuration.
  • Reset control system.
  • Reprogram or replace board if needed.
F20
Heating Element Failure
  • Test heating element continuity.
  • Inspect wiring for damage.
  • Check terminal connections.
  • Replace heating element if open.
F30
Probe Sensor Error
  • Reconnect temperature probe.
  • Inspect probe wiring.
  • Test resistance values.
  • Replace probe if faulty.
F31
Meat Probe Short Circuit
  • Inspect probe for damage.
  • Check connector for moisture.
  • Test for short circuit.
  • Replace probe if necessary.
F90
Door Lock System Failure
  • Inspect door lock assembly.
  • Check latch motor and switches.
  • Verify wiring integrity.
  • Replace lock components if faulty.
F95
Power Supply Error
  • Check incoming voltage supply.
  • Inspect power cord and terminals.
  • Verify circuit breaker condition.
  • Contact electrician if unstable.

Frequently Asked Questions


What does E10 Water Inlet / Filling Issue mean?
Check power supply stability, inspect internal water-related cooling components (if applicable), ensure proper installation, and restart the oven system.
What does E20 Oven Heating Failure mean?
Check heating element continuity, inspect wiring connections, verify thermostat operation, and replace heating element if faulty.
What does E24 Overheating Protection Activated mean?
Turn off oven and allow cooling, check temperature sensor accuracy, inspect ventilation system, and ensure no blockage around the oven cavity.
What does E30 Door Open / Door Lock Issue mean?
Ensure oven door is fully closed, check door latch alignment, inspect door switch, and remove any obstruction preventing closure.
What does E40 Door Lock Failure mean?
Inspect door lock mechanism, check wiring connections, test latch motor operation, and replace door lock assembly if needed.
What does E50 Fan Motor / Cooling System Fault mean?
Check cooling fan for obstruction, inspect wiring connections, test fan motor operation, and replace fan if defective.
What does E51 Control Relay Fault mean?
Inspect control board relay contacts, check wiring harness condition, test relay switching, and replace control board if needed.
What does E52 Signal Loss From Motor / Fan mean?
Check motor or fan wiring connections, inspect tachometer signal, test feedback circuit, and replace motor if signal is missing.
What does E56 Heating System Failure mean?
Check heating element, inspect thermostat wiring, test control board output, and replace heating component if faulty.
What does E60 Overheating / Temperature Fault mean?
Clean oven ventilation system, check temperature sensor, ensure proper airflow, allow oven to cool before restarting.
What does E61 Temperature Sensor Fault mean?
Inspect temperature sensor wiring, test resistance values, check connector condition, and replace sensor if faulty.
What does E63 Cooking Performance Issue mean?
Check heating elements, ensure proper preheating, avoid overcrowding oven cavity, and verify correct cooking mode selection.
What does E66 Airflow Restriction / Ventilation Issue mean?
Clean ventilation openings, check cooling fan operation, ensure proper installation clearance, and remove obstructions around oven.
What does E68 Control Board Fault mean?
Restart power supply, inspect control board for damage, check wiring connections, and replace PCB if fault persists.
What does E70 Communication Error mean?
Check wiring between control modules, inspect connectors, restart oven system, and replace control board if communication fails.
What does E90 Configuration / Software Error mean?
Reset oven power, verify configuration settings, check programming data, and reprogram or replace control board if needed.
What does E91 Memory / EEPROM Fault mean?
Disconnect power and restart oven, inspect control board connections, check for PCB damage, and replace board if memory failure persists.
What does E93 System Internal Fault mean?
Restart oven system, check wiring harness condition, inspect control board, and replace board if error continues.
Important: Always disconnect power before attempting repairs. If the issue continues, contact a qualified Electrolux service technician.
