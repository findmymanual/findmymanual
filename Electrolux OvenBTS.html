Electrolux Oven / Range Error Codes

Complete Troubleshooting & Repair Guide

Control System Errors
F1
Control Board Failure
  • Reset power by unplugging unit for 5–10 minutes.
  • Inspect control board for burn marks or damage.
  • Check wiring harness connections.
  • Replace main control board if fault persists.
Temperature Errors
F2
Over-Temperature Condition
  • Turn off oven and allow it to cool.
  • Check temperature sensor functionality.
  • Inspect relay or heating element stuck ON.
  • Replace control board if overheating continues.
F3
Temperature Sensor Open
  • Check sensor wiring for disconnection.
  • Test sensor resistance with multimeter.
  • Inspect connector pins for corrosion.
  • Replace temperature sensor if open circuit.
F4
Temperature Sensor Shorted
  • Inspect sensor wiring for damage.
  • Test resistance for short circuit.
  • Check connector harness condition.
  • Replace sensor if shorted.
Door & Safety System Errors
F5
Door Lock Failure
  • Check door latch alignment.
  • Inspect lock motor and wiring.
  • Ensure door closes fully.
  • Replace door lock assembly if needed.
F9
Latch Motor Issue
  • Inspect latch motor for obstruction.
  • Check wiring harness connections.
  • Test motor operation.
  • Replace latch motor if faulty.
Communication Errors
F6
Communication Fault
  • Reset appliance power.
  • Inspect wiring between control modules.
  • Check for loose or corroded connectors.
  • Replace main PCB if communication fails.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified Electrolux technician.
