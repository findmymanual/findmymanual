Frigidaire System Messages Error Codes

Complete Frigidaire System Messages Guide

This guide explains all Frigidaire System Messages error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

COMM ERROR
Communication Error Between Control Boards
  • Power cycle the refrigerator for 5–10 minutes.
  • Inspect wiring between main and UI control boards.
  • Check for loose or corroded connectors.
  • Replace main PCB if communication fails.
MAIN COMM FAIL
Main Control Communication Failure
  • Reset refrigerator power supply.
  • Inspect main control board connections.
  • Test wiring harness continuity between modules.
  • Replace control board if error persists.
CONDENSER FAN ERROR
Condenser Fan Failure
  • Remove dust and debris from condenser fan area.
  • Check fan blade for obstruction or damage.
  • Inspect fan motor wiring and voltage supply.
  • Replace condenser fan motor if not running.
EVAP FAN ERROR
Evaporator Fan Failure
  • Check evaporator fan for ice buildup or blockage.
  • Inspect fan motor and wiring connections.
  • Defrost unit if ice is blocking airflow.
  • Replace evaporator fan motor if faulty.
EVAP FAN CIRCUIT
Evaporator Fan Circuit Error
  • Inspect evaporator fan wiring harness.
  • Check control board output voltage.
  • Look for moisture or corrosion near fan circuit.
  • Replace fan motor or control board if needed.
FREEZER SENSOR
Freezer Sensor Fault
  • Test freezer thermistor resistance with multimeter.
  • Check sensor wiring for damage or looseness.
  • Ensure correct sensor placement inside freezer.
  • Replace sensor if readings are abnormal.
HUMIDITY SENSOR
Shorted Humidity Sensor
  • Inspect humidity sensor wiring connections.
  • Check for moisture or water intrusion.
  • Test sensor resistance using a multimeter.
  • Replace humidity sensor if shorted.
COMP FAN ERROR
Compressor Fan Issue
  • Remove dust and debris around compressor fan.
  • Inspect fan motor wiring and capacitor (if applicable).
  • Ensure proper ventilation around compressor area.
  • Replace compressor fan motor if faulty.
DOOR OPEN
Door Open Alert
  • Ensure refrigerator door is fully closed.
  • Inspect door gasket for dirt or damage.
  • Remove any obstruction preventing sealing.
  • Test door switch for proper operation.
DEFROST FAIL
Defrost System Failure
  • Check defrost heater continuity.
  • Inspect defrost thermostat and wiring.
  • Verify control board defrost cycle activation.
  • Replace heater or control board if needed.
DEFROST HEATER
Defrost Heater Fault
  • Test defrost heater resistance.
  • Inspect wiring harness for breaks or corrosion.
  • Check for ice buildup in evaporator area.
  • Replace heater if no continuity is found.
TEMP SENSOR
Temperature Sensor Error
  • Check thermistor resistance values.
  • Inspect wiring for damage or loose connections.
  • Ensure sensor is properly positioned.
  • Replace sensor if readings are unstable.
LOW TEMP WARNING
Low Temperature Warning
  • Check temperature settings on control panel.
  • Inspect thermostat and sensor operation.
  • Ensure door seals are tight and intact.
  • Allow system to stabilize after adjustment.
HIGH TEMP WARNING
High Temperature Warning
  • Check for door left open or poor sealing.
  • Inspect condenser coils for dust buildup.
  • Verify evaporator fan is operating.
  • Allow unit to cool after resolving issue.
POWER FAILURE
Power Failure Detected
  • Check household power supply and circuit breaker.
  • Reset refrigerator by unplugging for 5 minutes.
  • Verify outlet stability and voltage.
  • Restore settings after reboot.
SYSTEM ERROR
General System Error
  • Perform full power reset of refrigerator.
  • Check all wiring harness connections.
  • Inspect control board for damage or corrosion.
  • Replace main PCB if error persists.

Frequently Asked Questions


What do Frigidaire system messages mean?
They are built-in alerts that indicate a fault, status, or operating condition in the appliance. Each code or message helps identify issues with power, sensors, fans, water flow, or control systems.
Why does my Frigidaire system message keep appearing?
It usually means the underlying issue has not been fully resolved. Check power, airflow, water supply, and sensors, then restart the appliance to see if the message clears.
How do I reset Frigidaire system messages?
Turn off the appliance, unplug it or switch off the breaker for 5–10 minutes, then restore power. This clears temporary errors and resets the control system.
Are Frigidaire system messages serious?
Some are minor warnings like door open or power interruptions, while others indicate hardware issues such as fan, sensor, or control board failures that may require repair.
Can I ignore Frigidaire system messages?
No. Ignoring them can lead to reduced performance or further damage. It is best to identify the message and address the underlying cause.
What causes most Frigidaire system messages?
Common causes include power fluctuations, blocked airflow, dirty filters, faulty sensors, water supply issues, or communication errors between control boards.
When should I call a technician for Frigidaire system messages?
If the message returns after resetting, or if it involves control boards, motors, or sensors that require replacement, a qualified technician should inspect the appliance.
Important: If errors persist after troubleshooting, disconnect power and contact a certified Frigidaire technician.
