Frigidaire Oven / Range Error Codes

Complete Troubleshooting & Repair Guide

Temperature & Sensor Errors
F10
Temperature Runaway Detected
  • Turn off oven immediately and allow cooling.
  • Check oven temperature sensor resistance.
  • Inspect relay stuck in ON position.
  • Replace control board or sensor if needed.
F14
Oven Sensor Error
  • Inspect temperature sensor wiring.
  • Test sensor continuity with multimeter.
  • Check connector for corrosion or damage.
  • Replace sensor if readings are abnormal.
Control System Errors
F11
Shorted Keypad
  • Clean control panel surface.
  • Check for moisture or stuck buttons.
  • Disconnect ribbon cable and inspect connections.
  • Replace keypad assembly if short persists.
F13
Control Board Failure
  • Reset power by switching breaker OFF for 5 minutes.
  • Inspect control board for burnt components.
  • Check wiring harness connections.
  • Replace main PCB if necessary.
F30
Communication Error
  • Check wiring between control board and components.
  • Inspect connectors for looseness or corrosion.
  • Perform system power reset.
  • Replace PCB if communication fails.
Door Lock System Errors
F15
Door Lock Failure
  • Inspect door latch alignment.
  • Check door lock motor wiring.
  • Ensure door closes completely.
  • Replace lock mechanism if faulty.
F90
Door Lock Motor Issue
  • Check door lock motor operation.
  • Inspect wiring harness for damage.
  • Reset oven power supply.
  • Replace door lock assembly if needed.
Important: If the error persists after troubleshooting, disconnect power immediately and contact a certified Frigidaire technician.
