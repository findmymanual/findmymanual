Electrolux Washing Machine Error Codes

Complete Troubleshooting & Repair Guide

Water Supply Errors
E10
Water Fill Timeout / Low Water Pressure
  • Check water supply valves are fully open.
  • Inspect inlet hose for kinks or blockage.
  • Clean inlet filter screen.
  • Verify household water pressure.
E11
Water Fill Too Slow
  • Check inlet hose for clog or bending.
  • Clean water inlet filter.
  • Ensure proper water pressure.
  • Replace inlet valve if needed.
E12
Overflow Detected
  • Turn off water supply immediately.
  • Check pressure switch for fault.
  • Inspect inlet valve for sticking open.
  • Replace water level sensor if necessary.
Drain System Errors
E20
Drain Problem
  • Check drain hose for blockage or kink.
  • Clean pump filter.
  • Inspect drain pump operation.
  • Remove debris from drain system.
E21
Drain Timeout
  • Inspect drain hose and sink connection.
  • Clean pump filter and impeller.
  • Check pump motor operation.
  • Replace pump if necessary.
E22
Pump Failure
  • Check drain pump wiring.
  • Test pump motor resistance.
  • Inspect for blockages in pump housing.
  • Replace drain pump if faulty.
Door System Errors
E30
Door Lock Error
  • Check door latch alignment.
  • Inspect door lock wiring.
  • Ensure door is fully closed.
  • Replace door lock assembly if needed.
E31
Door Open During Cycle
  • Ensure door is closed properly.
  • Check door switch sensor.
  • Inspect latch mechanism.
  • Replace switch if faulty.
E40
Door Lock Failure
  • Inspect door lock assembly.
  • Check wiring harness connections.
  • Test lock mechanism.
  • Replace door lock if necessary.
E41
Door Sensor Fault
  • Check door sensor alignment.
  • Inspect wiring for damage.
  • Test continuity of sensor.
  • Replace sensor if defective.
Motor System Errors
E50
Motor Control Error
  • Reset power to washer.
  • Inspect motor wiring connections.
  • Check control board output.
  • Replace motor control board if needed.
E51
Motor Triac Failure
  • Inspect control board triac components.
  • Check for burnt PCB areas.
  • Test motor resistance.
  • Replace control board if necessary.
E52
Motor Overspeed Detected
  • Check tachometer sensor connection.
  • Inspect motor belt or rotor.
  • Verify load balance.
  • Replace motor sensor if faulty.
Important: If error codes continue after troubleshooting, disconnect power and contact a certified Electrolux technician.
