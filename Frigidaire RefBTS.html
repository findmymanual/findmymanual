Frigidaire Refrigerator Error Codes

Complete Troubleshooting & Repair Guide

Communication & Control Errors
SY CE
Communication Error Between Control Boards
  • Power cycle the refrigerator for 5–10 minutes.
  • Inspect wiring between main control board and UI board.
  • Check for loose or corroded connectors.
  • Replace main PCB if communication fails.
SY CE1
Main Control Communication Failure
  • Reset appliance power supply.
  • Inspect main control board connections.
  • Check harness continuity between modules.
  • Replace control board if error persists.
Fan System Errors
SY CF
Condenser Fan Failure
  • Check condenser fan for dust or obstruction.
  • Inspect fan motor wiring and voltage supply.
  • Ensure proper airflow around rear unit.
  • Replace condenser fan motor if not running.
SY EF
Evaporator Fan Failure
  • Check evaporator fan blade for ice blockage.
  • Inspect fan motor and wiring connections.
  • Defrost unit if ice buildup is present.
  • Replace evaporator fan motor if faulty.
5Y EF
Evaporator Fan Circuit Error
  • Inspect evaporator fan wiring harness.
  • Check control board output voltage.
  • Look for moisture damage near fan circuit.
  • Replace fan motor or PCB if needed.
Sensor Errors
SY FF
Freezer Sensor Fault
  • Test freezer thermistor resistance.
  • Check sensor wiring for damage.
  • Ensure proper placement inside compartment.
  • Replace sensor if readings are abnormal.
SH
Shorted Humidity Sensor
  • Inspect humidity sensor wiring.
  • Check for moisture intrusion.
  • Disconnect and test sensor resistance.
  • Replace humidity sensor if shorted.
Compressor System Errors
SY CF1
Compressor Fan Issue
  • Check compressor fan for obstruction or damage.
  • Inspect wiring and capacitor (if applicable).
  • Ensure adequate ventilation around compressor.
  • Replace fan motor if needed.
Door & Alerts
OP
Door Open Alert
  • Ensure refrigerator door is fully closed.
  • Inspect door gasket for damage or dirt buildup.
  • Remove any obstruction preventing closure.
  • Test door switch operation.
Important: If errors persist after troubleshooting, disconnect power and contact a certified Frigidaire technician.
