Frigidaire Dishwasher Error Codes

Complete Frigidaire Dishwasher Guide

This guide explains all Frigidaire Dishwasher error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

i10
Water Fill Issue
  • Check water supply valve is fully open.
  • Inspect inlet hose for kinks or blockage.
  • Clean inlet filter screen.
  • Verify household water pressure is sufficient.
i20
Drain Blockage
  • Inspect drain hose for clogs or bends.
  • Clean dishwasher filter and sump area thoroughly.
  • Check drain pump operation for obstruction.
  • Ensure proper drain installation height and routing.
i30
Leak Detected (Float Switch)
  • Check for water leakage under the appliance.
  • Inspect float switch movement and operation.
  • Dry base pan completely and remove standing water.
  • Inspect hoses, seals, and connections for cracks.
i40
Pressure Sensor Fault
  • Inspect pressure sensor hose for blockage.
  • Check wiring connections to sensor.
  • Test sensor response using a multimeter.
  • Replace pressure sensor if readings are incorrect.
i50
Wash Motor Failure
  • Check wash pump for blockage or debris.
  • Inspect motor wiring and electrical connectors.
  • Test motor resistance and operation.
  • Replace wash motor or circulation pump if needed.
i60
Heating System Issue
  • Check heating element continuity.
  • Inspect thermostat and wiring connections.
  • Verify water temperature supply conditions.
  • Replace heater if no continuity is detected.
iC0
Control Board Error
  • Disconnect power for 5–10 minutes to reset system.
  • Inspect main control board connections.
  • Check for moisture or corrosion on PCB.
  • Replace control board if fault persists.
iC1
Door Switch Error
  • Ensure dishwasher door is fully closed and latched.
  • Inspect door switch wiring connections.
  • Test door switch continuity.
  • Replace door switch if faulty.
iC2
UI Communication Error
  • Reset dishwasher power system.
  • Check ribbon cable between UI and control board.
  • Inspect connectors for corrosion or looseness.
  • Replace UI board if communication fails.
iD0
Turbidity Sensor Fault
  • Clean filter and sensor housing.
  • Inspect turbidity sensor wiring connections.
  • Run cleaning cycle with dishwasher cleaner.
  • Replace sensor if readings are abnormal.
iE0
Water Level Detection Error
  • Inspect pressure switch and air trap system.
  • Check for clogs in sensor hose.
  • Test wiring connections for continuity.
  • Replace water level sensor if faulty.
iE1
Temperature Sensor Fault
  • Inspect thermistor wiring connections.
  • Test sensor resistance values.
  • Check for corrosion or moisture damage.
  • Replace temperature sensor if defective.
iE2
Heating Relay Failure
  • Inspect relay on control board.
  • Check for burnt PCB traces or damage.
  • Test relay switching operation.
  • Replace control board if relay is faulty.
iE3
Motor Communication Error
  • Inspect wiring between motor and PCB.
  • Check connectors for looseness or damage.
  • Reset dishwasher power system.
  • Replace motor or board if communication fails.
iE4
Spray Arm Blockage
  • Inspect spray arms for debris or obstruction.
  • Clean spray nozzles thoroughly.
  • Ensure arms rotate freely.
  • Reinstall properly after cleaning.
iE5
Drain Pump Motor Fault
  • Inspect drain pump for blockage or damage.
  • Check wiring connections.
  • Clean pump housing and impeller.
  • Replace pump motor if not operating.
PF
Power Failure Recovery
  • Check household power supply stability.
  • Reset dishwasher by turning power off for 5 minutes.
  • Verify breaker and outlet condition.
  • Restart cycle after power is restored.
LO
Low Water Temperature
  • Verify hot water supply temperature.
  • Check heating element operation.
  • Inspect thermostat function.
  • Run cycle again after temperature stabilizes.

Frequently Asked Questions


What does E10 Water Fill Timeout / Low Water Pressure mean?
Check that the water supply valve is fully open, inspect the inlet hose for kinks or blockage, clean the inlet filter screen, and ensure household water pressure is sufficient for proper dishwasher filling.
What does E11 Water Fill Too Slow mean?
Inspect the inlet hose for clogging or bending, clean the water inlet filter thoroughly, verify stable water pressure, and replace the inlet valve if water flow remains weak.
What does E12 Overflow Detected mean?
Turn off the water supply immediately, inspect the pressure switch for malfunction, check if the inlet valve is stuck open, and replace the water level sensor if needed.
What does E20 Drain Problem mean?
Check the drain hose for blockage or kinks, clean the pump filter thoroughly, inspect the drain pump for debris, and ensure proper water flow through the drainage system.
What does E21 Drain Timeout mean?
Inspect the drain hose and sink connection, clean the pump filter and impeller, check drain pump operation, and replace the pump if drainage remains slow.
What does E22 Pump Failure mean?
Check drain pump wiring connections, test pump motor resistance, inspect for blockages in the pump housing, and replace the drain pump if defective.
What does E30 Door Lock Error mean?
Check door latch alignment and condition, inspect door lock wiring harness, ensure the door is fully closed, and replace the door lock assembly if needed.
What does E31 Door Open During Cycle mean?
Ensure the dishwasher door is properly closed, check the door switch sensor, inspect latch mechanism for damage, and replace the door switch if faulty.
What does E40 Door Lock Failure mean?
Inspect the door lock assembly, check wiring connections for damage, test the lock mechanism, and replace the door lock if it fails to engage.
What does E41 Door Sensor Fault mean?
Check door sensor alignment, inspect wiring for breaks or corrosion, test sensor continuity, and replace the sensor if readings are incorrect.
What does E50 Motor Control Error mean?
Reset dishwasher power supply, inspect motor wiring connections, check control board output signals, and replace the motor control board if needed.
What does E51 Motor Triac Failure mean?
Inspect the control board for burnt components, test motor resistance and operation, check wiring harness condition, and replace the control board if the triac is faulty.
What does E60 Heating System Error mean?
Check heating element continuity, inspect thermostat and wiring connections, verify control board output, and replace the heater if faulty.
What does E61 Temperature Heating Error mean?
Inspect temperature sensor wiring, test heater operation during cycle, check for scaling on the heating element, and replace sensor or heater if needed.
What does E62 Overheating Protection Triggered mean?
Allow the dishwasher to cool down completely, check water circulation and load balance, inspect the heating element, and replace the thermostat if overheating persists.
What does E90 Electronic Control Fault mean?
Reset power supply for 5–10 minutes, inspect control board connections, check for moisture or corrosion on the PCB, and replace the main control board if the error continues.
Important: Always disconnect power before attempting repairs. If the issue continues, contact a qualified Electrolux service technician.
