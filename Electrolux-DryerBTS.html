Electrolux Dryer Error Codes

Complete Electrolux Dryer Guide

This guide explains all Electrolux Dryer error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

E64
Heating Element Fault
  • Check heating element continuity using a multimeter.
  • Inspect wiring connections for burns or loose terminals.
  • Ensure proper airflow through the dryer.
  • Replace the heating element if defective.
E65
Thermistor Error
  • Inspect thermistor wiring connections.
  • Test resistance values at room temperature.
  • Check for moisture or corrosion damage.
  • Replace thermistor if readings are outside specifications.
E66
Overheating Detected
  • Clean lint filter and exhaust vent system.
  • Inspect airflow restrictions throughout ductwork.
  • Allow dryer to cool before restarting.
  • Check thermal fuse and high-limit thermostat.
E68
Control Board Failure
  • Disconnect power for 5–10 minutes.
  • Inspect control board for damaged components.
  • Check wiring harness connections.
  • Replace electronic control board if necessary.
E71
Motor Relay Fault
  • Inspect motor relay on the control board.
  • Check motor wiring connections.
  • Test relay switching operation.
  • Replace control board if relay is defective.
E72
Door Switch Issue
  • Check door latch alignment.
  • Inspect door switch wiring.
  • Test switch continuity.
  • Replace door switch if faulty.
E73
Temperature Sensor Fault
  • Inspect temperature sensor connections.
  • Check sensor resistance values.
  • Verify wiring harness condition.
  • Replace sensor if defective.
E74
Temperature Sensor Mismatch
  • Verify all temperature sensors are connected correctly.
  • Confirm correct sensor type is installed.
  • Inspect harness wiring for damage.
  • Replace sensor or control board if mismatch continues.
E82
User Interface Communication Error
  • Reset dryer power supply.
  • Inspect display panel wiring connections.
  • Check communication cable between boards.
  • Replace interface board if necessary.
E91
Main Board Communication Failure
  • Check communication wiring harness.
  • Inspect connectors for corrosion.
  • Restart appliance and retest.
  • Replace control board if fault remains.
E92
Configuration Error
  • Verify appliance configuration settings.
  • Check software programming data.
  • Reset control board if available.
  • Reprogram or replace board if required.
E93
EEPROM Memory Error
  • Disconnect power and restart appliance.
  • Check control board connections.
  • Inspect PCB for damage.
  • Replace control board if memory failure persists.
E5A
Motor Control Overheating
  • Allow dryer to cool down completely.
  • Check ventilation and airflow.
  • Inspect motor control board.
  • Replace motor control module if needed.
E5B
Supply Voltage Too Low
  • Verify incoming voltage at outlet.
  • Inspect power cord and connections.
  • Avoid using extension cords.
  • Contact an electrician if voltage remains unstable.
E5C
Supply Voltage Too High
  • Measure supply voltage levels.
  • Inspect electrical installation.
  • Disconnect appliance until voltage normalizes.
  • Contact a qualified electrician if necessary.
E41
Door Not Closed
  • Close the dryer door securely.
  • Inspect door latch mechanism.
  • Check for clothing blocking closure.
  • Replace latch assembly if damaged.
E51
Motor Triac Fault
  • Inspect motor control circuitry.
  • Check motor wiring connections.
  • Test motor operation.
  • Replace motor control board if required.
E52
No Motor Signal Detected
  • Check motor tachometer connections.
  • Inspect drive motor wiring.
  • Test motor operation manually.
  • Replace motor if signal remains absent.
E10
Water Supply / Sensor Issue
  • Check inlet water system (if steam function is used).
  • Inspect sensor connections for damage.
  • Restart the dryer to reset system.
  • Replace faulty sensor if error persists.
E20
Drain System Fault
  • Check drain hose for blockage or kinks.
  • Clean lint and water collection system.
  • Inspect pump (condensing models).
  • Reset unit after cleaning.
E30
Door Lock Error
  • Ensure door is fully closed.
  • Inspect door latch mechanism.
  • Check door switch wiring.
  • Replace latch if defective.
E40
Door Open / Safety Lock Active
  • Close dryer door securely.
  • Remove clothing blocking the seal.
  • Inspect door sensor alignment.
  • Reset dryer and retry cycle.
E50
Motor / Drum Rotation Failure
  • Check drum for obstruction or overload.
  • Inspect drive belt condition.
  • Test motor operation.
  • Replace motor if failure continues.
E60
Heating System Fault
  • Check heating element continuity.
  • Inspect thermal fuse and thermostat.
  • Clean lint filter and airflow system.
  • Replace heater if defective.
E61
Temperature Sensor Fault
  • Inspect thermistor wiring connections.
  • Test resistance readings.
  • Check for moisture or corrosion.
  • Replace sensor if readings are abnormal.
E70
Overheating Protection Activated
  • Clean lint filter and exhaust vents.
  • Ensure proper airflow around dryer.
  • Allow unit to cool before restarting.
  • Check thermal fuse condition.
E80
Control Board Communication Error
  • Disconnect power for 5–10 minutes.
  • Check wiring harness connections.
  • Inspect control board for damage.
  • Replace PCB if error persists.
E90
Configuration / EEPROM Error
  • Restart the dryer system.
  • Check control board settings.
  • Inspect PCB memory module.
  • Replace board if configuration fails.

Frequently Asked Questions


What does E10 Water Inlet / Filling Issue mean?
Check that the water supply valve is fully open, inspect inlet hose for blockages or kinks, clean inlet filter screen, and ensure proper household water pressure.
What does E20 Drainage Problem mean?
Check drain hose for clogs or kinks, clean lint and debris from drain system, inspect pump for obstruction, and ensure proper installation of drain line.
What does E24 Leak Detected / Water Protection Active mean?
Turn off water supply immediately, check hoses, seals, and connections for leaks, inspect base tray for water accumulation, and dry unit before resetting.
What does E30 Door Open / Door Lock Issue mean?
Ensure door is fully closed and latched, check door switch and latch alignment, remove any obstruction blocking closure, and replace door lock if faulty.
What does E40 Door Lock Failure mean?
Inspect door lock mechanism, check wiring connections, test door switch operation, and replace lock assembly if needed.
What does E50 Motor / Drive System Fault mean?
Check drum for blockage or overload, inspect motor wiring and connections, test motor operation, and replace motor if defective.
What does E51 Motor Control Fault mean?
Inspect control board connections, check motor triac or relay, test wiring harness for damage, and replace control board if needed.
What does E52 Motor Signal Loss mean?
Check motor tachometer connections, inspect wiring harness, test motor feedback signal, and replace motor if signal is missing.
What does E56 Heating System Failure mean?
Check heating element continuity, inspect thermostat and wiring, test control board output, and replace heating element if faulty.
What does E60 Overheating / Temperature Issue mean?
Clean lint filter and exhaust system, ensure proper airflow through vents, allow unit to cool before restart, and check thermal fuse and sensors.
What does E61 Temperature Sensor Fault mean?
Inspect thermistor wiring, test resistance values, check for moisture or corrosion, and replace sensor if readings are incorrect.
What does E63 Drying Performance Issue mean?
Clean lint filter thoroughly, check exhaust vent for blockage, avoid overloading drum, and select proper drying program.
What does E66 Airflow Restriction mean?
Clean lint trap and duct system, check for blocked vents, ensure proper installation clearance, and inspect fan system.
What does E68 Control Board Fault mean?
Restart power supply, inspect PCB for damage or moisture, check wiring connections, and replace control board if needed.
What does E70 Communication Error mean?
Check wiring between control modules, inspect connectors for looseness, restart dryer system, and replace board if communication fails.
What does E90 Configuration / Software Error mean?
Reset dryer power supply, check system configuration settings, inspect control board programming, and reprogram or replace board if needed.
What does E91 Memory / EEPROM Fault mean?
Disconnect power and restart unit, check control board connections, inspect PCB for damage, and replace control board if memory fails.
What does E93 System Error / Internal Fault mean?
Restart dryer system, check wiring harness connections, inspect control board condition, and replace board if issue persists.
Important: Always disconnect power before performing repairs. Contact a qualified technician if the issue persists.
