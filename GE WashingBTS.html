GE Washing Machine Error Codes

Complete Troubleshooting & Repair Guide

Door & Lock Errors
E22
Door Lock Failure
  • Check door latch alignment.
  • Inspect door lock wiring.
  • Ensure door closes completely.
  • Replace door lock assembly if faulty.
E47
Door Lock Circuit Issue
  • Inspect wiring harness to door lock.
  • Test continuity of lock circuit.
  • Check control board output signal.
  • Replace lock or PCB if needed.
E39
Lid Switch Failure
  • Check lid switch alignment.
  • Inspect switch wiring for damage.
  • Test switch continuity.
  • Replace lid switch if faulty.
Drain System Errors
E23
Drain Pump Issue
  • Clean drain pump filter.
  • Check for blockage in hose.
  • Inspect pump motor wiring.
  • Replace pump if not running.
E24
Drain Problem Detected
  • Inspect drain hose for kinks.
  • Check pump impeller for debris.
  • Ensure proper drainage path.
  • Reset machine after cleaning.
Motor Errors
E30
Motor Control Error
  • Check motor wiring connections.
  • Inspect control board output.
  • Test motor resistance.
  • Replace motor or PCB if needed.
E54
Motor Overload
  • Reduce heavy laundry load.
  • Check drum for blockage.
  • Inspect motor for overheating.
  • Allow cooling before restart.
E57
High Motor Current Detected
  • Inspect drum bearings.
  • Check motor shaft movement.
  • Look for jammed load.
  • Replace motor if current remains high.
E58
Motor Overheating
  • Allow machine to cool down.
  • Check ventilation around motor.
  • Inspect motor brushes (if applicable).
  • Replace motor if overheating persists.
Sensor Errors
E31
Pressure Sensor Fault
  • Inspect water level sensor tube.
  • Check pressure switch wiring.
  • Clean air trap hose.
  • Replace sensor if needed.
E38
Water Level Issue
  • Check inlet valve operation.
  • Inspect water pressure.
  • Clean inlet filter screen.
  • Verify level sensor accuracy.
Communication Errors
E43
Control Board Communication Fault
  • Restart machine power cycle.
  • Inspect wiring between modules.
  • Check for moisture damage.
  • Replace PCB if fault persists.
Important: If the issue continues after troubleshooting, disconnect power immediately and contact a certified GE technician.
