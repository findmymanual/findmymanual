Whirlpool Washing Machine Error Codes

Complete Troubleshooting & Repair Guide

Control & Communication Errors
F01 / E01
Main Control Board Failure
  • Restart the washing machine.
  • Check wiring between control board and modules.
  • Inspect for moisture or burn marks on PCB.
  • Replace control board if necessary.
F09
Software / Memory Issue
  • Power cycle the unit for 10 minutes.
  • Check firmware corruption.
  • Inspect EEPROM or memory chip.
  • Replace control module if needed.
F11
Communication Failure
  • Check wiring harness connections.
  • Inspect control and inverter boards.
  • Reset power supply.
  • Replace PCB if error persists.
Water System Errors
F02
Drain Problem Detected
  • Check drain hose for blockage.
  • Clean filter and pump.
  • Inspect drain motor.
  • Ensure proper installation height.
F20
Water Inlet Problem
  • Check water supply tap.
  • Inspect inlet valve and filter screen.
  • Ensure water pressure is sufficient.
  • Replace inlet valve if needed.
F21
Drain Pump Issue
  • Inspect drain pump for blockage.
  • Check impeller movement.
  • Clean drain hose.
  • Replace pump if faulty.
F8 E1
Low or No Water Detected
  • Check water supply pressure.
  • Inspect inlet valve screen.
  • Ensure hose is not kinked.
  • Restart cycle after correction.
F9 E1
Long Drain Time Detected
  • Clean drain filter.
  • Check for hose blockage.
  • Inspect drain pump performance.
  • Reset machine cycle.
Motor & Drive Errors
F06
Drive Motor Tachometer Error
  • Check motor tachometer wiring.
  • Inspect rotor and belt condition.
  • Test motor resistance.
  • Replace motor if needed.
F07
Motor Control Board Fault
  • Inspect inverter/control board.
  • Check motor wiring connections.
  • Reset power supply.
  • Replace PCB if required.
F7 E1
Motor Speed Sensing Error
  • Check motor hall sensor.
  • Inspect belt tension.
  • Test wiring connections.
  • Replace motor sensor if needed.
Heating Errors
F03
Temperature Sensor Fault
  • Inspect thermistor connection.
  • Check wiring harness.
  • Clean sensor area.
  • Replace sensor if faulty.
F05
Water Temperature Sensor Error
  • Test temperature sensor resistance.
  • Inspect heater wiring.
  • Check PCB connection.
  • Replace sensor if needed.
F08
Heater Circuit Failure
  • Inspect heating element.
  • Check relay on control board.
  • Test continuity of heater.
  • Replace heater if faulty.
Door System Errors
F22
Door Lock Failure
  • Check door latch alignment.
  • Inspect door lock switch.
  • Ensure door closes properly.
  • Replace lock mechanism if needed.
F5 E2
Door Not Locking Properly
  • Inspect door hook and strike.
  • Check wiring to lock system.
  • Restart machine.
  • Replace door lock assembly if needed.
System Errors
F09 (Alt)
Software / Memory Issue
  • Restart machine.
  • Check firmware corruption.
  • Inspect control board memory.
  • Replace PCB if necessary.
Important: If the issue continues after troubleshooting, disconnect power immediately and contact a qualified technician.
