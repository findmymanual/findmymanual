LG Refrigerator Error Codes

Complete LG Fridge Troubleshooting Guide

ER FF
Freezer Fan Failure
  • Check freezer fan for ice blockage.
  • Inspect fan motor operation.
  • Defrost unit if ice buildup is present.
  • Replace fan motor if faulty.
ER IF
Ice Fan Error
  • Inspect ice fan for obstruction.
  • Check wiring connections.
  • Defrost ice compartment.
  • Replace fan if not spinning.
ER DH
Defrost Heater Fault
  • Check defrost heater continuity.
  • Inspect wiring harness.
  • Look for ice buildup on evaporator.
  • Replace heater if defective.
ER CO
Communication Error
  • Reset power for 5–10 minutes.
  • Check main PCB connections.
  • Inspect wiring between boards.
  • Call technician if persistent.
ER FS
Freezer Sensor Error
  • Check sensor wiring.
  • Inspect freezer temperature sensor.
  • Ensure proper connector seating.
  • Replace sensor if needed.
ER CF
Condenser Fan Error
  • Clean condenser fan area.
  • Check fan motor operation.
  • Remove dust buildup.
  • Replace fan if not working.
ER RS
Refrigerator Sensor Error
  • Inspect fridge temperature sensor.
  • Check wiring connections.
  • Restart unit.
  • Replace sensor if faulty.
ER DS
Damper Sensor Error
  • Check air damper movement.
  • Inspect sensor wiring.
  • Ensure no blockage in airflow.
  • Replace damper assembly if needed.
22 / 33
Compressor Fault (Model Dependent)
  • Check power supply stability.
  • Inspect compressor wiring.
  • Listen for abnormal compressor noise.
  • Call technician for diagnosis.
ER HS
Humidity Sensor Error
  • Inspect humidity sensor connection.
  • Clean sensor area.
  • Restart refrigerator.
  • Replace sensor if faulty.
ER TS
Temperature Sensor Failure
  • Check thermistor wiring.
  • Inspect sensor placement.
  • Reset power.
  • Replace sensor if needed.
ER IS
Ice Maker Sensor Error
  • Check ice maker wiring.
  • Inspect water supply line.
  • Reset ice maker module.
  • Replace sensor if faulty.
ER SS
Pantry Sensor Error
  • Check pantry drawer sensor.
  • Inspect wiring connections.
  • Ensure drawer alignment.
  • Replace sensor if needed.
ER RT
Room Temperature Sensor Error
  • Inspect ambient sensor.
  • Check wiring harness.
  • Restart unit.
  • Replace sensor if defective.
OFF
Demo Mode Enabled
  • Hold refrigerator settings buttons.
  • Disable demo mode in settings.
  • Unplug unit for reset.
  • Check user manual for model steps.
ER GF
Flow Sensor Issue
  • Check water inlet line.
  • Inspect flow sensor for blockage.
  • Clean water filter.
  • Replace sensor if needed.

Frequently Asked Questions


What does ER FF mean on an LG refrigerator?

The ER FF error indicates a freezer fan failure. This usually happens due to ice buildup blocking the fan or a faulty fan motor that needs inspection or replacement.

How do I fix the ER IF error on my LG fridge?

The ER IF code means there is an issue with the ice fan. Check for obstructions, defrost the ice compartment, and inspect wiring connections. Replace the fan if it is not spinning.

What causes the ER DH error in LG refrigerators?

ER DH indicates a defrost heater fault. This may be due to a defective heater, damaged wiring, or ice buildup on the evaporator that prevents proper defrosting.

How do I resolve the ER CO communication error?

The ER CO error occurs when there is a communication failure between control boards. Try resetting the refrigerator by unplugging it for 5–10 minutes and checking wiring connections.

What should I do if my LG fridge shows ER FS?

ER FS indicates a freezer sensor issue. Check the temperature sensor wiring and connector seating, and replace the sensor if it is faulty.

What does ER CF mean on an LG refrigerator?

The ER CF error refers to a condenser fan issue. Clean dust buildup, check the fan motor operation, and replace the fan if it is not working properly.

How do I fix ER RS refrigerator sensor error?

ER RS means the refrigerator temperature sensor is faulty or disconnected. Inspect wiring, restart the unit, and replace the sensor if needed.

What causes ER DS damper sensor error?

ER DS occurs when the air damper is stuck or the sensor is malfunctioning. Check for airflow blockage and ensure the damper moves freely.

What does ER HS mean on LG fridges?

ER HS indicates a humidity sensor issue. Clean the sensor area, check connections, and replace the sensor if it continues to fail.

How do I fix ER TS temperature sensor failure?

ER TS means the thermistor or temperature sensor is not working correctly. Inspect wiring, reset power, and replace the sensor if needed.

What does ER IS mean on LG refrigerator ice maker?

ER IS indicates an ice maker sensor error. Check water supply, inspect wiring, and reset the ice maker module.

What is ER SS error in LG fridge?

ER SS refers to a pantry drawer sensor issue. Ensure the drawer is properly aligned and check wiring or sensor failure.

What does ER RT mean on LG refrigerator?

ER RT indicates a room temperature sensor error. Inspect the ambient sensor and wiring, and replace the sensor if necessary.

What is OFF mode on LG refrigerator display?

OFF means the refrigerator is in demo mode. You can disable it using the control panel or by holding the settings buttons depending on the model.

How do I fix ER GF water flow sensor issue?

ER GF indicates a problem with the water flow sensor. Check the water inlet line, clean the filter, and replace the sensor if blockage persists.

What should I do if LG refrigerator error codes keep coming back?

If error codes reappear after troubleshooting, disconnect power and contact an authorized LG service technician for deeper diagnosis.
