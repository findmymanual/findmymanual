Whirlpool Refrigerator Error Codes

Complete Troubleshooting & Repair Guide

Power & System Errors
E0 / F0
Power Loss or Door Open
  • Check if power was recently interrupted.
  • Ensure door is fully closed.
  • Inspect door switch sensor.
  • Restart unit after power stabilizes.
PE
Power Supply Error
  • Check outlet voltage stability.
  • Inspect power cord and plug.
  • Reset circuit breaker.
  • Call electrician if issue continues.
PO
Power Outage Detected
  • Wait for stable power supply.
  • Reset refrigerator after outage.
  • Check surge protector condition.
  • Verify appliance restart sequence.
Temperature Sensor Errors
E1 / F1
Refrigerator Temperature Sensor Fault
  • Check fridge thermistor connection.
  • Inspect wiring harness.
  • Test sensor resistance.
  • Replace sensor if faulty.
E2 / F2
Freezer Sensor / Evaporator Fan Error
  • Inspect evaporator fan motor.
  • Check freezer temperature sensor.
  • Remove ice buildup around fan.
  • Replace faulty components if needed.
E4 / F4
Fridge Defrost Sensor Fault
  • Check defrost sensor wiring.
  • Inspect evaporator coil area.
  • Test sensor resistance.
  • Replace sensor if required.
E7 / F7
Environmental Temperature Sensor Fault
  • Check ambient sensor placement.
  • Inspect wiring for damage.
  • Ensure proper airflow around unit.
  • Replace sensor if faulty.
Fan & Defrost Errors
E3 / F3
Defrost Sensor / Condenser Fan Error
  • Inspect condenser fan motor.
  • Check defrost heater system.
  • Remove ice buildup.
  • Test fan operation.
DF
Defrost Failure
  • Check defrost heater continuity.
  • Inspect defrost timer/control board.
  • Ensure evaporator is not iced over.
  • Replace heater if needed.
Ice Maker Errors
E5 / F5
Ice Maker Sensor Issue
  • Check water supply line.
  • Inspect ice maker sensor connection.
  • Clear ice blockage.
  • Reset ice maker module.
Communication Errors
E6 / F6
Communication Error
  • Reset refrigerator power for 10 minutes.
  • Inspect wiring between control boards.
  • Check PCB connectors.
  • Replace main board if needed.
SY / CE
System / Communication Error Between Boards
  • Check cable connections between modules.
  • Inspect control board for damage.
  • Restart system.
  • Replace PCB if fault persists.
Temperature Alarm
E9 / F9
Freezer High Temperature Alarm
  • Check door sealing.
  • Ensure compressor is running.
  • Reduce frequent door opening.
  • Allow unit to stabilize temperature.
Important: If the error continues after troubleshooting, disconnect power and contact a qualified refrigerator technician.
