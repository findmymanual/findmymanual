Westinghouse Oven / Range Error Codes

Complete Troubleshooting & Repair Guide

Control System Errors
F1
Control Board Fault
  • Reset power by unplugging unit for 5–10 minutes.
  • Inspect control board for burn marks or damage.
  • Check wiring connections for looseness or corrosion.
  • Replace main control board if issue persists.
Temperature Errors
F2
Over-Temperature Condition
  • Allow oven to cool completely before restart.
  • Check temperature sensor (thermistor) condition.
  • Inspect heating element for sticking ON issue.
  • Replace control board if overheating continues.
F3
Sensor Error
  • Check sensor wiring for disconnection or damage.
  • Test sensor resistance with multimeter.
  • Inspect connector terminals for corrosion.
  • Replace temperature sensor if faulty.
Door System Errors
F4
Door Switch Issue
  • Ensure oven door closes properly.
  • Inspect door switch alignment and wiring.
  • Test switch continuity.
  • Replace door switch if faulty.
Heating System Errors
F5
Heating Element Failure
  • Test heating element continuity.
  • Inspect wiring harness connections.
  • Check for visible burn damage.
  • Replace heating element if defective.
Cooling & Fan Errors
F6
Fan Malfunction
  • Check cooling fan for obstruction or dust buildup.
  • Inspect fan motor wiring.
  • Test fan operation directly.
  • Replace fan motor if not working.
User Interface Errors
F7
Keypad Error
  • Check keypad ribbon cable connection.
  • Inspect for moisture or dirt on panel.
  • Reset power to system.
  • Replace control panel if unresponsive.
Relay & Power Errors
F8
Relay Failure
  • Inspect relay on control board for burn marks.
  • Check wiring connections.
  • Test output voltage to components.
  • Replace control board if relay is faulty.
Communication Errors
F9
Communication Error
  • Reset appliance power.
  • Inspect wiring harness between modules.
  • Check connectors for corrosion or looseness.
  • Replace main PCB if issue persists.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified Westinghouse technician.
