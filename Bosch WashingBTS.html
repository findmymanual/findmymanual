Bosch Washing Machine Error Codes

Complete Troubleshooting & Repair Guide

Water Supply & Inlet Errors
F02 / E17
Water Supply Issue
  • Check water tap is fully open.
  • Inspect inlet hose for blockage.
  • Clean inlet filter screen.
  • Verify household water pressure.
F17
Water Intake Timeout
  • Check inlet valve operation.
  • Ensure water supply is stable.
  • Inspect hose for kinks.
  • Clean inlet filter.
F29 / E28
Flow Sensor Error
  • Inspect water flow sensor.
  • Check wiring connections.
  • Clean inlet system.
  • Replace sensor if faulty.
Drainage System Errors
F03 / E18
Drainage Failure / Blocked Pump
  • Check drain hose for blockage.
  • Clean pump filter.
  • Inspect drain pump impeller.
  • Remove debris from system.
F18
Drain Timeout
  • Check drain hose installation.
  • Inspect pump motor.
  • Clean lint and debris.
  • Restart washing cycle.
E24 / E25
Drain Blockage / Obstruction
  • Inspect drain pump area.
  • Remove foreign objects.
  • Clean filter housing.
  • Check hose routing.
Door Lock Errors
F16 / E16
Door Not Locked
  • Close door firmly.
  • Inspect door latch mechanism.
  • Check wiring to lock system.
  • Replace door lock if faulty.
F34 / E27
Door Lock Failure
  • Check door latch alignment.
  • Inspect locking motor.
  • Reset washing machine.
  • Replace lock system if needed.
E42 / E43
Door Unlocking Error
  • Wait for cycle to finish.
  • Turn power off for reset.
  • Check lock actuator.
  • Call technician if stuck.
Motor & Drum Errors
F01
Motor Triac Fault
  • Reset machine power.
  • Inspect motor wiring.
  • Check control board triac.
  • Replace PCB if needed.
F21 / E21
Motor Failure / Drum Jam
  • Check drum for blockage.
  • Inspect motor brushes.
  • Reset washing machine.
  • Replace motor if required.
F43 / E50–E52
Motor / Inverter Failure
  • Check inverter board.
  • Inspect motor connections.
  • Ensure proper voltage supply.
  • Call technician for repair.
F43 (Drum Not Spinning)
Drum Rotation Failure
  • Check belt condition.
  • Inspect motor coupling.
  • Remove load imbalance.
  • Test motor operation.
Leak & Pressure Errors
F23 / E22
Water Leakage Detected
  • Inspect hoses and seals.
  • Check detergent usage.
  • Look for water under machine.
  • Dry and reset system.
E23
Leak Sensor Activated
  • Check base tray for water.
  • Inspect internal seals.
  • Dry sensor area.
  • Restart machine.
E26
Water Pressure Sensor Fault
  • Check pressure switch hose.
  • Inspect wiring connection.
  • Clean pressure chamber.
  • Replace sensor if needed.
System & Electronic Errors
F57
Electronic Control Failure
  • Reset machine power.
  • Check PCB connections.
  • Inspect for moisture damage.
  • Replace control board if needed.
E29–E32
Load / System Imbalance
  • Redistribute laundry evenly.
  • Reduce load size.
  • Check drum suspension.
  • Restart cycle.
E36–E38
Pressure System Fault
  • Check pressure sensor tubing.
  • Inspect water level system.
  • Clean air chamber.
  • Replace sensor if needed.
Important: Always disconnect power before servicing. If errors persist after troubleshooting, contact a qualified appliance technician.
