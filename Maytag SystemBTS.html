Maytag System Messages Troubleshooting Guide

Complete Troubleshooting & Status Guide

Control & Lock Messages
LOC
Control Lock Active
  • Press and hold the lock button for 3–5 seconds.
  • Check user manual for model-specific unlock method.
  • Power cycle the appliance if lock does not clear.
  • Ensure no stuck buttons on control panel.
Temperature Warnings
HOT
High Temperature Warning
  • Allow appliance to cool down before use.
  • Check ventilation around the unit.
  • Inspect cooling fans if applicable.
  • Avoid continuous heavy use cycles.
Power & System Status
PF
Power Failure Detected
  • Check household power supply.
  • Reset breaker if tripped.
  • Unplug appliance for 5 minutes then restart.
  • Verify stable voltage supply.
RESET
System Restart Required
  • Turn off appliance and unplug for 5–10 minutes.
  • Restart system and reconfigure settings.
  • Check for repeated error after reset.
  • Contact technician if reset fails.
General System Errors
ERR
General Appliance Error
  • Restart the appliance to clear temporary fault.
  • Inspect wiring and connections.
  • Check for overheating or overload conditions.
  • Call service if error persists.
Cooling Status
COOL
Cooling Cycle Active
  • Allow cycle to complete before opening or using appliance.
  • Ensure proper airflow around unit.
  • Avoid interrupting cooling process.
  • This is a normal operation status.
Important: If system messages repeatedly appear without normal operation, disconnect power and contact a certified Maytag technician.
