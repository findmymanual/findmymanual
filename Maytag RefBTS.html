Maytag Refrigerator Error Codes

Complete Troubleshooting & Repair Guide

Power & System Issues
PO
Power Outage Detected
  • Check household power supply and circuit breaker.
  • Reset refrigerator by unplugging for 5 minutes.
  • Ensure stable voltage supply.
  • Confirm settings after restart.
Ice Maker System Errors
Er IF
Ice Maker Fan Motor Issue
  • Check ice maker fan for obstruction or ice buildup.
  • Inspect wiring connections.
  • Ensure proper airflow in freezer compartment.
  • Replace fan motor if not running.
Defrost System Errors
Er dH
Defrost Heater Failure
  • Test defrost heater continuity.
  • Inspect wiring harness for damage.
  • Check defrost thermostat operation.
  • Replace heater if faulty.
Cooling System Errors
Er CF
Cooling Fan Error
  • Check evaporator fan for blockage.
  • Inspect fan motor wiring.
  • Ensure proper ventilation inside unit.
  • Replace fan motor if needed.
Communication Errors
Er CO
Communication Error
  • Reset refrigerator power for 5–10 minutes.
  • Inspect wiring between control boards.
  • Check connectors for looseness or corrosion.
  • Replace control board if issue persists.
SY CE
Communication Error Between Boards
  • Inspect main PCB connections.
  • Check for moisture or damage on wiring.
  • Power cycle unit to reset system.
  • Replace PCB if communication fails.
SY EF
Evaporator Fan Circuit Issue
  • Check evaporator fan motor operation.
  • Inspect fan wiring harness.
  • Ensure no ice blockage in fan area.
  • Replace fan motor or PCB if required.
Door & Safety Alerts
OP
Door Open Warning
  • Ensure refrigerator door is fully closed.
  • Check door gasket for damage or dirt.
  • Remove any obstruction blocking door seal.
  • Test door switch operation.
Important: If errors persist after troubleshooting, disconnect power and contact a certified Maytag technician.
