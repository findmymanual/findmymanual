Midea Microwave Error Codes

Complete Troubleshooting & Diagnostic Guide

Door System Errors
E1
Door Switch Fault
  • Ensure microwave door closes properly.
  • Inspect door latch and hooks for damage.
  • Check door switch alignment and wiring.
  • Replace door switch assembly if faulty.
Protection System Errors
E2
Overheat Protection
  • Allow microwave to cool down completely.
  • Check ventilation around unit.
  • Ensure cooling fan is operating.
  • Reset power after cooling period.
Heating System Errors
E3
Magnetron Failure
  • Check high-voltage components (capacitor/diode).
  • Inspect magnetron connections.
  • Test for continuity issues.
  • Replace magnetron if defective.
Control System Errors
E4
Control Board Error
  • Power cycle the microwave.
  • Inspect PCB for burn marks or damage.
  • Check wiring harness connections.
  • Replace main control board if needed.
Important: Microwave repairs involving high-voltage components should only be performed by a qualified technician.
