KitchenAid Refrigerator Error Codes

Complete Troubleshooting & Repair Guide

Power & System Errors
PO
Power Outage Detected
  • Check household power supply and breaker.
  • Reset refrigerator by unplugging for 5–10 minutes.
  • Confirm display resets properly after restart.
  • Reprogram temperature settings if needed.
Er
General System Error
  • Perform a full power reset.
  • Check control board connections.
  • Inspect wiring harness for loose connections.
  • Replace main PCB if error persists.
Fan & Cooling System Errors
CF
Condenser Fan Failure
  • Clean condenser coils and fan blades.
  • Check fan motor for blockage or damage.
  • Inspect wiring connections.
  • Replace condenser fan motor if faulty.
rF
Refrigerator Fan Error
  • Inspect evaporator fan for ice buildup.
  • Check fan motor operation.
  • Verify wiring harness connection.
  • Replace fan motor if not spinning.
Defrost System Errors
dH
Defrost Heater Issue
  • Check defrost heater continuity.
  • Inspect defrost thermostat and wiring.
  • Look for frost buildup on evaporator coil.
  • Replace heater assembly if faulty.
Sensor Errors
rS
Refrigerator Sensor Fault
  • Check temperature sensor wiring.
  • Test sensor resistance values.
  • Inspect connector for corrosion.
  • Replace sensor if readings are incorrect.
FS
Freezer Sensor Fault
  • Inspect freezer thermistor wiring.
  • Check for ice damage or disconnection.
  • Test resistance with multimeter.
  • Replace sensor if faulty.
Door System Errors
OP
Door Open Alert
  • Ensure door is fully closed and sealed.
  • Check door gasket for damage.
  • Inspect door switch or sensor.
  • Remove any obstruction preventing closure.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified KitchenAid technician.
