GE System Messages Error Codes

Complete GE System Messages Guide

This guide explains all GE System Messages error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

LOCK
Control Lock Enabled
  • Press and hold the lock button for 3–5 seconds.
  • Check if child lock feature is activated in settings.
  • Power cycle the appliance if controls remain unresponsive.
  • Inspect keypad for stuck or damaged buttons.
HOT
High Temperature Warning
  • Allow appliance to cool completely before use.
  • Check ventilation openings for blockage or dust buildup.
  • Inspect cooling fan operation and airflow.
  • Avoid restarting until temperature returns to normal.
COOL
Cooling Cycle Active
  • Wait until the cooling cycle completes.
  • Do not disconnect power during operation.
  • Ensure proper airflow around the unit.
  • Restart only after the cycle finishes.
RESET
System Restart Required
  • Turn the appliance OFF completely.
  • Disconnect power for 5–10 minutes.
  • Reconnect and power back on.
  • Check if error reappears after restart.
ERR
General Appliance Error
  • Perform a full power reset of the unit.
  • Check for additional displayed error codes.
  • Inspect wiring and control connections.
  • Contact service technician if issue continues.
PF
Power Interruption Detected
  • Check household circuit breaker and outlet.
  • Verify stable voltage supply.
  • Reset appliance after power is restored.
  • Use a surge protector to prevent future issues.
F1
Control Board Communication Error
  • Power cycle the appliance for 10 minutes.
  • Check wiring harness connections.
  • Inspect control board for moisture or burns.
  • Replace PCB if communication fails.
F2
Temperature Sensor Fault
  • Inspect thermistor wiring connections.
  • Test sensor resistance with a multimeter.
  • Check for corrosion or loose terminals.
  • Replace sensor if readings are abnormal.
F3
Fan Motor Failure
  • Check fan blades for obstruction.
  • Inspect motor wiring and connectors.
  • Test fan rotation manually.
  • Replace fan motor if not operating.
F4
Heating Element Fault
  • Check heating element continuity.
  • Inspect wiring for burns or damage.
  • Test power output from control board.
  • Replace heating element if defective.
F5
Door Switch Fault
  • Ensure door closes and locks properly.
  • Inspect door switch alignment.
  • Check wiring connections to switch.
  • Replace door switch if faulty.
F6
Relay / Power Control Failure
  • Inspect control board relays.
  • Check for burnt PCB components.
  • Reset appliance power supply.
  • Replace control board if relay is stuck.
F7
Sensor Calibration Error
  • Restart appliance to recalibrate sensors.
  • Inspect sensor placement and alignment.
  • Check for firmware or board issues.
  • Replace sensor if calibration fails.
F8
Overheat Protection Activated
  • Turn off appliance immediately and let it cool.
  • Check ventilation openings for blockage.
  • Inspect cooling fan operation.
  • Clean dust buildup around internal components.
F9
Memory / EEPROM Error
  • Power cycle the appliance for 10 minutes.
  • Check control board for moisture damage.
  • Inspect EEPROM chip connections.
  • Replace control board if error persists.
F10
Voltage Supply Issue
  • Check household voltage stability.
  • Inspect outlet and breaker condition.
  • Avoid using extension cords.
  • Use a voltage stabilizer if needed.
F11
Low Power Input Detected
  • Check if other appliances are affecting the circuit.
  • Test appliance on a different outlet.
  • Inspect power cord for damage.
  • Contact electrician if voltage is unstable.
F12
High Current Draw / Overload
  • Disconnect appliance immediately.
  • Inspect motor or compressor for overload.
  • Check wiring for short circuits.
  • Replace faulty components if needed.
F13
Internal Wiring Fault
  • Inspect internal wiring harness connections.
  • Look for burnt or loose wires.
  • Check for rodent or physical damage.
  • Repair or replace wiring as needed.
F14
Control Panel Not Responding
  • Clean keypad surface and remove moisture.
  • Check ribbon cable connection.
  • Perform a full power reset.
  • Replace UI board if unresponsive.
F15
Water Leakage Detected
  • Check internal base for water buildup.
  • Inspect hoses and seals for leaks.
  • Dry affected area completely.
  • Replace damaged seals or components.
F16
Motor Speed Sensor Error
  • Inspect tachometer or speed sensor.
  • Check wiring connections to motor.
  • Test sensor signal output.
  • Replace sensor if readings are unstable.
F17
Inverter Module Failure
  • Check inverter board for burn marks.
  • Inspect cooling system around module.
  • Test power input/output signals.
  • Replace inverter module if faulty.
F18
Drainage / Pump Failure
  • Check pump for blockage or debris.
  • Inspect drain hose for kinks.
  • Test pump motor operation.
  • Replace pump if not working.
F19
Pressure Sensor Fault
  • Inspect pressure sensor tubing.
  • Check wiring connections.
  • Test sensor response with multimeter.
  • Replace sensor if readings are incorrect.
F20
System Communication Failure
  • Reset appliance power completely.
  • Inspect communication cables.
  • Check for PCB corrosion or damage.
  • Replace main control board if needed.
F21 / E21
Motor Failure / Drive System Jam
  • Check motor for obstruction or overload.
  • Inspect wiring and connectors.
  • Test motor resistance and operation.
  • Replace motor if no response is detected.

Frequently Asked Questions


What does “ER” mean on GE System Messages?
This indicates a general system error. Power cycle the refrigerator for 5–10 minutes, check control board connections, and inspect for moisture or wiring faults. Replace the main PCB if the issue continues.
What does “88” mean on GE System Messages?
This is a communication error between control boards. Inspect wiring harness connections, ensure plugs are secure, and reset the appliance to restore communication.
What does “PF” mean on GE System Messages?
PF means power failure detected. Check household power supply, inspect circuit breaker and outlet, then reset the refrigerator after power is restored.
What does “dE” mean on GE System Messages?
This indicates a defrost system error. Check the defrost heater, sensor, and control board. If ice buildup is present, manually defrost the unit before restarting.
What does “CI” mean on GE System Messages?
CI refers to an ice maker system fault. Check water supply line, ensure freezer temperature is cold enough, and inspect the ice maker module for proper operation.
What does “HRS” mean on GE System Messages?
HRS indicates high refrigerator temperature. Check door seals, condenser coils, and airflow. Ensure the compressor and fans are running properly.
What does “T1” mean on GE System Messages?
T1 is a freezer thermistor fault. Inspect sensor wiring, test resistance values, and replace the thermistor if readings are incorrect.
What does “T2” mean on GE System Messages?
T2 indicates a fresh food thermistor fault. Check wiring connections, sensor placement, and replace the sensor if it is not reading correctly.
What does “FF” mean on GE System Messages?
FF indicates a fresh food temperature sensor error. Inspect wiring, check for frost buildup, and test sensor resistance for proper operation.
What does “LOCK” mean on GE System Messages?
LOCK means control lock is enabled. Press and hold the lock button for 3–5 seconds to unlock or power cycle the unit if controls remain frozen.
What does “HOT” mean on GE System Messages?
HOT indicates high temperature inside the refrigerator. Check ventilation, allow cooling time, and ensure fans and compressor are operating normally.
What does “COOL” mean on GE System Messages?
COOL means the cooling cycle is active. Do not disconnect power and allow the system to complete its cooling process before checking performance.
What does “RESET” mean on GE System Messages?
RESET means the system requires a restart. Turn off the appliance, disconnect power for 5–10 minutes, then restore power and restart operation.
What does “ERR” mean on GE System Messages?
ERR indicates a general system fault. Perform a full reset, check wiring connections, and review for additional error codes on the display.
What does flashing “PF” mean on GE System Messages?
A flashing PF means unstable or repeated power interruptions. Check outlet stability, breaker condition, and use surge protection if needed.
Important: If the error code continues after troubleshooting, disconnect power immediately and contact a certified GE technician.
