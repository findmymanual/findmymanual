Midea Washer Error Codes

Complete Troubleshooting & Diagnostic Guide

Water Supply & Drain Errors
E10
Water Inlet Timeout
  • Ensure water supply valves are fully open.
  • Inspect inlet hose for kinks or blockage.
  • Clean inlet filter screens.
  • Test inlet valve operation.
E11
Drain Error
  • Inspect drain hose for blockage or bends.
  • Clean drain pump filter.
  • Check drain pump operation.
  • Replace pump if malfunctioning.
E12
Water Overflow Detected
  • Turn off water supply immediately.
  • Inspect pressure sensor and hose.
  • Check inlet valve for continuous filling.
  • Replace faulty water level components.
Door System Errors
E13
Door Lock Failure
  • Ensure door is fully closed.
  • Inspect door latch and strike assembly.
  • Check wiring to door lock mechanism.
  • Replace door lock if defective.
Motor System Errors
E21
Motor Failure
  • Inspect motor wiring connections.
  • Check drive belt and drum movement.
  • Test motor resistance values.
  • Replace motor if faulty.
E22
Motor Speed Abnormal
  • Inspect tachometer sensor wiring.
  • Check motor control board operation.
  • Ensure drum rotates freely.
  • Replace tachometer or motor if needed.
Heating System Errors
E30
Heating Error
  • Test heating element continuity.
  • Inspect heater wiring and connectors.
  • Check thermal protection devices.
  • Replace heating element if defective.
Temperature Sensor Errors
E31
Temperature Sensor Fault
  • Inspect thermistor wiring connections.
  • Test sensor resistance values.
  • Check for corrosion or moisture damage.
  • Replace sensor if readings are incorrect.
Important: If error codes continue after troubleshooting, disconnect power and contact a certified Midea technician.
