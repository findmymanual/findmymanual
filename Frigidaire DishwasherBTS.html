Frigidaire Dishwasher Error Codes

Complete Troubleshooting & Repair Guide

Water System Errors
i10
Water Fill Issue
  • Check water supply valve is fully open.
  • Inspect inlet hose for kinks or blockage.
  • Clean inlet filter screen.
  • Verify household water pressure.
i20
Drain Blockage
  • Inspect drain hose for clogs or bends.
  • Clean filter and sump area.
  • Check drain pump operation.
  • Ensure proper drain installation height.
i30
Leak Detected (Float Switch)
  • Check for water leakage under unit.
  • Inspect float switch movement.
  • Dry base pan and remove standing water.
  • Check hoses and seals for cracks.
Sensor Errors
i40
Pressure Sensor Fault
  • Inspect pressure sensor hose for blockage.
  • Check wiring connections to sensor.
  • Test sensor response with multimeter.
  • Replace pressure sensor if faulty.
Motor & Wash System Errors
i50
Wash Motor Failure
  • Check wash pump for obstruction.
  • Inspect motor wiring and connectors.
  • Test motor resistance and operation.
  • Replace wash motor if needed.
Heating System Errors
i60
Heating Issue
  • Check heating element continuity.
  • Inspect thermostat and wiring.
  • Ensure proper water temperature supply.
  • Replace heater if faulty.
Control System Errors
iC0
Control Board Error
  • Reset dishwasher by cutting power for 5–10 minutes.
  • Inspect main control board connections.
  • Check for moisture or corrosion on PCB.
  • Replace control board if issue persists.
Important: If errors continue after troubleshooting, disconnect power and contact a certified Frigidaire technician.
