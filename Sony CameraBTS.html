Sony Camera Error Codes

Diagnostic & Troubleshooting Guide

Stabilization System Errors
E:62:10
SteadyShot Error
  • Turn camera off and remove battery.
  • Check for lens or sensor movement blockage.
  • Reinsert battery and restart camera.
  • Service stabilizer unit if error persists.
Focus System Errors
E:61:00
Autofocus Malfunction
  • Clean lens contacts carefully.
  • Reattach lens securely.
  • Test with another lens if available.
  • Service AF motor if problem continues.
Internal System Errors
E:91:01
Internal System Error
  • Power cycle camera.
  • Remove memory card and retry.
  • Reset camera settings.
  • Update firmware if available.
Memory Card Errors
C:32:60
Memory Card Error
  • Remove and reinsert memory card.
  • Format card in camera.
  • Try a different SD card.
  • Check card compatibility.
Lens System Errors
E:94:00
Lens Communication Failure
  • Clean lens contacts.
  • Reattach lens properly.
  • Test with another compatible lens.
  • Service lens mount if needed.
Shutter System Errors
E:92:10
Shutter Malfunction
  • Power cycle the camera.
  • Check for physical obstruction.
  • Test shutter in different modes.
  • Repair shutter mechanism if faulty.
Important: Camera internal mechanical errors may require professional servicing.
