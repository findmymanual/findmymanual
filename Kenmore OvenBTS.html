Kenmore Oven / Range Error Codes

Complete Troubleshooting & Repair Guide

Control System Errors
F1
Control Board Failure
  • Disconnect power for 5–10 minutes.
  • Inspect electronic control board for damage.
  • Check wiring harness connections.
  • Replace control board if error returns.
F6
Communication Error
  • Inspect ribbon cable and wiring connections.
  • Power cycle the oven.
  • Check for loose or corroded connectors.
  • Replace faulty communication board if needed.
F7
Keypad Error
  • Inspect keypad for stuck buttons.
  • Clean control panel surface.
  • Reconnect keypad ribbon cable.
  • Replace keypad assembly if faulty.
Temperature System Errors
F2
Over-Temperature Condition
  • Turn off oven and allow cooling.
  • Check temperature sensor resistance.
  • Inspect cooling fan operation.
  • Replace sensor or control board if needed.
F3
Temperature Sensor Error
  • Test oven sensor resistance.
  • Inspect sensor wiring for damage.
  • Check sensor connector security.
  • Replace temperature sensor if defective.
Door System Errors
F4
Door Switch Issue
  • Ensure oven door closes completely.
  • Inspect door latch and switch alignment.
  • Test door switch continuity.
  • Replace switch if malfunctioning.
Heating System Errors
F5
Heating Element Failure
  • Inspect bake and broil elements for damage.
  • Test element continuity.
  • Check wiring and relay output.
  • Replace defective heating element.
Important: If error codes continue after troubleshooting, disconnect power and contact a certified Kenmore technician.
