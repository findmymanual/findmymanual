Shark Robot Vacuum Error Codes

Complete Robot Navigation & System Troubleshooting Guide

Cleaning System Errors
CLN
Cleaning System Blocked
  • Turn off robot vacuum.
  • Check suction inlet for debris or blockage.
  • Clean filters and dust pathway.
  • Restart cleaning cycle.
Navigation Sensor Errors
CLIFF
Cliff Sensor Error Detected
  • Clean cliff sensors underneath unit.
  • Ensure robot is not on reflective surface.
  • Move robot to flat floor area.
  • Restart mapping cycle.
Movement System Errors
WHEEL
Wheel Jam or Obstruction
  • Turn off robot before inspection.
  • Remove hair, threads, or debris from wheels.
  • Ensure wheels spin freely.
  • Restart unit after cleaning.
Brush System Errors
BRUSH
Brush Roller Jammed
  • Remove brush roller carefully.
  • Clean hair and debris from roller ends.
  • Check belt and mounting alignment.
  • Reinstall and test operation.
Dust System Errors
BIN
Dust Bin Full or Missing
  • Empty dust bin completely.
  • Reinsert bin securely into place.
  • Check bin sensor contacts.
  • Restart cleaning cycle.
Important: Regular cleaning of sensors and brushes helps maintain optimal navigation performance.
