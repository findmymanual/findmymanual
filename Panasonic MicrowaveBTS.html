Panasonic Microwave Error Codes

System Diagnostic & Safety Guide

Inverter System Errors
H97
Inverter Circuit Failure
  • Turn microwave off immediately.
  • Check inverter board for damage or loose connections.
  • Ensure proper ventilation during use.
  • Replace inverter unit if fault persists.
Heating System Errors
H98
Magnetron Overheating
  • Allow microwave to cool completely.
  • Check cooling fan operation.
  • Ensure air vents are not blocked.
  • Inspect magnetron if overheating continues.
Power System Errors
H99
Power Supply Fault
  • Unplug microwave for 3–5 minutes.
  • Check power cord and outlet.
  • Inspect internal fuse if applicable.
  • Replace power board if necessary.
Safety Interlock Errors
U10
Door Switch Error
  • Ensure microwave door is fully closed.
  • Check door latch and switch alignment.
  • Clean door contact area.
  • Replace door switch if faulty.
Warning: Microwave inverter and magnetron systems contain high voltage components. Service should be performed by qualified technicians only.
