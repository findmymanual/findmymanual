Haier Microwave / Oven Error Codes

Complete Troubleshooting & Repair Guide

Temperature Sensor Errors
F1
Temperature Sensor Open
  • Check temperature sensor wiring connection.
  • Inspect sensor for physical damage.
  • Test continuity with multimeter.
  • Replace sensor if circuit is open.
F2
Temperature Sensor Shorted
  • Inspect sensor wiring for short circuit.
  • Check connector pins for corrosion.
  • Test resistance values.
  • Replace sensor if shorted.
Control & Communication Errors
F3
Keypad Communication Error
  • Inspect ribbon cable connection.
  • Clean control panel contacts.
  • Reset power to unit.
  • Replace control board if needed.
SE
Control Panel Shorted
  • Disconnect power immediately.
  • Check keypad for moisture damage.
  • Inspect membrane switch panel.
  • Replace control panel assembly.
Safety & Mechanical Errors
F4
Door Switch Fault
  • Check door latch alignment.
  • Inspect door switch operation.
  • Ensure door closes fully.
  • Replace door switch if faulty.
F5
Cooling Fan Malfunction
  • Inspect fan motor for obstruction.
  • Check wiring connections.
  • Clean dust buildup.
  • Replace fan motor if not working.
Important: If the issue persists after troubleshooting, disconnect power immediately and contact a qualified technician.
