Ninja Oven Error Codes

Troubleshooting & Repair Guide

E1
Temperature Sensor Error
  • Turn off and unplug the oven.
  • Allow unit to cool completely.
  • Check sensor wiring connections.
  • Clean sensor area from grease or residue.
  • Replace sensor if issue persists.
E2
Heating Element Issue
  • Disconnect power immediately.
  • Inspect heating element for visible damage.
  • Check electrical connections.
  • Replace heating element if faulty.
E3
Cooling Fan Issue
  • Check fan for obstruction or dust buildup.
  • Ensure fan spins freely.
  • Clean internal airflow paths.
  • Replace fan motor if necessary.
E4
Door Sensor Error
  • Ensure oven door is fully closed.
  • Inspect door latch mechanism.
  • Clean sensor contact points.
  • Replace door switch if faulty.
E5
System Failure
  • Power cycle the oven.
  • Check for electrical fluctuations.
  • Inspect main control board.
  • Contact service center if error continues.
E6
Heating Relay Failure
  • Turn off and unplug unit.
  • Inspect relay connections on PCB.
  • Check for burn marks or damage.
  • Replace relay or board if needed.
E7
Internal Fan Circulation Error
  • Inspect internal fan for blockage.
  • Clean grease buildup inside oven.
  • Check fan wiring connection.
  • Replace fan if not functioning.
E8
Power Regulation Fault
  • Check power supply stability.
  • Inspect internal power board.
  • Avoid using extension cords.
  • Contact technician if issue persists.
HOT
Overheat Warning
  • Turn off oven immediately.
  • Allow full cooling period.
  • Check ventilation around oven.
  • Ensure no blockage inside chamber.
ERR HEAT
Heating System Failure
  • Inspect heating components.
  • Check wiring and relays.
  • Restart after cooling.
  • Replace heating system if needed.
ERR FAN
Cooling Fan Failure
  • Check fan for obstruction.
  • Clean dust and grease buildup.
  • Test fan motor operation.
  • Replace fan if not working.
Important: Always disconnect power before servicing. If errors persist, contact Ninja support or a certified technician.
