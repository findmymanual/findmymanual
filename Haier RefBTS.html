Haier Refrigerator Error Codes

Complete Troubleshooting & Repair Guide

Sensor Errors
F1
Freezer Sensor Fault
  • Check freezer thermistor wiring connection.
  • Inspect sensor for frost or damage.
  • Test resistance values of sensor.
  • Replace sensor if readings are incorrect.
F2
Ambient Temperature Sensor Error
  • Inspect ambient sensor wiring harness.
  • Ensure sensor is not exposed to heat sources.
  • Test continuity of sensor circuit.
  • Replace sensor if faulty.
F3
Defrost Sensor Issue
  • Check defrost sensor connection.
  • Inspect evaporator area for ice buildup.
  • Test sensor resistance.
  • Replace sensor if defective.
F4
Refrigerator Temperature Sensor Fault
  • Inspect fridge compartment sensor wiring.
  • Check for loose connectors.
  • Test thermistor accuracy.
  • Replace sensor if needed.
Communication Errors
F5
Communication Error Between Boards
  • Check wiring between main and display board.
  • Inspect connectors for corrosion or looseness.
  • Reset power to system.
  • Replace control board if issue persists.
Ice Maker & Defrost System
E0
Ice Maker Malfunction
  • Check water supply line.
  • Inspect ice maker module for blockage.
  • Reset ice maker system.
  • Replace ice maker assembly if needed.
E1
Defrost Heater Error
  • Test defrost heater continuity.
  • Inspect wiring harness for damage.
  • Check defrost control board operation.
  • Replace heater if faulty.
Cooling System Errors
E2
Fan Motor Failure
  • Inspect evaporator fan for obstruction.
  • Check fan motor wiring.
  • Test fan motor operation.
  • Replace motor if not spinning.
Control Board Errors
E5
EEPROM Memory Error
  • Disconnect power for 10 minutes.
  • Check control board for damage.
  • Inspect firmware corruption issues.
  • Replace main PCB if necessary.
Important: If the error continues after troubleshooting, disconnect power immediately and contact a certified technician.
