Samsung Microwave / Oven Error Codes

Troubleshooting & Repair Guide

Sensor & Control Errors

SE
Keypad Error
  • Check keypad for stuck buttons.
  • Clean control panel surface.
  • Disconnect power for 5 minutes.
  • Replace membrane keypad if needed.
E-11
Sensor Failure
  • Inspect temperature sensor wiring.
  • Check for loose connections.
  • Test sensor resistance.
  • Replace sensor if faulty.
E-12
Temperature Sensor Short Circuit
  • Turn OFF power immediately.
  • Inspect sensor wiring damage.
  • Replace shorted sensor.
  • Check PCB input circuit.
E-13
Humidity Sensor Failure
  • Inspect humidity sensor connection.
  • Clean interior cavity.
  • Test sensor response.
  • Replace sensor if needed.

Heating System Errors

E-21
Magnetron Issue
  • Check magnetron connection.
  • Inspect for burning smell or damage.
  • Verify power supply.
  • Replace magnetron if faulty.
E-23
Magnetron Overheating
  • Check ventilation fan operation.
  • Clean internal cooling system.
  • Avoid continuous long cooking cycles.
  • Replace cooling fan if needed.
E-22
Inverter Failure
  • Turn OFF power immediately.
  • Inspect inverter board.
  • Check for burnt components.
  • Replace inverter board.

Door & Safety System Errors

E-41
Door Switch Error
  • Check door latch alignment.
  • Inspect door switches.
  • Clean door hooks.
  • Replace switch if faulty.
E-45
Door Latch Stuck
  • Inspect latch mechanism.
  • Remove debris from door area.
  • Check spring mechanism.
  • Replace latch assembly if needed.
E-42
Relay Failure
  • Check control board relay.
  • Inspect for burnt relay contacts.
  • Test power switching function.
  • Replace control board if needed.

Communication & Control Errors

C-F0
Communication Fault
  • Restart microwave.
  • Check control board wiring.
  • Inspect PCB connectors.
  • Replace board if needed.
C-F1
Control Board Failure
  • Disconnect power for 10 minutes.
  • Inspect PCB for damage.
  • Check voltage supply.
  • Replace control board if necessary.

Cooling System Errors

E-24
Cooling Fan Error
  • Check fan blade obstruction.
  • Inspect motor wiring.
  • Clean dust buildup.
  • Replace fan motor if needed.
Important: Microwave and oven repairs involve high voltage components. Always disconnect power before inspection and contact a qualified technician for magnetron or inverter issues.
