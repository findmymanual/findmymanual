Haier Refrigerator Error Codes

Complete Haier Refrigerator Guide

This guide explains all Haier Refrigerator error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

F1
Freezer Sensor Fault
  • Check freezer thermistor wiring connection.
  • Inspect sensor for frost or physical damage.
  • Test resistance values using a multimeter.
  • Replace sensor if readings are out of range.
F2
Ambient Temperature Sensor Error
  • Inspect ambient sensor wiring harness.
  • Avoid placing unit near heat sources.
  • Test sensor continuity.
  • Replace sensor if faulty.
F3
Defrost Sensor Issue
  • Check evaporator area for ice buildup.
  • Inspect defrost sensor connection.
  • Test sensor resistance values.
  • Replace sensor if defective.
F4
Refrigerator Temperature Sensor Fault
  • Inspect fridge compartment sensor wiring.
  • Check for loose or corroded connectors.
  • Test thermistor accuracy.
  • Replace sensor if readings are incorrect.
F5
Communication Error Between Boards
  • Check wiring between main control board and display board.
  • Inspect connectors for looseness or corrosion.
  • Reset power to the refrigerator for 5–10 minutes.
  • Replace control board if issue persists.
F6
Control Signal Failure
  • Inspect communication harness wiring.
  • Check for moisture damage on PCB.
  • Restart system after power reset.
  • Replace main board if signals are missing.
E0
Ice Maker Malfunction
  • Check water supply line is open.
  • Inspect ice maker for blockage or jam.
  • Reset ice maker module.
  • Replace ice maker assembly if needed.
E1
Defrost Heater Error
  • Test defrost heater continuity.
  • Inspect wiring harness for damage.
  • Check defrost control board operation.
  • Replace heater if faulty.
E3
Defrost System Failure
  • Inspect defrost timer or PCB control.
  • Check evaporator for ice buildup.
  • Test defrost sensor operation.
  • Replace faulty defrost components.
E2
Fan Motor Failure
  • Inspect evaporator fan for obstruction.
  • Check fan motor wiring connection.
  • Test fan motor operation.
  • Replace motor if not spinning.
E4
Compressor Start Failure
  • Check compressor relay or start capacitor.
  • Inspect wiring to compressor.
  • Ensure proper voltage supply.
  • Replace start relay or compressor if needed.
E5
EEPROM Memory Error
  • Disconnect power for 10 minutes.
  • Check main control board for damage.
  • Inspect for firmware corruption.
  • Replace PCB if error persists.
E6
Control Board Failure
  • Inspect PCB for burn marks or damage.
  • Check all wiring harness connections.
  • Reset power and retest system.
  • Replace main control board if needed.
F7
Door Switch Fault
  • Check if refrigerator door closes properly.
  • Inspect door switch alignment.
  • Test door switch continuity.
  • Replace door switch if faulty.
F8
High Temperature Alarm
  • Check if doors were left open too long.
  • Inspect condenser coils for dust buildup.
  • Ensure proper airflow inside compartments.
  • Allow unit to stabilize and reset alarm.
F9
Low Voltage Detection
  • Check household power supply stability.
  • Avoid using extension cords.
  • Inspect outlet and circuit breaker.
  • Use voltage stabilizer if needed.
E7
Evaporator Sensor Failure
  • Inspect evaporator sensor wiring.
  • Check sensor placement on coil.
  • Test resistance readings.
  • Replace sensor if readings are abnormal.
E8
Condenser Fan Error
  • Check condenser fan for obstruction.
  • Inspect fan motor wiring.
  • Clean dust and debris buildup.
  • Replace fan motor if not operating.
E9
Refrigerant System Issue
  • Check for weak cooling performance.
  • Inspect for possible refrigerant leak.
  • Verify compressor operation.
  • Contact technician for gas recharge or repair.
E10
Defrost Timeout Error
  • Check defrost heater operation.
  • Inspect defrost timer or PCB control.
  • Look for excessive ice buildup.
  • Reset unit after manual defrost.
E11
Ice Maker Sensor Fault
  • Check ice maker sensor connection.
  • Inspect for ice blockage in module.
  • Test sensor continuity.
  • Replace sensor or ice maker assembly if needed.
E12
Water Supply Failure
  • Check water inlet valve is open.
  • Inspect water line for blockage or kink.
  • Clean inlet filter screen.
  • Verify water pressure is sufficient.
E13
Ice Maker Motor Jam
  • Check ice tray for blockage or ice buildup.
  • Inspect motor gear for obstruction.
  • Reset ice maker module.
  • Replace motor assembly if jam persists.
E14
Overload Protection Activated
  • Reduce food load inside refrigerator.
  • Check compressor temperature.
  • Ensure proper ventilation around unit.
  • Allow system to cool before restart.
E15
System Communication Delay
  • Reset power to the refrigerator.
  • Check wiring between modules.
  • Inspect connectors for looseness.
  • Replace control board if issue continues.

Frequently Asked Questions


Why is my Haier refrigerator not cooling properly?
Check that temperature settings are set correctly for both fridge and freezer compartments. Clean condenser coils, ensure vents are not blocked, and verify door seals are tight. If cooling is still weak, inspect the compressor or thermostat.
Why is my Haier refrigerator not turning on?
Check the power outlet and circuit breaker. Ensure the refrigerator is properly plugged in, inspect the power cord for damage, and verify the internal fuse or control board if there is still no power.
Why is my Haier refrigerator making loud noise?
Check if the unit is level and not touching nearby surfaces. Inspect the evaporator fan and condenser fan for obstructions. Clean dust buildup around the compressor area.
Why is my Haier refrigerator leaking water?
Inspect the drain pan and defrost drain line for clogs. Check water inlet connections and ensure the fridge is properly leveled. Clear any ice buildup blocking drainage.
Why is my Haier refrigerator not making ice?
Check that the ice maker is turned on and water supply line is connected. Ensure freezer temperature is cold enough and inspect the water inlet valve for blockage.
Why is my Haier refrigerator ice maker producing small or hollow ice?
Check water pressure and filter condition. Replace clogged water filter, inspect inlet valve, and ensure freezer temperature is stable.
Why is my Haier refrigerator freezer not freezing?
Check temperature settings and ensure airflow is not blocked. Clean condenser coils and inspect evaporator fan and thermostat for faults.
Why does my Haier refrigerator smell bad?
Remove spoiled food, clean interior surfaces, and check drain pan for stagnant water. Replace or clean filters and ensure proper airflow.
Why is my Haier refrigerator door not sealing properly?
Inspect door gasket for dirt, damage, or warping. Clean the seal and ensure the door is aligned properly. Replace gasket if worn out.
Why is my Haier refrigerator running constantly?
Check door seals for air leaks and ensure vents are not blocked. Clean condenser coils and verify temperature settings are not too low.
Why is my Haier refrigerator light not working?
Check the door switch and replace the LED bulb if needed. Inspect wiring connections or control board if light still does not turn on.
Why is my Haier refrigerator water dispenser not working?
Check water supply line and filter condition. Ensure the reservoir is not frozen and inspect the dispenser switch for faults.
How do I reset my Haier refrigerator?
Unplug the refrigerator or switch off the breaker for 5–10 minutes. Restore power, allow the system to restart, and recheck temperature settings.
Why is my Haier refrigerator showing unusual behavior?
Check for power fluctuations, blocked airflow, or sensor issues. Reset the unit and inspect for any error indications on the display panel.
Why is my Haier refrigerator not defrosting?
Check the defrost heater, thermostat, and control board. Ice buildup may block airflow, so manually defrost the unit if necessary.
Why is my Haier refrigerator too warm inside?
Check thermostat settings and ensure doors are closing properly. Clean condenser coils, inspect evaporator fan, and avoid overloading shelves.
Why is my Haier refrigerator compressor hot or noisy?
Ensure proper ventilation around the unit. Dirty coils or a faulty start relay can cause overheating. If noise persists, inspect compressor components.
Important: If the error code continues after troubleshooting, disconnect power immediately and contact a certified GE technician.
