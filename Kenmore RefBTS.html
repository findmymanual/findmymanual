Kenmore Refrigerator Error Codes

Complete Troubleshooting & Diagnostic Guide

General System Errors
Er
General System Error
  • Disconnect power for 5–10 minutes.
  • Reconnect and allow system to restart.
  • Check for additional error codes.
  • Replace main control board if issue persists.
Fan System Errors
rF
Refrigerator Fan Fault
  • Inspect evaporator fan for ice blockage.
  • Check fan motor wiring connections.
  • Test fan motor operation.
  • Replace fan motor if defective.
CF
Condenser Fan Failure
  • Clean condenser fan and surrounding area.
  • Inspect fan blades for obstruction.
  • Test condenser fan motor.
  • Replace motor if not functioning.
Sensor Errors
FS
Freezer Sensor Fault
  • Inspect freezer thermistor wiring.
  • Test sensor resistance values.
  • Check for corrosion or loose connections.
  • Replace sensor if faulty.
Defrost System Errors
dF
Defrost System Failure
  • Check defrost heater continuity.
  • Inspect defrost thermostat and sensor.
  • Verify control board defrost cycle.
  • Replace faulty defrost components.
Door System Warnings
OP
Door Open Warning
  • Ensure refrigerator door is fully closed.
  • Inspect door gasket for leaks or damage.
  • Check door switch alignment.
  • Remove items blocking door closure.
Compressor System Errors
CO
Compressor Overload
  • Allow compressor to cool down.
  • Check condenser coils for dirt buildup.
  • Inspect start relay and capacitor.
  • Replace overload protector if faulty.
Important: If error codes continue after troubleshooting, disconnect power and contact a certified Kenmore technician.
