Whirlpool Dryer Error Codes

Complete Whirlpool Dryer Guide

This guide explains all Whirlpool Dryer error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

E1
Airflow Restriction Detected
  • Clean lint filter thoroughly.
  • Check exhaust vent for blockage or lint buildup.
  • Inspect vent hose for kinks or crushing.
  • Ensure proper airflow path to outside vent.
E2
Restricted Airflow / Vent Blockage
  • Remove lint from filter and housing.
  • Check external vent hood for obstruction.
  • Inspect blower wheel for debris buildup.
  • Verify vent installation length and routing.
E3
Overheating Protection Activated
  • Allow dryer to cool completely.
  • Clean lint filter and vent system.
  • Check thermal fuse condition.
  • Inspect heating element for faults.
E4
Low Voltage Detected
  • Verify household power supply stability.
  • Avoid using extension cords.
  • Check outlet and wiring connections.
  • Contact electrician if issue persists.
E5
Temperature Detection Fault
  • Allow unit to reach proper freezing temperature.
  • Check freezer environment stability.
  • Ensure pint is pre-frozen correctly.
  • Restart after 10–15 minutes.
PF
Power Failure During Cycle
  • Check power outlet stability.
  • Inspect plug and cord connection.
  • Reset breaker if tripped.
  • Restart dryer cycle.
E6
Unstable Voltage Supply
  • Check household voltage fluctuations.
  • Avoid multiple high-load appliances on same circuit.
  • Inspect wiring and breaker panel.
  • Use voltage stabilizer if needed.
F01
Main Electronic Control Fault
  • Reset dryer power for 10 minutes.
  • Inspect control board for damage.
  • Check wiring harness connections.
  • Replace control board if necessary.
F70
Communication Failure Between Boards
  • Check wiring between UI and main PCB.
  • Inspect connectors for corrosion or looseness.
  • Restart system power.
  • Replace PCB if fault continues.
F71
User Interface Communication Error
  • Inspect keypad ribbon cable.
  • Check UI board connections.
  • Reset dryer system.
  • Replace UI panel if needed.
F02
User Interface Keypad Issue
  • Clean control panel surface.
  • Check for stuck buttons.
  • Inspect ribbon cable connection.
  • Replace keypad assembly if needed.
F03
Control Board Memory Error
  • Perform full power reset.
  • Inspect main PCB for damage.
  • Check wiring connections.
  • Replace control board if error persists.
F20
Heater Relay Failure
  • Inspect heating relay on control board.
  • Check wiring to heating element.
  • Test heater continuity.
  • Replace relay if faulty.
F21
Heating Element Failure
  • Test heating element continuity.
  • Inspect wiring harness.
  • Check for burn marks on element.
  • Replace heater if defective.
F22
Outlet Thermistor Open
  • Check outlet thermistor wiring.
  • Test sensor resistance.
  • Inspect connector pins.
  • Replace thermistor if needed.
F23
Outlet Thermistor Shorted
  • Inspect thermistor wiring for short circuit.
  • Replace damaged sensor.
  • Check moisture damage near sensor.
F24
Inlet Thermistor Fault
  • Inspect inlet temperature sensor.
  • Check wiring harness.
  • Test resistance values.
  • Replace sensor if faulty.
F25
Inlet Thermistor Shorted
  • Check wiring for short circuit.
  • Inspect connector damage.
  • Replace thermistor if needed.
F28
Moisture Sensor Failure
  • Clean moisture sensor bars.
  • Check wiring connections.
  • Test sensor response.
  • Replace sensor if required.
F29
Moisture Sensor Shorted
  • Inspect sensor wiring.
  • Check for moisture damage.
  • Replace sensor assembly.
LOC
Control Lock Enabled
  • Press and hold control lock button for 3–5 seconds.
  • Check user manual for unlock sequence.
  • Reset power if panel is frozen.

Frequently Asked Questions


Why does my Whirlpool dryer show system messages or error codes?
Check airflow restriction system. Inspect lint filter and vent hose. Ensure proper power supply. Reset dryer and test again.
Why does my Whirlpool dryer stop working suddenly?
Check overheating protection system. Inspect thermal fuse and thermostat. Ensure stable voltage. Allow unit to cool before restarting.
Why is my Whirlpool dryer not drying clothes properly?
Check lint filter for blockage. Inspect exhaust vent for restriction. Ensure proper airflow path. Clean vent system and retry.
Why is my dryer taking too long to dry?
Inspect lint buildup and vent blockage. Check moisture sensor condition. Avoid overloading drum. Clean airflow system completely.
Why is my Whirlpool dryer not heating?
Check heating element for damage. Inspect thermal fuse and thermostat. Verify power supply. Replace faulty heating components if needed.
Why is the dryer overheating?
Check blocked vent system. Inspect thermostat and thermal cutoff. Clean lint filter. Allow dryer to cool before restarting.
Why does my Whirlpool dryer show sensor errors?
Check moisture sensor bars for dirt. Inspect wiring connections. Test sensor response. Clean sensors and restart cycle.
Why are clothes still damp after drying cycle?
Check moisture sensor calibration. Inspect vent airflow. Avoid overloading dryer. Clean sensor strips and retry cycle.
Why is my Whirlpool dryer not spinning?
Check drive belt condition. Inspect motor operation. Ensure door is fully closed. Replace belt or motor if faulty.
Why does my dryer make loud noises?
Check drum rollers and bearings. Inspect for loose objects inside drum. Verify motor condition. Tighten or replace worn parts.
Why does my Whirlpool dryer keep restarting?
Check power supply stability. Inspect control board and wiring. Avoid extension cords. Reset breaker and restart unit.
Why does my dryer not turn on at all?
Check outlet power and breaker. Inspect thermal fuse. Verify door switch is engaged. Test control board if needed.
Why does my Whirlpool dryer not start?
Check door switch engagement. Ensure door is fully closed. Inspect control settings. Replace door switch if faulty.
Why does my dryer show a door error?
Check door latch alignment. Inspect door switch wiring. Ensure no obstruction. Close door firmly and restart cycle.
Why does my dryer shut off mid-cycle?
Check thermal fuse and overheating protection. Inspect airflow restriction. Clean lint filter and vent system. Restart after cooling.
Why is my dryer displaying a general system error?
Check control board communication. Inspect wiring connections. Perform power reset. Replace PCB if error persists.
How do I reset Whirlpool dryer system messages?
Turn off dryer power. Unplug for 5–10 minutes. Restore power and restart cycle. Check if error returns.
When should I service my Whirlpool dryer?
Service if drying is slow. Service if overheating continues. Service if errors persist after reset. Service if unusual noises occur.
Important: Whirlpool dryer system messages are designed to protect key components such as the heating element, thermal fuse, thermostat, motor, drive belt, moisture sensors, airflow system, and control board. If problems continue after troubleshooting, disconnect power and contact a qualified appliance technician.
