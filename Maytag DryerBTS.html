Maytag Dryer Error Codes

Complete Troubleshooting & Repair Guide

Airflow & Ventilation Issues
AF
Restricted Airflow Detected
  • Clean lint filter thoroughly.
  • Check vent hose for blockages.
  • Inspect external exhaust outlet.
  • Ensure proper airflow path.
F4E3
Restricted Airflow Problem
  • Remove lint buildup inside vent system.
  • Check for crushed or blocked ducting.
  • Clean blower housing.
  • Reset dryer after maintenance.
Control System Errors
F1E1
Main Electronic Control Fault
  • Power cycle the dryer for 10 minutes.
  • Inspect wiring harness connections.
  • Check for moisture damage on PCB.
  • Replace control board if necessary.
User Interface Errors
F2E1
Stuck Key Detected
  • Clean control panel surface.
  • Check for moisture or detergent residue.
  • Press all buttons to release stuck key.
  • Replace UI panel if issue persists.
Sensor Errors
F3E1
Exhaust Thermistor Open
  • Inspect thermistor wiring connections.
  • Check for broken sensor leads.
  • Test resistance values.
  • Replace thermistor if open circuit detected.
F3E2
Exhaust Thermistor Shorted
  • Check sensor wiring for short circuit.
  • Inspect connector pins for corrosion.
  • Test resistance readings.
  • Replace thermistor if shorted.
Communication Errors
F6E3
Communication Error
  • Inspect wiring between control boards.
  • Check connectors for corrosion or looseness.
  • Power cycle the unit.
  • Replace PCB if communication fails.
System / Drain Message
F9E1
Long Drain Issue
  • Check drain pump operation.
  • Inspect drain hose for blockage.
  • Clean lint and debris from system.
  • Reset appliance after inspection.
Control Messages
LOC
Control Lock Enabled
  • Press and hold control lock button for 3–5 seconds.
  • Check user manual for unlock sequence.
  • Reset power if controls are unresponsive.
  • Ensure no stuck buttons on panel.
Important: If the error persists after troubleshooting, disconnect power immediately and contact a certified Maytag technician.
