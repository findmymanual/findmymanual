Bosch Oven & Cooker Error Codes

Complete Troubleshooting & Repair Guide

Heating & Sensor Errors
E011
Temperature Sensor Error
  • Check sensor connection and wiring.
  • Inspect for loose or damaged cables.
  • Clean sensor area if dirty.
  • Replace sensor if readings are abnormal.
E012
Heating Element Failure
  • Inspect heating element for damage.
  • Check continuity with a multimeter.
  • Verify power supply to heater.
  • Replace heating element if faulty.
E016 / E005
Overheating Protection Activated
  • Turn off appliance immediately.
  • Allow oven to cool completely.
  • Check ventilation and airflow.
  • Inspect thermostat and safety cut-off.
Cooling Fan Errors
E013 / E115
Cooling Fan Error
  • Inspect fan motor for dust or blockage.
  • Check wiring connections.
  • Ensure fan spins freely.
  • Replace fan motor if needed.
Door Lock Errors
E014 / E118
Door Lock Issue
  • Ensure door is fully closed.
  • Inspect latch mechanism.
  • Check lock switch wiring.
  • Replace door lock assembly if faulty.
Control Board & Power Errors
E015
Control Board Failure
  • Reset power supply.
  • Inspect PCB for burn marks.
  • Check wiring harness connections.
  • Replace control board if needed.
E017
Power Supply Issue
  • Check outlet voltage.
  • Inspect power cable for damage.
  • Reset circuit breaker.
  • Test appliance on stable power source.
E305
Control Board Communication Fault
  • Disconnect power for 5–10 minutes.
  • Check internal wiring connections.
  • Inspect PCB communication lines.
  • Replace control board if error persists.
Heating System Errors
E512
Heating Element Failure
  • Inspect heating coil for damage.
  • Check electrical resistance.
  • Verify power supply to heater.
  • Replace heating element if needed.
Important: Always disconnect power before servicing. If errors continue after troubleshooting, contact a qualified technician.
