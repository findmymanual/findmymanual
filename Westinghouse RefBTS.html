Westinghouse Refrigerator Error Codes

Complete Troubleshooting & Repair Guide

Temperature Sensor Errors
F1
Freezer Temperature Sensor Fault
  • Check freezer thermistor connection.
  • Inspect wiring harness for damage or corrosion.
  • Test sensor resistance with multimeter.
  • Replace sensor if readings are incorrect.
F2
Fridge Temperature Sensor Fault
  • Inspect fridge thermistor wiring.
  • Check connector pins for looseness.
  • Test resistance values at room temperature.
  • Replace sensor if faulty.
Defrost System Errors
F3
Defrost Sensor Failure
  • Inspect defrost sensor wiring.
  • Check for ice buildup around sensor.
  • Test continuity with multimeter.
  • Replace sensor if defective.
F8
Defrost Heater Failure
  • Check heater element continuity.
  • Inspect wiring connections.
  • Verify defrost cycle operation.
  • Replace heater if faulty.
Fan System Errors
F4
Evaporator Fan Error
  • Check fan blade for obstruction or ice buildup.
  • Inspect wiring connections.
  • Test fan motor operation.
  • Replace fan motor if not running.
F5
Condenser Fan Fault
  • Clean condenser coil and fan area.
  • Check fan blade for damage.
  • Inspect wiring harness.
  • Replace fan motor if necessary.
Compressor & Power Errors
F6
Compressor Overload Protection
  • Allow compressor to cool down.
  • Check power supply stability.
  • Inspect start relay and capacitor.
  • Replace compressor components if needed.
F9
Power Supply Instability
  • Check household voltage supply.
  • Inspect power cord and plug.
  • Reset appliance power.
  • Use voltage stabilizer if needed.
Communication Errors
F7
Communication Error Between Boards
  • Inspect wiring between control boards.
  • Check connectors for corrosion or looseness.
  • Perform full power reset.
  • Replace main PCB if issue persists.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified Westinghouse technician.
