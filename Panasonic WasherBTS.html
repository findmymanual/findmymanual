Panasonic Washing Machine Error Codes

System Diagnostic & Troubleshooting Guide

Water System Errors
U11
Drain Error
  • Check drain hose for blockage or kinks.
  • Clean drain filter and pump.
  • Ensure proper installation height of hose.
  • Restart wash cycle after cleaning.
U12
Door Open
  • Close door firmly until locked.
  • Check door latch mechanism.
  • Remove obstructions from door seal.
  • Restart machine after securing door.
U14
Water Supply Error
  • Check water inlet tap is open.
  • Inspect inlet hose for blockage.
  • Clean inlet filter screen.
  • Ensure sufficient water pressure.
Load & Balance Errors
U13
Unbalanced Load
  • Redistribute clothes evenly in drum.
  • Avoid overloading washer.
  • Wash heavy items separately.
  • Restart spin cycle.
Pump System Errors
U18
Pump Failure
  • Check drain pump for blockage.
  • Clean lint and debris from pump filter.
  • Inspect pump motor wiring.
  • Replace pump if faulty.
Control System Errors
H01
Main Control Board Error
  • Restart washing machine.
  • Check power supply stability.
  • Inspect control board connections.
  • Replace PCB if issue persists.
H04
Motor Control Fault
  • Check motor wiring harness.
  • Inspect drive motor for damage.
  • Reset control system.
  • Replace motor driver board if needed.
Note: Electrical and control board issues should be handled by qualified technicians for safety.
