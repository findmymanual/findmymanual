LG Refrigerator Error Codes

Complete LG Refrigerator Guide

This guide explains all LG Refrigerator error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

ER FF
Freezer Fan Failure
  • Check freezer fan for ice blockage.
  • Inspect fan motor operation.
  • Defrost unit if ice buildup is present.
  • Replace fan motor if faulty.
ER IF
Ice Fan Error
  • Inspect ice fan for obstruction.
  • Check wiring connections.
  • Defrost ice compartment.
  • Replace fan motor if not spinning.
ER DH
Defrost Heater Fault
  • Check defrost heater continuity.
  • Inspect wiring harness.
  • Look for ice buildup on evaporator.
  • Replace heater if defective.
ER CO
Communication Error
  • Reset power for 5–10 minutes.
  • Check main PCB connections.
  • Inspect wiring between control boards.
  • Call technician if the issue persists.
ER FS
Freezer Sensor Error
  • Check sensor wiring connections.
  • Inspect freezer temperature sensor.
  • Ensure connectors are properly seated.
  • Replace sensor if faulty.
ER CF
Condenser Fan Error
  • Clean condenser fan and surrounding area.
  • Check fan motor operation.
  • Remove dust and debris buildup.
  • Replace fan motor if not working.
ER RS
Refrigerator Sensor Error
  • Inspect refrigerator temperature sensor.
  • Check wiring connections.
  • Restart unit after power reset.
  • Replace sensor if faulty.
ER DS
Damper Sensor Error
  • Check air damper movement.
  • Inspect sensor wiring connections.
  • Ensure no airflow blockage.
  • Replace damper assembly if needed.
22 / 33
Compressor Fault (Model Dependent)
  • Check power supply stability.
  • Inspect compressor wiring connections.
  • Listen for abnormal compressor noise.
  • Contact technician for diagnosis.
ER HS
Humidity Sensor Error
  • Inspect humidity sensor connection.
  • Clean sensor area inside compartment.
  • Restart refrigerator.
  • Replace sensor if faulty.
ER TS
Temperature Sensor Failure
  • Check thermistor wiring connections.
  • Inspect sensor placement.
  • Reset power to the unit.
  • Replace sensor if needed.
ER IS
Ice Maker Sensor Error
  • Check ice maker wiring connections.
  • Inspect water supply line.
  • Reset ice maker module.
  • Replace sensor if faulty.
ER SS
Pantry Sensor Error
  • Check pantry drawer sensor alignment.
  • Inspect wiring connections.
  • Ensure drawer closes properly.
  • Replace sensor if needed.
ER RT
Room Temperature Sensor Error
  • Inspect ambient temperature sensor.
  • Check wiring harness connections.
  • Restart refrigerator after reset.
  • Replace sensor if defective.
OFF
Demo Mode Enabled
  • Press and hold control panel buttons to exit demo mode.
  • Check settings menu for demo mode option.
  • Unplug refrigerator for a full reset.
  • Refer to model manual for instructions.
ER GF
Flow Sensor Issue
  • Check water inlet line for blockage.
  • Inspect flow sensor for debris.
  • Clean water filter.
  • Replace sensor if needed.

Frequently Asked Questions


What does ER FF mean on an LG refrigerator?
The ER FF error indicates a freezer fan failure. This usually happens due to ice buildup blocking the fan or a faulty fan motor that needs inspection or replacement.
How do I fix ER IF error on my LG fridge?
ER IF means there is an ice fan issue. Check for obstructions, defrost the ice compartment, inspect wiring connections, and replace the fan if it is not spinning.
What causes ER DH error in LG refrigerators?
ER DH indicates a defrost heater fault. This may be due to a defective heater, damaged wiring, or heavy ice buildup on the evaporator preventing proper defrosting.
How do I resolve ER CO communication error?
ER CO occurs when there is a communication failure between control boards. Reset the refrigerator by unplugging it for 5–10 minutes and inspect wiring connections.
What should I do if my LG fridge shows ER FS?
ER FS indicates a freezer sensor issue. Check sensor wiring and connectors, then replace the sensor if it is faulty or giving incorrect readings.
What does ER CF mean on an LG refrigerator?
ER CF refers to a condenser fan failure. Clean dust buildup, check fan motor operation, and replace the fan if it is not working properly.
How do I fix ER RS refrigerator sensor error?
ER RS means the refrigerator temperature sensor is faulty or disconnected. Inspect wiring, restart the unit, and replace the sensor if necessary.
What causes ER DS damper sensor error?
ER DS occurs when the air damper is stuck or the sensor is malfunctioning. Check airflow blockage and ensure the damper moves freely.
What does ER HS mean on LG fridges?
ER HS indicates a humidity sensor issue. Clean the sensor area, check connections, and replace the sensor if the problem persists.
How do I fix ER TS temperature sensor failure?
ER TS means the thermistor is not working correctly. Inspect wiring, reset power, and replace the sensor if readings remain abnormal.
What does ER IS mean on LG refrigerator ice maker?
ER IS indicates an ice maker sensor error. Check water supply, inspect wiring, and reset the ice maker module to restore operation.
What is ER SS error in LG fridge?
ER SS refers to a pantry drawer sensor issue. Ensure the drawer is properly aligned and check for wiring or sensor failure.
What does ER RT mean on LG refrigerator?
ER RT indicates a room temperature sensor error. Inspect the ambient sensor and wiring, and replace the sensor if necessary.
What is OFF mode on LG refrigerator display?
OFF means the refrigerator is in demo mode. Disable it through the control panel or by holding the settings buttons depending on your model.
How do I fix ER GF water flow sensor issue?
ER GF indicates a water flow sensor problem. Check the water inlet line, clean the filter, and replace the sensor if blockage or failure persists.
What should I do if LG refrigerator error codes keep coming back?
If error codes keep returning after troubleshooting, this may indicate deeper electrical or control board issues that require professional diagnosis.
Important: If the error persists after troubleshooting, disconnect power and contact an authorized LG refrigerator technician for further inspection and repair. Continued operation with recurring faults may cause cooling failure or component damage.
