Electrolux Refrigerator Error Codes

Complete Troubleshooting & Repair Guide

Fan System Errors
SY EF
Evaporator Fan Failure
  • Check evaporator fan motor for obstruction.
  • Inspect wiring connections.
  • Test fan motor continuity.
  • Replace fan motor if not operating.
SY CF
Condenser Fan Failure
  • Clean condenser coils and fan area.
  • Check fan blade for blockage or damage.
  • Inspect wiring harness.
  • Replace condenser fan motor if needed.
SY CF1
Compressor Fan Issue
  • Inspect compressor fan operation.
  • Check for debris or obstruction.
  • Test motor resistance.
  • Replace fan assembly if faulty.
Communication Errors
SY CE
Communication Error Between Boards
  • Check wiring harness between control boards.
  • Inspect connectors for corrosion or looseness.
  • Reset power supply for 5–10 minutes.
  • Replace main PCB if issue persists.
Sensor Errors
SY FF
Freezer Sensor Fault
  • Check freezer thermistor connection.
  • Inspect wiring for damage.
  • Test sensor resistance.
  • Replace sensor if readings are abnormal.
SH
Shorted Humidity Sensor
  • Inspect humidity sensor wiring.
  • Check for moisture damage.
  • Test sensor continuity.
  • Replace sensor if shorted.
System Warnings
OP
Door Open Warning
  • Ensure refrigerator door is fully closed.
  • Check door gasket for damage.
  • Inspect door switch sensor.
  • Remove any obstruction blocking closure.
Defrost System Errors
DF
Defrost Failure
  • Check defrost heater continuity.
  • Inspect defrost timer or control board.
  • Verify wiring connections.
  • Replace defrost heater if faulty.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified Electrolux technician.
