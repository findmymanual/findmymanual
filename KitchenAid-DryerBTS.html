KitchenAid Dryer Error Codes

Complete KitchenAid Dryer Guide

This guide explains all KitchenAid Dryer error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

AF
Restricted Airflow Detected
  • Clean lint filter thoroughly.
  • Check exhaust vent for blockage or lint buildup.
  • Inspect vent hose for kinks or damage.
  • Ensure proper airflow outside vent outlet.
F01
Main Control Failure
  • Reset power by unplugging dryer for 5–10 minutes.
  • Inspect control board for burn marks.
  • Check wiring harness connections.
  • Replace main control board if needed.
F02
Keypad / UI Stuck
  • Clean control panel surface.
  • Check for moisture or debris under buttons.
  • Inspect ribbon cable connection.
  • Replace UI panel if issue persists.
F22
Exhaust Thermistor Fault
  • Check thermistor resistance with multimeter.
  • Inspect wiring harness for damage.
  • Ensure proper connection to control board.
  • Replace thermistor if readings are abnormal.
F28
Moisture Sensor Failure
  • Clean moisture sensor strips inside drum.
  • Check wiring connections to sensor.
  • Test sensor response with damp cloth.
  • Replace sensor if readings fail.
F70
Communication Error
  • Check wiring between control modules.
  • Inspect connectors for looseness or corrosion.
  • Perform full system power reset.
  • Replace control board if communication fails.
F21 / E21
Motor Failure / Drum Jam
  • Check drum for blockage.
  • Inspect motor and drive belt.
  • Remove load imbalance.
  • Replace motor if needed.
F03
Heating Element Failure
  • Check heating element continuity.
  • Inspect thermal fuse and thermostat.
  • Check wiring connections.
  • Replace heating element if defective.
F04
High Temperature Warning
  • Clean lint filter and exhaust vent.
  • Check airflow restrictions.
  • Inspect thermal cutoff switch.
  • Allow dryer to cool before restart.
F05
Temperature Sensor Error
  • Check thermistor wiring connections.
  • Test sensor resistance values.
  • Inspect for moisture damage.
  • Replace sensor if readings are incorrect.
F06
Drum Not Spinning
  • Inspect drive belt condition.
  • Check motor operation.
  • Ensure drum is not overloaded.
  • Replace belt or motor if needed.
F07
Power Supply Instability
  • Check outlet voltage stability.
  • Inspect power cord for damage.
  • Reset circuit breaker.
  • Contact electrician if issue persists.
F08
Blower Wheel Blocked
  • Inspect blower housing for lint buildup.
  • Clean blower wheel and housing.
  • Check motor shaft alignment.
  • Replace blower motor if damaged.
F09
Drying Cycle Timeout
  • Check vent system for blockage.
  • Clean lint filter thoroughly.
  • Reduce load size.
  • Restart cycle after cleaning.

Frequently Asked Questions


Why does my KitchenAid dryer not respond?
Check power supply, control lock status, and system connection. Ensure the unit is properly plugged in and reset the dryer system.
Why is my KitchenAid dryer not starting?
Check door switch and power supply. Ensure the door is fully closed and control panel is responsive. Reset the system if needed.
Why is my KitchenAid dryer not drying clothes properly?
Check lint filter, vent system, and heating element. Remove blockages and ensure proper airflow during drying cycles.
Why is my KitchenAid dryer not heating?
Inspect heating element, thermal fuse, and thermostat. Ensure stable power supply and reset the dryer system.
Why is my KitchenAid dryer making unusual noises?
Inspect drum rollers, belt, and blower wheel. Remove any debris or foreign objects inside the drum area.
Why does my KitchenAid dryer stop mid-cycle?
Check overheating protection, power interruptions, and door switch. Allow unit to cool before restarting.
Why is my KitchenAid dryer taking too long to dry?
Check lint filter and exhaust vent for blockages. Reduce load size and ensure proper airflow system operation.
Why is my KitchenAid dryer leaking hot air or smelling burnt?
Check lint buildup inside vent system. Clean exhaust duct and inspect heating element for damage or residue.
Why is my KitchenAid dryer display not working?
Check power connection, control board, and display wiring. Restart system and inspect control panel.
Why is my KitchenAid dryer showing an error code?
Note the error code displayed. Reset the dryer and inspect sensors, wiring, or control board if needed.
Why is my KitchenAid dryer drum not spinning?
Check drive belt, motor, and drum rollers. Replace worn or broken belt if necessary.
How do I reset my KitchenAid dryer system messages?
Turn off power for 5–10 minutes, then restore power to reset system errors and clear temporary faults.
Important: If the dryer continues to show errors after troubleshooting, disconnect power and contact a certified KitchenAid technician.
