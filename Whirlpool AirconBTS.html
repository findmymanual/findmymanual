Whirlpool Air Conditioner Error Codes

Troubleshooting & Repair Guide

Sensor Errors
E1
Room Temperature Sensor Error
  • Check room sensor wiring connection.
  • Clean dust around sensor area.
  • Test resistance of thermistor.
  • Replace sensor if faulty.
E2
Indoor Coil Sensor Fault
  • Inspect coil sensor wiring.
  • Check evaporator coil for icing.
  • Test sensor continuity.
  • Replace sensor if needed.
Fan System Errors
E3
Fan Motor Speed Error
  • Check fan motor wiring.
  • Inspect fan blades for blockage.
  • Test motor capacitor.
  • Replace fan motor if faulty.
Communication Errors
E4
Communication Failure
  • Inspect indoor and outdoor wiring.
  • Check control board connections.
  • Restart unit after power reset.
  • Replace PCB if issue persists.
Compressor Protection
E5
Compressor Overload Protection
  • Turn off unit and allow cooling.
  • Check refrigerant pressure.
  • Inspect compressor wiring.
  • Call technician if repeated.
Power Protection Errors
P1
Voltage Protection Activated
  • Check power supply stability.
  • Inspect circuit breaker.
  • Use voltage stabilizer if needed.
  • Restart unit after power reset.
P2
High Temperature Protection
  • Clean air filters and condenser coil.
  • Ensure proper airflow.
  • Check outdoor unit ventilation.
  • Allow system to cool before restart.
Important: If the error continues after troubleshooting, disconnect power immediately and contact a certified technician.
