Whirlpool Dishwasher Error Codes

Complete Troubleshooting & Repair Guide

Control System Errors
F1 E1
Control Board Failure
  • Restart dishwasher power for 10 minutes.
  • Inspect main control board for burn marks.
  • Check wiring connections.
  • Replace PCB if fault persists.
F2 E1
Stuck Keypad Button
  • Clean control panel surface.
  • Check for stuck or damaged buttons.
  • Inspect ribbon cable connection.
  • Replace UI panel if needed.
Wash System Errors
F4 E3
Wash Motor Not Running
  • Inspect wash pump motor.
  • Check wiring connections.
  • Clear debris blocking impeller.
  • Replace motor if faulty.
Door System Errors
F5 E1
Door Switch Problem
  • Check door latch alignment.
  • Inspect door switch wiring.
  • Ensure door closes properly.
  • Replace door switch if needed.
Water System Errors
F6 E1
Water Inlet Issue
  • Check water supply valve.
  • Clean inlet filter screen.
  • Inspect inlet valve solenoid.
  • Ensure proper water pressure.
Heating System Errors
F7 E1
Heating Circuit Problem
  • Inspect heating element.
  • Check thermal fuse.
  • Test wiring connections.
  • Replace heater if needed.
Drain System Errors
F8 E2
Drain Motor Electrical Issue
  • Inspect drain pump motor.
  • Check wiring harness.
  • Remove debris from pump.
  • Replace pump if faulty.
F9 E1
Drain System Problem
  • Clean drain hose and filter.
  • Check for blockage in pump.
  • Inspect drain valve operation.
  • Restart cycle after cleaning.
Overflow Protection
F8 E4
Overflow / Float Switch Activated
  • Check for water leakage inside unit.
  • Inspect float switch movement.
  • Clean base tray of dishwasher.
  • Dry unit and reset system.
Important: If the issue continues after troubleshooting, disconnect power and contact a qualified technician.
