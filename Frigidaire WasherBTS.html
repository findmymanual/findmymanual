Frigidaire Washer Error Codes

Complete Troubleshooting & Repair Guide

Water System Errors
E11
Water Fill Timeout
  • Check water supply valves are fully open.
  • Inspect inlet hose for blockage or kinks.
  • Clean inlet filter screens.
  • Verify water pressure is adequate.
E12
Drain Timeout
  • Inspect drain hose for clogs or bends.
  • Clean drain pump filter.
  • Check drain pump operation.
  • Ensure proper drain height installation.
E13
Pressure Sensor Fault
  • Check pressure sensor hose for blockage.
  • Inspect wiring connections to sensor.
  • Test sensor resistance with multimeter.
  • Replace pressure sensor if faulty.
Motor System Errors
E21
Motor Not Running
  • Check drum for mechanical blockage.
  • Inspect motor wiring connections.
  • Test motor capacitor (if applicable).
  • Replace motor if no response.
E22
Motor Triac Failure
  • Inspect control board for burnt components.
  • Check motor triac circuit.
  • Reset machine power.
  • Replace main PCB if required.
E52
Overspeed Detected
  • Stop machine immediately.
  • Check motor speed sensor (tachometer).
  • Inspect control board calibration.
  • Replace motor control board if needed.
Door Lock System Errors
E23
Door Lock Failure
  • Check door latch alignment.
  • Inspect door lock switch wiring.
  • Ensure door closes properly.
  • Replace door lock assembly if faulty.
E24
Door Unlock Failure
  • Wait 1–2 minutes after cycle ends.
  • Reset power supply.
  • Check door lock mechanism for jam.
  • Replace lock motor if stuck.
Sensor & Temperature Errors
E31
Temperature Sensor Error
  • Inspect temperature sensor wiring.
  • Test sensor resistance values.
  • Check connector pins for corrosion.
  • Replace sensor if readings are incorrect.
E32
Heating Element Fault
  • Check heating element continuity.
  • Inspect wiring harness for damage.
  • Test control relay operation.
  • Replace heater if faulty.
Control System Errors
E41
Communication Error
  • Reset machine power for 5–10 minutes.
  • Inspect wiring between PCB and components.
  • Check for moisture on control board.
  • Replace PCB if communication fails.
E43
Control Board Failure
  • Inspect main control board for damage.
  • Check power supply stability.
  • Reset appliance system.
  • Replace control board if needed.
Important: If errors continue after troubleshooting, disconnect power immediately and contact a certified Frigidaire technician.
