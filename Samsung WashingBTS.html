Samsung Washing Machine Troubleshooting Guide

Error Codes & Repair Instructions

Water Supply & Drainage Issues

4E / 4C
Water Supply Problem
  • Check water tap is fully open.
  • Inspect inlet hose for blockage.
  • Clean inlet filter screen.
  • Check water pressure.
5E / 5C
Drainage Issue
  • Clean drain filter.
  • Check drain hose for clogging.
  • Inspect pump operation.
  • Reset machine.
1E
Water Level Sensor Error
  • Check pressure sensor hose.
  • Inspect wiring connection.
  • Clean air trap.
  • Replace sensor if faulty.
4E2
Water Inlet Valve Error
  • Check inlet valve filter.
  • Inspect valve wiring.
  • Test water supply pressure.
  • Replace valve if needed.

Motor & Drum Issues

3E
Motor Error
  • Turn off machine for 10 minutes.
  • Check motor wiring.
  • Inspect drum movement.
  • Replace motor if needed.
3C
Motor Overload Detected
  • Reduce laundry load.
  • Check drum blockage.
  • Inspect motor condition.
  • Restart machine.
3E2
Motor Hall Sensor Failure
  • Check hall sensor wiring.
  • Inspect rotor movement.
  • Test sensor signal.
  • Replace sensor if faulty.
UE / UB
Unbalanced Load
  • Redistribute clothes evenly.
  • Avoid single heavy items.
  • Reduce load size.
  • Restart cycle.

Drain & Leak Issues

LE / LC
Water Leak Detected
  • Check hose connections.
  • Inspect door seal.
  • Look for cracks in tub.
  • Dry and restart unit.
5E2
Drain Motor Abnormality
  • Clean drain pump filter.
  • Inspect drain motor wiring.
  • Check for blockages.
  • Replace pump if needed.

Door & Control Issues

dE / DC
Door Issue
  • Ensure door is fully closed.
  • Check latch mechanism.
  • Inspect door switch.
  • Replace lock if needed.
bE
Button Stuck Error
  • Clean control panel.
  • Check stuck buttons.
  • Reset machine.
  • Replace panel if needed.
dC1
Door Lock Failure
  • Check door latch.
  • Inspect wiring connection.
  • Test lock mechanism.
  • Replace door lock.

Sensor & Heating Issues

tE
Temperature Sensor Failure
  • Check thermistor wiring.
  • Inspect heating system.
  • Test sensor resistance.
  • Replace sensor if needed.
HE / 6E
Heating Error / Relay Fault
  • Check heating element.
  • Inspect relay connection.
  • Test wiring continuity.
  • Replace heater if faulty.
HC2
Heating Sensor Issue
  • Inspect heater sensor.
  • Check wiring harness.
  • Test resistance levels.
  • Replace sensor if needed.

Power & System Errors

9E1
Power Supply Issue
  • Check outlet voltage.
  • Inspect power cord.
  • Reset machine.
  • Call electrician if unstable.
9E2
Low Voltage Detected
  • Use stable power supply.
  • Avoid extension cords.
  • Check breaker box.
  • Restart unit.
EE
EEPROM Data Error
  • Reset machine.
  • Check control board.
  • Inspect firmware corruption.
  • Replace PCB if needed.
AC / AE
Communication Error
  • Check wiring between boards.
  • Reset system.
  • Inspect connectors.
  • Replace PCB if needed.
AC6
Inverter Communication Error
  • Check inverter wiring.
  • Inspect control board.
  • Reset machine.
  • Service required if persistent.
2E
Internal System Error
  • Power reset unit.
  • Check PCB board.
  • Inspect wiring connections.
  • Replace control board if needed.
Important: If the issue continues after troubleshooting, disconnect power and contact Samsung service center or qualified technician.
