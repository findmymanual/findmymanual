GE Oven & Range Error Codes

Complete Troubleshooting & Repair Guide

Control Panel Errors
F0
Function Key Stuck
  • Press each keypad button individually.
  • Clean control panel surface.
  • Disconnect power for 5 minutes.
  • Replace keypad if button remains stuck.
F1
Electronic Control Failure
  • Power cycle the oven.
  • Inspect control board connections.
  • Check for burn marks or damage.
  • Replace electronic control board if needed.
F5
Control Board Hardware Issue
  • Disconnect appliance power.
  • Inspect PCB for visible damage.
  • Check internal wiring harnesses.
  • Replace faulty control board.
F7
Keypad Failure
  • Inspect ribbon cable connection.
  • Clean keypad contacts carefully.
  • Restart appliance after reset.
  • Replace keypad assembly if unresponsive.
Temperature Sensor Errors
F2
Oven Over-Temperature Condition
  • Turn off oven immediately.
  • Allow appliance to cool completely.
  • Check cooling fan operation.
  • Inspect temperature sensor accuracy.
F3
Oven Sensor Open
  • Inspect oven sensor wiring.
  • Check sensor resistance values.
  • Ensure connector is secure.
  • Replace sensor if circuit is open.
F4
Oven Sensor Shorted
  • Disconnect power before inspection.
  • Check for damaged sensor wires.
  • Test sensor for short circuit.
  • Replace defective temperature sensor.
Cooling Fan Errors
F8
Cooling Fan Failure
  • Inspect cooling fan blades for obstruction.
  • Check fan motor wiring.
  • Verify fan spins freely.
  • Replace cooling fan motor if faulty.
Door Lock Errors
F9
Door Lock Malfunction
  • Inspect door latch assembly.
  • Check lock motor operation.
  • Ensure door alignment is correct.
  • Replace defective door lock mechanism.
Important: If the error code continues after troubleshooting, disconnect power immediately and contact a certified GE technician.
