Samsung Air Conditioner Troubleshooting Guide

Error Codes & Repair Instructions

Communication & PCB Errors

E1
Indoor/Outdoor Communication Error
  • Turn OFF power for 5–10 minutes.
  • Check communication wiring between units.
  • Inspect PCB connectors.
  • Restart system.
E101
Indoor PCB Error
  • Reset power supply.
  • Inspect indoor control board.
  • Check for burnt components.
  • Replace PCB if needed.
E237-1
Outdoor PCB Communication Failure
  • Check outdoor PCB wiring.
  • Inspect signal cable.
  • Restart both units.
  • Replace PCB if necessary.

Fan Motor Errors

E154
Fan Motor Error
  • Check fan blade for blockage.
  • Inspect motor wiring.
  • Clean dust buildup.
  • Replace motor if faulty.
E201
Indoor Fan Motor Error
  • Check indoor blower motor.
  • Inspect capacitor.
  • Clean air filter.
  • Replace motor if needed.
E202
Outdoor Fan Motor Error
  • Check outdoor fan rotation.
  • Inspect wiring connection.
  • Remove debris.
  • Replace motor if abnormal.
C404
Outdoor Fan Error
  • Inspect fan blades.
  • Check motor capacitor.
  • Clean condenser area.
  • Replace fan motor if needed.

Sensor & Temperature Errors

C101
Temperature Sensor Error
  • Check indoor thermistor.
  • Inspect wiring connection.
  • Test sensor resistance.
  • Replace sensor if faulty.
E128
Indoor Temperature Sensor Failure
  • Inspect sensor cable.
  • Clean evaporator area.
  • Check PCB connection.
  • Replace sensor if needed.
C105
Indoor Coil Sensor Abnormality
  • Check coil sensor wiring.
  • Inspect evaporator coil.
  • Clean dust buildup.
  • Replace sensor if faulty.
C417
Outdoor Temperature Sensor Error
  • Inspect outdoor sensor wiring.
  • Check sensor placement.
  • Clean outdoor unit.
  • Replace sensor if needed.

Compressor & Refrigeration Errors

E203
Compressor Failure
  • Check compressor wiring.
  • Inspect capacitor and relay.
  • Verify power supply.
  • Replace compressor if needed.
E251
Compressor Overheating
  • Turn OFF system.
  • Check airflow around outdoor unit.
  • Clean condenser coil.
  • Call technician if repeated.
E440
Compressor Overload
  • Check refrigerant level.
  • Inspect condenser coil.
  • Ensure proper ventilation.
  • Restart system.
E422
Low Refrigerant Detected
  • Check for refrigerant leaks.
  • Inspect piping system.
  • Do not run unit continuously.
  • Call HVAC technician.
E320
Refrigerant Leak Detected
  • Turn OFF unit immediately.
  • Check oil residue on pipes.
  • Inspect coil for damage.
  • Schedule repair service.
E441
High Pressure Protection
  • Clean condenser coil.
  • Check airflow blockage.
  • Ensure outdoor ventilation.
  • Restart after cooling.

System Errors

E162
EEPROM Error
  • Reset power supply.
  • Inspect control board.
  • Check firmware corruption.
  • Replace PCB if needed.
E237
Outdoor Communication Issue
  • Check communication cable.
  • Inspect PCB connectors.
  • Restart system.
  • Replace board if needed.
E237-1
Outdoor Communication Failure
  • Inspect wiring harness.
  • Check PCB signal line.
  • Reset system.
  • Replace PCB if needed.
Important: If the error persists after troubleshooting, disconnect power immediately and contact a qualified HVAC technician.
