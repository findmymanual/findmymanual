Nikon Camera Error Codes

Diagnostic & Troubleshooting Guide

Memory Card Errors
CHA / CHR
Memory Card Read/Write Error
  • Reinsert memory card properly.
  • Try a different SD card.
  • Format card in camera.
  • Check card compatibility.
For
Formatting Required
  • Backup data immediately.
  • Format memory card in camera menu.
  • Use recommended card type.
  • Avoid formatting on computer unless necessary.
Lens Errors
FEE
Aperture Ring Not Locked
  • Set lens aperture ring to minimum (locked position).
  • Reattach lens securely.
  • Check compatibility of lens model.
  • Clean lens contacts if needed.
F--
Lens Communication Failure
  • Remove and reattach lens.
  • Clean lens contacts carefully.
  • Test with another lens.
  • Inspect lens mount for damage.
System Errors
ERR
General Camera Malfunction
  • Restart camera.
  • Remove battery and memory card.
  • Update firmware if available.
  • Reset camera settings.
E
Internal System Error
  • Power cycle camera.
  • Check for firmware updates.
  • Remove external accessories.
  • Service camera if persistent.
Storage Status Messages
FULL
Memory Card Full
  • Delete unwanted files or images.
  • Transfer data to computer.
  • Replace with larger capacity card.
  • Format card after backup.
No Card
Memory Card Not Detected
  • Insert memory card properly.
  • Clean card contacts gently.
  • Try another SD card.
  • Restart camera.
Note: Many Nikon errors are card or lens related and can be fixed with reseating or formatting.
