Sony PlayStation Error Codes

System, Network & Account Troubleshooting Guide

System & Application Errors
CE-34878-0
Application Crash Error
  • Restart the game or application.
  • Update system software and game patches.
  • Rebuild database in Safe Mode.
  • Reinstall corrupted application if needed.
CE-36329-3
System Error / Crash Report
  • Restart console and check for updates.
  • Clear cache and rebuild database.
  • Check storage health for corruption.
  • Contact support if persistent.
Network Errors
NW-31201-7
Network Connection Failure
  • Restart router and console.
  • Check Wi-Fi or LAN cable connection.
  • Test internet connection settings.
  • Change DNS to Google DNS (8.8.8.8).
PlayStation Network Errors
WS-37397-9
PSN Service Restriction
  • Check PSN server status.
  • Verify account standing and bans.
  • Log out and sign back in.
  • Contact PlayStation Support if needed.
NP-102942-8
Account Sign-In Issue
  • Verify email and password.
  • Reset PlayStation account password.
  • Check two-factor authentication settings.
  • Try sign-in from another network.
System Update Errors
SU-30746-0
System Software Update Failure
  • Restart console and retry update.
  • Update via Safe Mode using USB.
  • Check internet stability.
  • Reinstall system software if needed.
Store & Payment Errors
E-8210604A
Payment Method Error
  • Check card details and billing address.
  • Ensure payment method is supported.
  • Try another payment method.
  • Contact bank if transaction is blocked.
Note: Some errors are service-related and may require waiting for PSN recovery.
