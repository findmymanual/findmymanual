Midea System Messages

Meaning & Quick Troubleshooting Guide

Control System Messages
LOC
Child Lock Active
  • Press and hold lock button for 3–5 seconds.
  • Check control panel for stuck keys.
  • Refer to model-specific unlock method.
  • Power reset if lock remains active.
ERR
General System Error
  • Turn off appliance and disconnect power.
  • Wait 5–10 minutes before restarting.
  • Check for additional error codes.
  • Inspect control board if error persists.
RESET
System Restart Required
  • Unplug appliance from power source.
  • Wait several minutes before reconnecting.
  • Restart system and monitor operation.
  • Contact technician if message returns.
Temperature & Cooling Messages
HOT
Overheat Warning
  • Allow appliance to cool completely.
  • Check airflow and ventilation.
  • Inspect fans for proper operation.
  • Avoid continued use until cooled.
COOL
Cooling Cycle Active
  • Normal cooling operation in progress.
  • Do not unplug during cycle.
  • Allow system to complete cooling.
  • No repair needed unless persistent.
Power System Messages
PF
Power Failure Detected
  • Check household power supply.
  • Inspect circuit breaker and outlet.
  • Reset appliance after power restoration.
  • Reconfigure settings if required.
Important: If system messages appear frequently, it may indicate an electrical or control board issue requiring professional service.
