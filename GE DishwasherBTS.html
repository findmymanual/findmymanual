GE Dishwasher Error Codes

Complete Troubleshooting & Repair Guide

Drain System Errors
C1
Drain Timeout
  • Inspect drain hose for blockage or kinks.
  • Clean dishwasher filter and sump area.
  • Check drain pump operation.
  • Restart dishwasher after cleaning.
Water Supply Errors
C2
Water Fill Problem
  • Ensure water supply valve is open.
  • Inspect inlet hose for blockage.
  • Clean inlet valve filter screen.
  • Check household water pressure.
Heating & Temperature Errors
C3
Water Temperature Issue
  • Verify incoming hot water temperature.
  • Inspect heating element connections.
  • Check temperature sensor operation.
  • Replace faulty heating component if needed.
C7
Heating Element Failure
  • Disconnect power before inspection.
  • Test heating element continuity.
  • Inspect wiring for damage or burns.
  • Replace heating element if defective.
Leak & Float System Errors
C4
Float Switch Activated
  • Check for standing water inside base.
  • Inspect float switch for obstruction.
  • Dry internal leak tray if wet.
  • Reset dishwasher after inspection.
C6
Water Leak Detected
  • Inspect hoses and pump seals for leaks.
  • Check door gasket condition.
  • Dry internal components completely.
  • Repair leaking parts before restarting.
Door System Errors
C5
Door Not Latched Properly
  • Close door firmly and restart cycle.
  • Inspect latch assembly for damage.
  • Check door alignment.
  • Replace defective latch switch if needed.
Electronic Control Errors
888
Control Board Initialization Error
  • Disconnect power for 10 minutes.
  • Inspect control board wiring connections.
  • Check for moisture or burn marks.
  • Replace control board if error persists.
Important: If the error code continues after troubleshooting, disconnect power immediately and contact a certified GE technician.
