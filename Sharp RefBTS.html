Sharp Refrigerator Error Codes

Complete Diagnostic & Troubleshooting Guide

Temperature & Sensor Errors
F1
Temperature Sensor Fault
  • Inspect thermistor wiring connections.
  • Test sensor resistance values.
  • Check for corrosion or loose terminals.
  • Replace faulty temperature sensor.
F5
Door Sensor Error
  • Ensure refrigerator door closes fully.
  • Inspect door switch alignment.
  • Test door sensor continuity.
  • Replace sensor if defective.
Defrost System Errors
F2
Defrost System Error
  • Test defrost heater continuity.
  • Inspect defrost thermostat and wiring.
  • Check evaporator for excessive ice buildup.
  • Replace faulty defrost components.
Fan System Errors
F3
Fan Motor Failure
  • Inspect evaporator fan for obstruction.
  • Check fan motor wiring connections.
  • Test fan motor operation.
  • Replace fan motor if defective.
Compressor System Errors
F4
Compressor Issue
  • Inspect compressor relay and capacitor.
  • Check voltage supply stability.
  • Clean condenser coils for airflow.
  • Replace compressor components if needed.
Communication Errors
F6
Communication Failure
  • Power cycle the refrigerator.
  • Inspect wiring between control boards.
  • Check connectors for looseness or damage.
  • Replace main PCB if communication fails.
Important: Compressor and electrical repairs should only be performed by a certified appliance technician.
