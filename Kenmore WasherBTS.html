Kenmore Washer Error Codes

Complete Troubleshooting & Repair Guide

Control System Errors
F1
Main Control Board Failure
  • Power cycle the washer (unplug for 5–10 minutes).
  • Inspect control board for burn marks or damage.
  • Check wiring harness connections.
  • Replace main control board if error persists.
F2
Keypad Stuck or Shorted
  • Inspect control panel for stuck buttons.
  • Clean keypad surface for moisture or debris.
  • Disconnect and reconnect ribbon cable.
  • Replace user interface if unresponsive.
Drain System Errors
F21
Drain System Issue
  • Check drain hose for blockage or kinks.
  • Clean pump filter and impeller.
  • Inspect drain pump operation.
  • Replace pump if necessary.
Door System Errors
F22
Door Lock Failure
  • Ensure door is fully closed.
  • Inspect door latch and strike mechanism.
  • Check wiring to door lock assembly.
  • Replace door lock if faulty.
Heating System Errors
F23
Heating Element Fault
  • Test heating element continuity.
  • Inspect wiring for burns or disconnection.
  • Check temperature relay function.
  • Replace heating element if defective.
Water Temperature Errors
F24
Water Temperature Error
  • Check inlet water temperature supply.
  • Inspect thermistor sensor wiring.
  • Test sensor resistance values.
  • Replace temperature sensor if faulty.
Motor System Errors
F28
Motor Control Error
  • Inspect motor wiring connections.
  • Check belt and drum movement.
  • Test motor operation under load.
  • Replace motor control board if needed.
F29
Motor Tachometer Issue
  • Check tachometer sensor wiring.
  • Inspect motor rotor for damage.
  • Test speed feedback signal.
  • Replace motor or sensor if faulty.
Water Level Errors
F31
Pressure Switch Fault
  • Check pressure hose for blockage or leaks.
  • Inspect pressure switch operation.
  • Clean or replace hose if clogged.
  • Replace switch if defective.
F32
Water Level Sensor Error
  • Inspect water level sensor wiring.
  • Check for moisture or corrosion.
  • Test sensor resistance.
  • Replace sensor if incorrect readings occur.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified Kenmore technician.
