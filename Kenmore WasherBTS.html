Kenmore Washer Error Codes

Complete Kenmore Washer Guide

This guide explains all Kenmore Washer error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

F1
Main Control Board Failure
  • Power cycle the washer (unplug for 5–10 minutes).
  • Inspect control board for burn marks or damage.
  • Check wiring harness connections.
  • Replace main control board if error persists.
F2
Keypad or User Interface Fault
  • Check control panel for stuck buttons.
  • Clean surface for moisture or debris.
  • Reconnect ribbon cable.
  • Replace user interface if unresponsive.
F3
Communication Error
  • Inspect wiring between control boards.
  • Power cycle washer.
  • Check for loose connectors.
  • Replace control board if needed.
F21 / E21
Drain System Failure
  • Check drain hose for blockage or kinks.
  • Clean pump filter and impeller.
  • Inspect drain pump operation.
  • Replace drain pump if needed.
F22
Drain Pump Slow or Blocked
  • Clear lint or debris from pump.
  • Check hose routing.
  • Inspect pump motor wiring.
  • Replace pump if weak.
F23
Door Lock Failure
  • Ensure door is fully closed.
  • Inspect latch and strike mechanism.
  • Check door lock wiring.
  • Replace door lock assembly if faulty.
F24
Door Switch Error
  • Test door switch continuity.
  • Check alignment of latch.
  • Inspect wiring connections.
  • Replace switch if defective.
F25
Motor Control Failure
  • Check motor wiring harness.
  • Inspect belt and drum rotation.
  • Test motor operation.
  • Replace motor control board if needed.
F26
Motor Tachometer Fault
  • Inspect tachometer sensor wiring.
  • Check rotor and motor shaft.
  • Test speed feedback signal.
  • Replace motor if faulty.
F27
Motor Overload
  • Reduce laundry load size.
  • Check drum for blockage.
  • Inspect motor overheating.
  • Allow cooling before restart.
F28
Water Inlet Failure
  • Check water supply valves.
  • Inspect inlet hose for blockage.
  • Clean inlet filter screens.
  • Replace inlet valve if needed.
F29
Water Fill Timeout
  • Check water pressure.
  • Inspect inlet valve operation.
  • Clear hose blockages.
  • Replace valve if slow fill persists.
F30
Pressure Sensor Failure
  • Check pressure hose for leaks or blockage.
  • Inspect sensor connection.
  • Clean hose and fittings.
  • Replace pressure switch if faulty.
F31
Water Level Sensor Error
  • Inspect sensor wiring.
  • Check for corrosion or moisture.
  • Test resistance values.
  • Replace sensor if needed.
F32
Heating Element Fault
  • Test heating element continuity.
  • Inspect wiring connections.
  • Check thermostat operation.
  • Replace heating element if defective.
F33
Thermal Fuse Open
  • Inspect thermal fuse continuity.
  • Check for overheating issues.
  • Ensure proper ventilation.
  • Replace fuse if blown.
F34
Imbalance Detection
  • Redistribute laundry evenly.
  • Remove heavy or single items.
  • Check drum movement.
  • Restart cycle.
F35
Oversuds Condition
  • Reduce detergent amount.
  • Use HE detergent only.
  • Run rinse cycle.
  • Check detergent drawer.
F36
Communication Fault
  • Inspect wiring between boards.
  • Power cycle washer.
  • Check connectors.
  • Replace control board if needed.

Frequently Asked Questions


Why does my Kenmore washer not respond?
Check power supply, control lock status, and control board connection. Try resetting the washer.
Why is my Kenmore washer not starting?
Ensure the door is fully closed and locked. Check power supply and verify control panel is responsive.
Why is my Kenmore washer not spinning or agitating?
Inspect motor, drive belt, and load balance. Remove overload and reset the washer system.
Why is my Kenmore washer taking too long to complete a cycle?
Check load balance, water supply, and sensor performance. Avoid overloading the washer.
Why is my Kenmore washer making unusual noises?
Inspect drum, motor, and internal components. Ensure no foreign objects are inside the drum.
Why does my Kenmore washer stop mid-cycle?
Check for drainage issues, overheating protection, and power interruptions. Restart after cooling.
Why is my Kenmore washer not draining water?
Inspect drain hose for blockage. Clean pump filter and check drain pump operation.
Why is my Kenmore washer not filling with water?
Check water inlet valve, hose connection, and water pressure. Clean inlet filters if needed.
Why is my Kenmore washer showing an error code or system message?
Note the error code displayed. Reset the washer and inspect sensors, wiring, or control board if needed.
Why is my Kenmore washer display not working?
Check power connection, display module, and control board. Restart system and inspect wiring.
Why is my Kenmore washer leaking water?
Inspect hoses, pump, and door seal. Tighten connections and replace damaged components if needed.
Why is my Kenmore washer vibrating or shaking excessively?
Check load balance, leveling legs, and floor stability. Redistribute laundry evenly.
How do I reset my Kenmore washer system messages?
Turn off power for 5–10 minutes, then restore power to reset system errors and clear temporary faults.
Important: If Kenmore washer system messages persist after troubleshooting, disconnect power and contact a certified technician.
