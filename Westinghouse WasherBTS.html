Westinghouse Washing Machine Error Codes

Complete Troubleshooting & Repair Guide

Water System Errors
E1
Water Inlet Issue
  • Check water supply valves are fully open.
  • Inspect inlet hose for kinks or blockage.
  • Clean inlet filter screen.
  • Verify household water pressure.
E5
Water Overflow Detected
  • Turn off water supply immediately.
  • Check water level sensor for fault.
  • Inspect inlet valve for sticking open.
  • Reset appliance after draining excess water.
Drain System Errors
E2
Drain Pump Failure
  • Check drain hose for blockage or kink.
  • Clean pump filter.
  • Inspect pump impeller for debris.
  • Replace drain pump if not working.
Door System Errors
E3
Door Lock Error
  • Ensure door is fully closed.
  • Inspect door latch alignment.
  • Check wiring to door lock.
  • Replace lock mechanism if faulty.
Motor & Load Errors
E4
Motor Failure
  • Check motor wiring connections.
  • Inspect drum belt and motor shaft.
  • Test motor resistance.
  • Replace motor if defective.
E8
Unbalanced Load Detected
  • Redistribute laundry evenly in drum.
  • Check suspension springs and shock absorbers.
  • Reduce load size if overloaded.
  • Run spin cycle test.
Heating System Errors
E6
Temperature Sensor Fault
  • Inspect temperature sensor wiring.
  • Test sensor resistance with multimeter.
  • Check connector for corrosion.
  • Replace sensor if readings are incorrect.
E7
Heater Error
  • Check heating element continuity.
  • Inspect wiring harness.
  • Verify control board output.
  • Replace heater if faulty.
Control System Errors
E9
Control Board Failure
  • Reset power for 5–10 minutes.
  • Inspect PCB for burn marks or damage.
  • Check wiring connections.
  • Replace control board if necessary.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified Westinghouse technician.
