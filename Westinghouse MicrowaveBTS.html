Westinghouse Microwave Error Codes

Complete Troubleshooting & Repair Guide

Control Panel Errors
F1
Touch Pad Fault
  • Check keypad ribbon cable connection.
  • Inspect control panel for moisture or damage.
  • Clean surface and remove debris.
  • Replace touch panel if unresponsive.
Safety & Temperature Errors
F2
Overheat Protection
  • Allow microwave to cool down completely.
  • Check ventilation openings for blockage.
  • Ensure unit is not overused continuously.
  • Inspect thermal sensor or fuse.
Sensor Errors
F3
Sensor Failure
  • Inspect temperature or humidity sensor wiring.
  • Check for loose or corroded connectors.
  • Test sensor resistance with multimeter.
  • Replace sensor if readings are abnormal.
Door System Errors
F4
Door Switch Error
  • Ensure door closes and latches properly.
  • Inspect door switch alignment.
  • Test door interlock switch continuity.
  • Replace switch if faulty.
Heating System Errors
F5
Magnetron Issue
  • Check high-voltage components carefully.
  • Inspect magnetron for burn damage.
  • Test diode and capacitor condition.
  • Replace magnetron if faulty (technician recommended).
Important: Microwave high-voltage systems are dangerous. If error persists, stop using the appliance and contact a qualified technician.
