Electrolux System Messages Error Codes

Complete Electrolux System Messages Guide

This guide explains all Electrolux System Messages error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

PF
Power Failure Detected
  • Check household power supply and circuit breaker.
  • Reset appliance by unplugging for 5–10 minutes.
  • Reprogram settings after power is restored.
  • Inspect outlet for unstable voltage.
RESET
System Restart Required
  • Turn off refrigerator completely.
  • Wait 5–10 minutes before restarting.
  • Check if display clears after reboot.
  • Inspect control board if issue persists.
LOC
Control Lock Active
  • Press and hold lock button for 3–5 seconds.
  • Clean control panel from moisture or dirt.
  • Check keypad responsiveness.
  • Reset power if lock cannot be cleared.
HOT
Overheat Warning
  • Ensure proper ventilation around unit.
  • Check condenser coils for dust buildup.
  • Allow appliance to cool down.
  • Do not overload internal compartments.
DOOR
Door Not Closed
  • Ensure door is fully closed and sealed.
  • Check gasket for damage or debris.
  • Inspect door switch sensor.
  • Remove items blocking door closure.
ERR
General System Error
  • Restart refrigerator system.
  • Check wiring connections.
  • Inspect control board condition.
  • Replace PCB if error persists.
COOL
Cooling Cycle Active
  • Allow cycle to complete normally.
  • Do not open doors frequently.
  • Ensure airflow is not blocked.
  • System will stabilize automatically.
DEF
Defrost Cycle Active
  • Ice is being removed automatically.
  • Do not disconnect power during cycle.
  • Wait for completion before use.
  • Check drain path after defrost.
FAN
Fan Operation Mode
  • Check if fan is blocked or frozen.
  • Inspect evaporator fan motor.
  • Verify airflow inside compartments.
  • Replace fan motor if needed.
SLEEP
Sleep Mode Active
  • Appliance is in low power mode.
  • Check timer settings.
  • Disable sleep mode if needed.
  • Press any control to wake system.
ECO
Energy Saving Mode
  • System is running in energy-saving mode.
  • Cooling may be slightly reduced.
  • Adjust settings for higher performance.
  • Ensure ambient temperature is stable.
FILTER
Filter Maintenance Required
  • Clean air filter thoroughly.
  • Remove dust and debris buildup.
  • Dry filter before reinstalling.
  • Reset filter indicator after cleaning.
WIFI
Wi-Fi Connection Active
  • Check router connection stability.
  • Reconnect device to network.
  • Reset network settings if needed.
  • Verify correct password entry.
SERVICE
Maintenance Reminder
  • Schedule routine maintenance check.
  • Clean condenser coils and filters.
  • Inspect internal components.
  • Contact technician if warning persists.

Frequently Asked Questions


What does E10 Water Supply / Inlet Issue mean?
Check water supply valve is open, inspect inlet hose for blockage or kinks, clean filter screen, and ensure proper water pressure for ice maker or dispenser system.
What does E20 Cooling Performance Failure mean?
Check evaporator fan operation, clean condenser coils, inspect airflow inside compartments, and ensure correct temperature settings.
What does E24 Overheating Protection Activated mean?
Ensure proper ventilation around refrigerator, clean condenser coils, check compressor operation, and allow unit to stabilize temperature.
What does E30 Door Open / Door Switch Issue mean?
Ensure refrigerator door is fully closed, check door gasket seal, inspect door switch operation, and remove any obstruction preventing closure.
What does E40 Door Seal or Lock Failure mean?
Inspect door gasket for damage, check alignment of door hinges, test door switch, and replace seal or latch if necessary.
What does E50 Fan Motor / Air Circulation Fault mean?
Check evaporator or condenser fan for blockage, inspect wiring connections, test fan motor operation, and replace fan if defective.
What does E51 Relay / Control Circuit Fault mean?
Inspect control board relay system, check wiring harness, test switching operation, and replace PCB if faulty.
What does E52 Fan or Compressor Signal Loss mean?
Check wiring connections to compressor or fan motor, inspect feedback signal circuit, and replace motor or control board if signal is missing.
What does E56 Cooling System Failure mean?
Inspect compressor operation, check condenser coils for dust buildup, verify fan performance, and allow technician inspection if needed.
What does E60 Temperature Control Fault mean?
Check temperature sensors, inspect airflow inside fridge, ensure doors are sealing properly, and allow system to stabilize.
What does E61 Temperature Sensor Fault mean?
Inspect thermistor wiring, test resistance values, check connectors for corrosion, and replace sensor if readings are incorrect.
What does E63 Cooling Performance Issue mean?
Clean condenser coils, ensure proper airflow, avoid overloading fridge, and check evaporator fan operation.
What does E66 Airflow Restriction mean?
Remove food blocking air vents, clean internal ducts, check fan operation, and ensure proper spacing around refrigerator.
What does E68 Control Board Failure mean?
Restart refrigerator power, inspect PCB for moisture or damage, check wiring connections, and replace control board if needed.
What does E70 Communication Error mean?
Check wiring between main control board and display module, inspect connectors, restart system, and replace board if communication fails.
What does E90 Configuration Error mean?
Reset refrigerator power, verify system settings, check control board programming, and reprogram or replace PCB if necessary.
What does E91 Memory / EEPROM Fault mean?
Disconnect power and restart unit, inspect control board connections, check for PCB damage, and replace board if memory error persists.
What does E93 System Internal Fault mean?
Restart refrigerator system, inspect wiring harness, check control board condition, and replace PCB if issue continues.
Important: Always disconnect power before attempting repairs. If the issue continues, contact a qualified Electrolux service technician.
