Electrolux System Messages

Meaning & Troubleshooting Guide

Power & Startup Messages
PF
Power Failure Detected
  • Check household power supply and circuit breaker.
  • Reset appliance by unplugging for 5–10 minutes.
  • Reprogram settings after restart.
  • Inspect outlet for unstable voltage if repeated.
RESET
System Restart Required
  • Turn off power for several minutes.
  • Restart appliance after reset cycle.
  • Check if error returns after reboot.
  • Inspect control board if persistent.
Control Lock Messages
LOC
Control Lock Active
  • Press and hold lock button for 3–5 seconds.
  • Check if control panel is stuck or unresponsive.
  • Clean keypad surface from moisture or dirt.
  • Reset power if lock cannot be cleared.
Temperature & Safety Messages
HOT
Overheat Warning
  • Allow appliance to cool completely.
  • Check ventilation and airflow paths.
  • Clean filters or internal cooling system.
  • Do not restart until temperature normalizes.
Door & Safety Messages
DOOR
Door Not Closed
  • Ensure door is fully closed and latched.
  • Check for obstruction in door seal.
  • Inspect door switch sensor.
  • Replace latch or switch if faulty.
System Errors
ERR
General System Error
  • Perform full power reset.
  • Check wiring connections and control board.
  • Look for additional fault codes.
  • Replace control board if unresolved.
Cooling Cycle Messages
COOL
Cooling Cycle Active
  • Allow cycle to complete normally.
  • Do not open appliance unnecessarily.
  • Ensure proper ventilation around unit.
  • System will return to normal operation automatically.
Important: If system messages persist repeatedly, disconnect power and contact a certified Electrolux technician.
