Philips Air Fryer / Small Appliance Error Codes

System Diagnostic & Troubleshooting Guide

Temperature & Sensor Errors
E1
Temperature Sensor Fault
  • Check temperature probe connection.
  • Clean internal heating chamber.
  • Restart device.
  • Replace sensor if faulty.
Safety Protection Errors
E2
Overheat Protection
  • Turn off and allow cooling.
  • Ensure vents are not blocked.
  • Clean internal airflow channels.
  • Avoid continuous high-temperature use.
Airflow System Errors
E3
Fan Motor Error
  • Check fan for obstruction.
  • Inspect motor wiring.
  • Clean dust buildup inside unit.
  • Replace fan motor if not spinning.
Heating System Errors
E4
Heating Element Failure
  • Inspect heating coil for damage.
  • Check electrical connections.
  • Test continuity of element.
  • Replace heating component if needed.
Control System Errors
E5
Control Board Issue
  • Restart device.
  • Check internal wiring connections.
  • Inspect PCB for burn marks.
  • Replace control board if faulty.
Power System Errors
E6
Power Supply Instability
  • Check wall outlet stability.
  • Avoid using extension cords.
  • Inspect power cable for damage.
  • Test device on another outlet.
Note: Always unplug the appliance before inspecting internal components.
