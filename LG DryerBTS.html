LG Dryer Error Codes

Complete LG Dryer Troubleshooting Guide

d80
Airflow Blockage (80%)
  • Clean lint filter thoroughly.
  • Inspect vent hose for blockage.
  • Check exterior exhaust vent.
  • Ensure proper airflow path.
d90
Severely Blocked Vent (90%)
  • Disconnect dryer vent system.
  • Clean duct pipe completely.
  • Remove lint buildup inside vent.
  • Test airflow after cleaning.
d95
Critical Vent Blockage
  • Turn off dryer immediately.
  • Inspect full vent line system.
  • Remove all lint and obstructions.
  • Restart after airflow is restored.
tE1
Thermistor Error
  • Check temperature sensor wiring.
  • Inspect thermistor connection.
  • Reset power to unit.
  • Replace sensor if faulty.
tE2
Sensor Fault
  • Inspect internal wiring harness.
  • Check control board connection.
  • Restart dryer cycle.
  • Replace sensor if needed.
HS
Humidity Sensor Issue
  • Clean humidity sensor bars.
  • Check wiring connections.
  • Restart dryer.
  • Replace sensor if malfunctioning.
PS
Power Supply Issue
  • Check outlet voltage.
  • Inspect power cord.
  • Reset circuit breaker.
  • Avoid extension cords.
NP
No Power Detected
  • Ensure dryer is plugged in.
  • Check breaker panel.
  • Inspect fuse or outlet.
  • Test with another appliance.
DHE
Heater Error
  • Check heating element continuity.
  • Inspect thermal fuse.
  • Ensure proper airflow.
  • Replace heater if defective.
CL
Child Lock Enabled
  • Press and hold Child Lock button.
  • Refer to control panel instructions.
  • Wait for indicator to clear.
  • Resume operation.
PF
Power Failure
  • Check home power supply.
  • Reset breaker if tripped.
  • Restart dryer cycle.
  • Avoid unstable power sources.
Flow Sense
Vent Restriction Warning
  • Clean lint filter.
  • Inspect full duct system.
  • Remove airflow blockages.
  • Ensure proper vent installation.
LOC
Control Lock Enabled
  • Hold control lock button for 3–5 seconds.
  • Check control panel settings.
  • Restart dryer if needed.
  • Unlock controls before use.
nP
Incorrect Power Supply
  • Verify the dryer is connected to the correct outlet.
  • Check voltage requirements in the user manual.
  • Inspect the power cord for damage.
  • Contact an electrician if voltage is incorrect.
HE
Heating Error
  • Check the heating element for continuity.
  • Inspect the thermal fuse and thermostat.
  • Ensure vents are not blocked.
  • Replace faulty heating components if needed.
LE
Motor Lock Error
  • Turn off the dryer and unplug it.
  • Inspect the drum for obstructions.
  • Check motor wiring connections.
  • Restart the dryer after inspection.
AE
Auto Shutoff Error
  • Disconnect power for several minutes.
  • Inspect control board connections.
  • Check for overheating issues.
  • Restart the appliance.
FE
Frequency Error
  • Verify the electrical supply frequency.
  • Check outlet stability.
  • Avoid using generators if possible.
  • Contact an electrician if the issue persists.
E13
Drain Pump Error (Heat Pump Models)
  • Check the drain hose for blockages.
  • Empty the water container if equipped.
  • Inspect the drain pump operation.
  • Restart the dryer after clearing obstructions.
E14
Water Level Detection Error
  • Inspect the condensate tank.
  • Check sensor connections.
  • Clean the water level sensor.
  • Replace the sensor if necessary.
FO
Filter Maintenance Reminder
  • Remove and clean the lint filter.
  • Inspect the filter housing.
  • Ensure the filter is installed correctly.
  • Restart the drying cycle.
Hot
High Internal Temperature
  • Allow the dryer to cool down.
  • Check airflow and venting.
  • Clean the lint filter.
  • Resume operation once the warning clears.
Cool
Cool Down Cycle Active
  • This is not an error condition.
  • The dryer is cooling clothes before completion.
  • Wait for the cycle to finish.
  • Remove laundry when complete.
Add Water
Steam Function Water Supply Required
  • Fill the steam water reservoir.
  • Ensure the reservoir is seated properly.
  • Restart the steam cycle.
  • Check for leaks around the tank.
Empty Water
Condensate Tank Full
  • Remove and empty the water container.
  • Reinstall the tank securely.
  • Check the drain hose connection.
  • Resume the drying cycle.

Frequently Asked Questions


What does the d80 error code mean on an LG dryer?

The d80 error indicates approximately 80% airflow blockage in the dryer vent system. Clean the lint filter, inspect the vent hose, and check the outside exhaust vent for restrictions.

How do I fix the d90 error code on my LG dryer?

The d90 code means the vent system is severely restricted. Disconnect and clean the vent duct, remove lint buildup, and verify proper airflow before operating the dryer again.

What should I do when my LG dryer shows d95?

The d95 error indicates a critical vent blockage. Turn off the dryer, inspect the entire vent system, and remove all obstructions before restarting the appliance.

Can a clogged vent cause LG dryer error codes?

Yes. Codes such as d80, d90, and d95 are commonly triggered by restricted airflow caused by lint buildup, crushed ducts, or blocked exterior vents.

How often should I clean my LG dryer vent?

It is recommended to clean the lint filter after every load and inspect the vent system at least once a year to prevent airflow-related errors.

Will cleaning the lint filter fix a d80 error?

Cleaning the lint filter may resolve the issue if it is the source of the airflow restriction. If the error remains, inspect the entire vent system.

Can I continue using my LG dryer with a d95 error?

No. A d95 error indicates severe airflow blockage that can increase drying times and create overheating risks. Resolve the blockage before using the dryer.

Why are my clothes taking longer to dry?

Long drying times often occur when airflow is restricted by lint buildup, clogged vents, or an obstructed exhaust system.

How do I reset my LG dryer after fixing an error code?

Turn the dryer off, unplug it for several minutes, reconnect power, and restart the appliance. If the code returns, further troubleshooting may be required.

Can a crushed vent hose trigger LG dryer airflow errors?

Yes. A kinked or crushed vent hose can restrict airflow and cause d80, d90, or d95 error codes to appear.

What is the difference between d80, d90, and d95 errors?

The numbers represent the estimated severity of the airflow blockage. d80 indicates significant restriction, d90 indicates severe restriction, and d95 indicates critical blockage.

How can I prevent LG dryer airflow errors in the future?

Clean the lint filter regularly, inspect the vent system periodically, keep the exhaust vent clear, and avoid using excessively long or crushed vent hoses.

Important: If error codes persist, stop using the dryer and contact a qualified LG technician.
