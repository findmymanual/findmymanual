GE Dishwasher Error Codes

Complete GE Dishwasher Guide

This guide explains all GE Dishwasher error codes (CH series) with simple troubleshooting steps to help you identify and fix common issues safely before calling a technician.

C1
Drain Timeout
  • Inspect drain hose for blockage or kinks.
  • Clean dishwasher filter and sump area.
  • Check drain pump operation.
  • Restart dishwasher after cleaning.
C2
Water Fill Problem
  • Ensure water supply valve is fully open.
  • Inspect inlet hose for blockage.
  • Clean inlet valve filter screen.
  • Check household water pressure.
C3
Water Temperature Issue
  • Verify incoming hot water temperature.
  • Inspect heating element connections.
  • Check temperature sensor operation.
  • Replace heating component if needed.
C4
Float Switch Activated
  • Check for standing water in base pan.
  • Inspect float switch for obstruction.
  • Dry internal leak tray completely.
  • Reset dishwasher after inspection.
C5
Door Not Latched Properly
  • Close door firmly and restart cycle.
  • Inspect latch assembly for damage.
  • Check door alignment.
  • Replace latch switch if faulty.
C6
Water Leak Detected
  • Inspect hoses and pump seals for leaks.
  • Check door gasket condition.
  • Dry internal components completely.
  • Repair leaking parts before restart.
C7
Heating Element Failure
  • Disconnect power before inspection.
  • Test heating element continuity.
  • Inspect wiring for burns or damage.
  • Replace heating element if defective.
C8
Wash Motor Failure
  • Check wash motor for obstruction.
  • Inspect wiring harness connections.
  • Test motor resistance.
  • Replace motor if not running.
C9
Turbidity Sensor Fault
  • Clean sensor lens inside tub.
  • Inspect wiring connections.
  • Check for hard water buildup.
  • Replace sensor if readings are incorrect.
C0
Control Communication Error
  • Reset power for 10 minutes.
  • Inspect control board connections.
  • Check for moisture or corrosion on PCB.
  • Replace control board if failure persists.
888
Control Board Initialization Error
  • Disconnect power for 10 minutes.
  • Inspect control board wiring connections.
  • Check for moisture or burn marks.
  • Replace control board if error persists.
C10
Overfill Condition
  • Turn off water supply immediately.
  • Inspect inlet valve for sticking open.
  • Check float switch operation.
  • Replace inlet valve if needed.
C11
Drain Pump Failure
  • Inspect drain pump for blockage.
  • Check wiring and voltage supply.
  • Test pump motor operation.
  • Replace drain pump if defective.
C12
Pressure Sensor Fault
  • Inspect pressure sensor hose for clogging.
  • Check wiring connections.
  • Test sensor response.
  • Replace sensor if faulty.
C13
Spray Arm Blockage
  • Check spray arms for food debris.
  • Ensure arms rotate freely.
  • Clean spray nozzles thoroughly.
  • Reinstall correctly after cleaning.
C14
Water Level Sensor Error
  • Inspect water level sensor wiring.
  • Check for buildup or blockage.
  • Test sensor resistance values.
  • Replace sensor if readings are unstable.
C15
Power Supply Instability
  • Check household voltage supply.
  • Inspect outlet and breaker condition.
  • Avoid using extension cords.
  • Contact electrician if voltage fluctuates.
C16
Drying System Fault
  • Check drying fan operation.
  • Inspect vent for blockage.
  • Test thermal fuse continuity.
  • Replace drying heater if faulty.
C17
Detergent Dispenser Failure
  • Inspect dispenser door mechanism.
  • Check latch spring and motor.
  • Clean detergent residue buildup.
  • Replace dispenser assembly if needed.
C18
Salt/Water Softener Fault
  • Check salt reservoir for blockage.
  • Inspect softener valve operation.
  • Clean mineral buildup inside system.
  • Replace softener unit if malfunction persists.
C19
Anti-Flood Protection Activated
  • Check base tray for water leakage.
  • Inspect inlet valve for continuous flow.
  • Dry float switch area completely.
  • Replace leak sensor if triggered incorrectly.
C20
UI Control Panel Failure
  • Check ribbon cable connection.
  • Inspect keypad for stuck buttons.
  • Clean moisture from control panel.
  • Replace UI board if unresponsive.
C21
Motor Current Overload
  • Check wash motor for blockage.
  • Inspect wiring for overheating signs.
  • Test motor current draw.
  • Replace motor or control board if needed.
C22
Water Turbidity Sensor Dirty
  • Clean sensor lens inside tub.
  • Remove grease or hard water deposits.
  • Inspect sensor wiring connections.
  • Replace sensor if inaccurate readings continue.
C23
Inlet Flow Restriction
  • Check water inlet hose for kinks.
  • Clean inlet valve filter screen.
  • Ensure proper water pressure.
  • Replace inlet valve if flow remains low.
C24
Drain Backflow Detected
  • Check drain hose height installation.
  • Inspect for sewer backflow issues.
  • Clean non-return valve if present.
  • Reposition drain hose correctly.
C25
Heater Relay Stuck ON
  • Disconnect power immediately.
  • Inspect heater relay on control board.
  • Check for burnt PCB traces.
  • Replace main control board if relay is stuck.
C26
Temperature Sensor Drift
  • Test thermistor resistance accuracy.
  • Check sensor positioning in tub.
  • Inspect wiring harness.
  • Replace sensor if readings are unstable.
C27
Water Hammer / Pressure Surge
  • Check household water pressure stability.
  • Inspect inlet valve for rapid closing.
  • Install pressure regulator if needed.
  • Secure plumbing connections.
C28
Internal Memory Fault
  • Power cycle dishwasher for 10 minutes.
  • Check control board firmware corruption.
  • Inspect moisture damage on PCB.
  • Replace main PCB if error persists.
C29
Drain Pump Cavitation
  • Check pump for air blockage.
  • Inspect drain hose for partial clog.
  • Clean pump impeller thoroughly.
  • Replace pump if noise continues.
C30
System Calibration Required
  • Reset dishwasher to factory settings.
  • Run calibration cycle if available.
  • Check sensor alignment.
  • Update control board firmware if supported.

Frequently Asked Questions


Why is my dishwasher not cleaning dishes properly?
Check that spray arms are not clogged and can rotate freely. Clean the filter and sump area, use proper detergent, and ensure water temperature is sufficient for effective cleaning.
Why is my GE dishwasher not starting?
Ensure the dishwasher is plugged in and receiving power. Check that the door is fully closed and latched, select a wash cycle, and verify that child lock is not enabled.
Why is my GE dishwasher leaking water?
Inspect door gasket for damage or debris. Check hoses and connections for leaks, avoid overloading, and ensure the unit is properly leveled.
Why is my GE dishwasher making loud noises?
Check for loose items inside the tub, ensure spray arms are not hitting dishes, and inspect the drain pump or motor if noise continues.
Why does my GE dishwasher smell bad?
Clean the filter and spray arms, remove food debris buildup, run a cleaning cycle, and leave the door slightly open after use to prevent mold and odors.
Why is my GE dishwasher not drying dishes?
Check rinse aid level, ensure heated dry option is selected, inspect heating element, and confirm proper water temperature.
Why is my GE dishwasher not responding to controls?
Restart the dishwasher, check power supply, inspect control panel for stuck buttons or moisture, and reset the unit if needed.
Why does my GE dishwasher stop mid-cycle?
Check for power interruptions, door latch issues, or drainage problems. Ensure water supply is stable and restart the cycle.
How do I reset my GE dishwasher?
Turn off the dishwasher and unplug it for 5–10 minutes. Restore power, then select a new cycle to restart operation.
Important: If the error code continues after troubleshooting, disconnect power immediately and contact a certified GE technician.
