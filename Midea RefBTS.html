Midea Refrigerator Error Codes

Complete Troubleshooting & Diagnostic Guide

Temperature & Sensor Errors
F1
Temperature Sensor Fault
  • Check refrigerator thermistor wiring connections.
  • Test sensor resistance with multimeter.
  • Inspect for corrosion or loose connectors.
  • Replace temperature sensor if readings are abnormal.
Defrost System Errors
F2
Defrost System Failure
  • Test defrost heater continuity.
  • Inspect defrost thermostat and wiring.
  • Check evaporator for excessive ice buildup.
  • Replace defective defrost components.
Fan System Errors
F3
Fan Motor Error
  • Inspect evaporator fan for ice blockage.
  • Check fan motor wiring connections.
  • Test fan motor operation.
  • Replace fan motor if not functioning.
Compressor System Errors
F4
Compressor Issue
  • Check compressor start relay and capacitor.
  • Inspect power supply and voltage stability.
  • Ensure condenser coils are clean.
  • Replace compressor or relay if faulty.
Door System Errors
F5
Door Switch Error
  • Ensure door closes completely.
  • Inspect door switch alignment.
  • Test switch continuity.
  • Replace door switch if defective.
Communication Errors
F6
Communication Failure
  • Power cycle the refrigerator.
  • Inspect wiring between control boards.
  • Check connectors for looseness or corrosion.
  • Replace main PCB if communication fails.
Ice Maker Errors
F7
Ice Maker Fault
  • Check water supply line to ice maker.
  • Inspect ice maker module for jams.
  • Test fill valve operation.
  • Replace ice maker assembly if needed.
Important: If error codes persist after troubleshooting, disconnect power and contact a certified appliance technician.
